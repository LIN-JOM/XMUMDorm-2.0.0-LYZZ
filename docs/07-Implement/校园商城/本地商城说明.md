# 本地商城使用说明

仓库：https://github.com/yejianqin61-cell/XMUMDorm-2.0.0-LYZZ

## 启动与登录

项目目录为 `D:\Projects\XMUMDorm`。双击 `启动本地商城.cmd`，然后访问 http://127.0.0.1:5173/shop 。使用项目现有账号登录；商家在自己的店铺进入「商家管理」。本地运行不会自动更新线上网站。

已有商家默认使用「创建我的店铺」，新店直接归当前账号，创建后自动进入管理页。创建表单只需填写店铺名称和网址名称，不需要再次注册账号。普通学生不能创建商家或修改商品。管理员权限检查保留在服务端。

常规 Node 环境：安装根目录及 frontend 依赖，配置本地数据库，运行 `npm run migrate:shop`，分别运行 `npm run dev` 和 `npm run dev:web`。本机便携启动脚本使用已有 `.local` 运行工具，仅绑定本机地址，并关闭后台通知任务。

## 商家操作

进入店铺管理，新增商品并填写分类、双语名称、规格、描述、RM 价格及库存。商品图片支持拖拽或选择图片。在「配送时段」中设置一次每天重复的配送名称、开始与结束时间、每日容量并启用；无需逐日新增日期。学生下单时会看到系统自动安排的下一个可用日期及该时段。开始时间后提交的订单排到次日；具体时段与容量由商家按实际情况配置。

在「收款与配送 → 管理收款方式与配送费」维护付款方式，每个方式填写名称并上传自己的收款码，可拖拽或点击选图。支持 JPG、PNG、WebP、AVIF，单图不超过 5MB；HEIC 需要先转为 JPG。上传期间不能保存或关闭编辑窗口。上传成功后仍须点击保存，才会更新店铺配置。系统只检查图片文件，无法判断内容是否为可收款二维码；保存前商家必须自行扫码核对。配送日期与时段在「开放下单日期」单独管理。

修改付款码仅影响新订单；既有订单保留当时的付款信息，旧码不会立即删除。移除图片按钮只移除本次配置引用，不销毁历史订单使用的图片。

## 学生操作

选购、加入购物车、填写收货信息并选择配送时段后提交订单，按照订单详情的付款说明线下付款，再上传截图。截图上传成功才展示成功动效，订单仍为待人工核实，不能据此认定已经到账。

订单本人可以在「待核实」状态删除付款截图并重新上传。删除会清除数据库中的图片内容；已核实或已进入后续状态的订单不允许删除或替换凭证。商家查看凭证后人工核实，按状态流程备货、配送及完成。系统未接入支付网关、自动退款或通知发送。

## 数据与文件

本机 MySQL 数据库名沿用 `xmumdorm_demo`，名称保留不代表存在演示商品。物理数据在 `.local/mysql-data`。商品、库存、购物车、订单、商户关联及收货信息存储在现有 MySQL；付款截图存储在 `shop_payment_proofs`，按本人、所属商家和管理员限制读取。

本地商品图与付款码在 `.local/shop-assets`。正式环境付款码优先使用项目现有对象存储，必须配置公开 HTTPS 资源地址；未配置对象存储时必须显式配置持久目录 `SHOP_ASSET_DIR`。该目录必须挂载持久卷并备份；多实例必须共享目录。配置对象存储不代表商品图片也会自动迁移，商品图仍使用持久目录。

`.local/`、`.env` 和数据库文件不提交 Git。不要把任何账号密码、付款截图或学生资料放进提交。

## 已清理内容与待确认事项

已移除演示种子入口、公开演示图片、演示商户及相关订单、截图、账号，保留已有真实本地店铺。自动测试只在隔离临时数据库创建合成数据，结束删除临时库，不会初始化演示商户到应用数据库。

正式使用前须由商家确认商品与价格、实际收款人、配送时间（原表单中英文不一致）、配送范围及费用、截止时间、取消与退款规则、凭证留存期限。当前订单创建即占库存，取消返库存，不自动超时取消。
