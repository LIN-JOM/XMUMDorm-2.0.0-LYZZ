# 商家自建店铺与权限修复

当前问题：商城仅提供「创建商家账号与店铺」，当前登录商家代建新账号后，店铺仅属于新账号；页面却对任意商家展示管理链接，造成创建者访问被拒绝。

本次调整：默认提供「创建我的店铺」，使用当前登录身份在事务中创建店铺、成员关系、空白配置，成功跳转后台；不要求新账号和密码。商城页面已移除「为其他商家创建账号」入口，只保留当前登录商家自建店铺。服务端不接受客户端指定自建店铺的拥有者，不允许学生、停用账号创建；重复网址返回明确冲突，不追加权限。

当前本地水水店的创建审计证实由 shop_merchant 创建，此次按用户要求补回该账号的管理成员关系，保留原新账号的成员关系，不批量放宽其他店铺权限。

验证：隔离数据库测试覆盖自建店铺即获权限、不可伪造拥有者、跨店隔离、停用与学生账号拒绝、重名及并发冲突。前端静态检查、构建及本地现有账号访问验证。

完成结果：69项商城Jest测试、96项隔离MySQL/API断言通过，前端ESLint及构建通过。现有商家账号访问水水后台返回200，学生返回403；浏览器登录shop_merchant后已正常显示水水管理页面。当前修复仅限本地数据和代码，没有推送或部署。
