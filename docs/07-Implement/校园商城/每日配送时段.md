# 商家指定日期开放下单

当前商城不提供每日重复配送规则。商家在「开放下单日期」中手动添加具体日期和配送时间段；只有这些尚未截止、已启用且有可用容量的时段会展示给学生。未添加的日期不开放下单。

学生选择开放的日期和时段，填写联系人、联系方式、宿舍楼及房间号后提交订单。服务端会再次确认时段属于当前商家、标记为指定日期、仍启用且未截止，并在事务中锁定时段和库存。商家随后在后台查看学生地址并处理订单。

旧的 `shop_daily_schedules` 表和 `shop_slots.schedule_id` 数据结构由迁移 `073_daily_delivery_schedule.sql` 建立，为避免破坏历史数据库保留；当前商城目录与下单接口均不读取每日配送计划，也拒绝非指定日期时段下单。
