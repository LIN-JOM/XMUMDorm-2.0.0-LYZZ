# 校园资讯原创与转载声明实现记录

## 实现

- `SquareCampusPostNew.jsx` 新增原创/转载选择，转载来源必填。
- `campusPostAttribution.js` 将声明写入正文头部，复用现有发布、存储和展示链路。
- 未新增依赖、API 或数据库迁移；旧帖子与旧客户端行为不变。

## 验证

- `npm test -- __tests__/web/campusPostAttribution.test.js --runInBand`：3/3 通过。
- `cd frontend && npm run build`：生产构建通过。
- `npm test -- --runInBand`：886/888 通过；现有商城时段测试 2 例在当前日期失败，与本次发布页改动无关。

## 已知边界

声明是正文的一部分，不支持单独筛选原创/转载；如果未来确实需要筛选或统计，再升级为结构化字段。
