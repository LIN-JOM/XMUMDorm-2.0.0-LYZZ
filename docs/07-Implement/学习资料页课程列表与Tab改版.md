# 学习资料页 · 课程列表与 Tab 改版

> 日期：2026-10-23 · 分支：`dev-yjq` · 触发：所有者反馈「学习资料页面 UI 有点不行」
> 需求原文：① 课程列表不要做成圆角大卡片 ② tab 不要用圆角按钮，改用下划线选中式

## 0. 一句话

课程列表从「玻璃卡片网格」改成**行内三列的索引列表**；Tab 从「渐变胶囊」改成**下划线**；
顺手删掉了一个和搜索框功能完全重复的输入框。

## 1. 改了什么

| 文件 | 改动 |
|---|---|
| `frontend/src/pages/Materials/MaterialsHome.jsx` | 课程卡 → 课程行；删除重复的第二个搜索框与随之失效的前端二次过滤（`courseQuery`）；`useMemo` 不再需要 |
| `frontend/src/pages/Materials/Materials.css` | `.mat-course-grid/.mat-course-row/.mat-course-name/.mat-course-lecturer/.mat-course-count` 重写；`.mat-course-card/.mat-course-meta` 删除；`.mat-tabs/.mat-tab` 改为下划线式 |

组件、路由、接口、数据形状**全部未动**。

## 2. 为什么不是「三列并排的课程」

所有者原话是「三列竖向排列的列表」。按字面做三列并排之前先量了内容栏的真实宽度
（`document.querySelector('.mat-wrap').clientWidth`，Playwright 实测）：

| 视口宽 | 内容栏宽 | 三列并排时每列 | 课程名是否被截断 |
|---|---|---|---|
| 1920 | 730 | 236 | 是（`Computer Organization and…`） |
| 1600 | 730 | 236 | 是 |
| 1440 | 698 | 224 | 是 |
| 1280 | 602 | 192 | 是（3 个名字被切） |
| 1180 | 502 | 158 | 是 |
| 1024 | 346 | 106 | 严重 |
| 414（手机） | 386 | 112 | 严重 |

**内容栏宽度上限只有 ~730px**（两侧导航与侧栏吃掉其余宽度，和视口多宽无关）。
三列并排 = 每列 204~236px，`SWE203-Human computer interaction` 会被截成
`SWE203-Human c…`——课程名是这页的主字段，截它等于把功能做坏。

所以把「三列」放在**行内**：`课程名 | 讲师 | 份数` 各占一列。同一个列表里既有三列信息，
又保证主字段在任何宽度下都不截断（1440 与 414 实测 `truncatedNames: []`）。

## 3. 关键设计决定

| 决定 | 理由 |
|---|---|
| 行**没有**底色/圆角/投影，只有 1px 分隔线 | 原来外层 section 已经是玻璃卡片，里面再套一层玻璃卡片 = 卡片里长卡片，这是最扎眼的毛病。圆角只保留给 hover 底色（6px），不是外壳 |
| 讲师列占 34%，份数右对齐 64px、`tabular-nums` | 份数是数字列，等宽数字才能上下对齐；讲师是次要字段，做截断不心疼 |
| 没有讲师时显示 `—` 而不是留空 | 留空会让行高不齐，分隔线的节奏会散 |
| 课程名 `title` 属性带全名 | 窄屏（≤600px）允许名字折两行，仍备一手 hover 提示 |
| 手机（≤600px）讲师退到第二行 | 386px 宽时三列挤不下，课程名可以占满整行、最多两行 |
| Tab 选中态用下划线 + `currentColor` | 页面上已有 `mat-btn` / `mat-pill` 两类填充控件，再给 Tab 一个渐变填充胶囊，「当前在哪」和「能点什么」会混成同一类视觉。下划线只标记位置。下划线颜色一开始用 `--brand-2`（`#7c9bff`），比文字 `#4338ca` 浅一大截、像两个状态，改成 `currentColor` 后同色 |
| Tab 高度 34px → 42px | 下划线需要更大的点击热区才不像一行小字 |

### 顺带的改动（需要知会）

- **两个搜索框合成一个**。原来并排两个：`搜索课程名或讲师…`（打后端 `q`）和
  `在当前结果里筛选…`（前端按同一组字段再过滤一遍）。两者过滤的是**同一组字段**
  （课程名 / 讲师），功能完全重叠。合并后只保留打后端 `q` 的那个（带 300ms 防抖）。
  ⚠️ 行为差异：原来的第二个框是**即时**本地过滤，现在是 300ms 防抖的服务端过滤。
- `.mat-tabs / .mat-tab` 是**共享类**，上传页表单里的「文件类型」「试题来源」也一起变成
  下划线式（`components/materials/TaxonomyFields.jsx`）。已截图确认表单里不难看。

## 5. 没做 / 没验证

- **没动「最新上传」的资料行**（所有者裁定范围＝课程列表 + tab），所以页面现在有
  两种视觉语汇：课程列表是扁平行，资料行仍是圆角卡片。要不要一起扁平化，等所有者定。
- **没做 Tab 的 a11y 语义**（`role="tablist"` / `aria-selected`）。原实现没有，本次也没加，
  属于未改善而非回退。
- **没验证** Safari / Firefox（`-webkit-line-clamp` 只用在手机分支做两行截断；桌面分支不依赖它）
- 截图里的 12 门课是**模拟数据**（生产课程字典只有 4 门：`data_structure` / `English` /
  `SWE203-Human computer interaction` / `通用 / 其他`），用来看 12 行时的密度与节奏；
  4 门课的真实数据也单独渲染验证过，同样的布局、只是行数少。

## 6. 风险与回滚

- 风险低：只改两个文件的 CSS 和一段 JSX，无接口 / 无数据 / 无路由改动。
- 回滚：`git revert` 单个提交即可，无迁移、无 env、无缓存失效。
- 已知未修：同页「最新上传」的资料行仍是玻璃卡片，与新列表风格不统一（见 §5）。
