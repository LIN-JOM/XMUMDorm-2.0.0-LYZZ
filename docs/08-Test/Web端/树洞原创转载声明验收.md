## 复核发现与处理

1. 旧网页改动位于校园资讯投稿，不是树洞发布页，且缺少来源预设。
   本分支接入真正的 /post/new 页面，提供 WX、QQ、抖音、INS、Telegram、X、Whatsapp、自定义。
2. 旧网页方案把声明塞入正文，改变了用户内容。
   本分支复用声明接口、共享校验和迁移 076，保存独立字段；旧客户端仍可省略声明。
3. 截图复核发现图片卡片声明沿用了深色字。
   已与该卡片正文一样使用白字，并在最终构建复验。

按现有分页信息流和多用户服务检查，新增字段沿用原查询，不增加逐帖数据库往返。
客户端与接口分别校验，来源去掉首尾空格后限制为 1–100 字符，拒绝标签与内部控制字符。
复用现有网页控件和详情插槽，没有增加依赖、演示页面或新的平台配置。

## 发布边界

网站功能需要 migrations/076_post_attribution.sql 的两个 nullable 字段。
先确认目标库与备份，再执行单个迁移，随后部署接口与网站；缺列会影响读写接口。
不要为这次功能执行全部历史迁移或 init-db.sql。
回退应用时先保留新增列，避免丢失已经保存的声明；ALTER TABLE 的锁表影响需按目标数据库评估。

本轮未执行远端迁移、部署、真实账号发帖、真实图片上传或语音读屏，也没有修改或测试 App。
