## 实现与限制

- 呼吸周期分别为 4.8 秒、5.8 秒，纵向伸缩上限分别为 0.6%、1%。
- 每帧变换及透明度由 Animated 驱动；原生开启 native driver，周期衔接仍使用 JS 调度。
- 无新增依赖、网络图片或每帧 React 状态更新。
- 四张人物图常驻当前装饰层；低端设备的纹理内存峰值和帧率尚未实测。
- 用户暂无设备；浏览器预览及 Android 导出不代表 Android/iOS 真机验证完成。
- API 依据：[Expo SDK 57](https://docs.expo.dev/versions/v57.0.0/)、[RN 0.86 Animated](https://reactnative.dev/docs/0.86/animated)。
- 接触点使用 [RN 0.86 transforms](https://reactnative.dev/docs/0.86/transforms)，前后台依据 [AppState](https://reactnative.dev/docs/0.86/appstate)。
