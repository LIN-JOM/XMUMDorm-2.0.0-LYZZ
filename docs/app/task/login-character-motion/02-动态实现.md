# 人物动态与密码闭眼

## 1. 任务位置

- Phase 1 人物轻动且不干扰登录：让拆分素材在真实登录页独立轻动。
- 推进 R-1 人物自然轻动、R-2 输入时闭眼与动态开关。
- 前置：素材拆分。后续双主题回归依赖本任务。

## 2. 开发信息

先读：

- `app/src/features/auth/LoginArtwork.tsx` — 静态底图在哪里？
- `app/src/app/login.tsx` — 密码状态由谁拥有？
- `app/src/components/ui/Input.tsx` — 焦点回调如何透传？
- `app/src/design-system/theme.tsx` — 减少动态效果如何订阅？
- `app/src/__tests__/login-curve-ui.test.tsx` — 表单行为在哪里验证？

已定：只传闭眼布尔值；不增加依赖；卡片和背景保持静止。
边界与入口：登录页组件及人物组件生命周期测试；不改变认证接口。
运行：`npm.cmd test -- --runInBand --cacheDirectory .scratch/jest-preview login-curve-ui login-character-motion`；`npm.cmd run typecheck`。
未知：动画清理及矮屏卸载；通过测试证明，不依赖肉眼推断。

## 3. 工作流

1. 读取开发信息，用一句话重述实现目标。
2. 写密码焦点与生命周期失败用例，独立提交测试。
3. 接入人物呼吸、眨眼与小羊耳朵轻动。
4. 接入密码闭眼、减少动态效果及前后台停止。
5. 检查卸载清理与输入保留，运行检查并提交。

## 4. 测试用例

| 用例 | 输入 | 预期 | 入口 |
| --- | --- | --- | --- |
| 输入密码 | 聚焦后移开 | 闭眼后睁眼，值保留 | 登录页 |
| 显示密码 | 显示后移开焦点 | 保持闭眼，隐藏后恢复 | 登录页 |
| 减少动态 | 系统设置开启 | 无环境循环 | 人物组件 |
| 页面离开 | 压栈、后台、卸载 | 动画停止、监听清理 | 人物组件 |
