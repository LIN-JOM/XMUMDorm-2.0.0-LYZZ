# 连续慢动作验证

日期：2026-10-22；实现版本：33ca2f17；基线：7e6b1d75。

## 结论与原因

旧版闭合 80 毫秒、睁开 120 毫秒，并交叉渐隐整个人物，造成用户看到短暂换图。
上一版验收覆盖生命周期，没有核对实际动作时间与中间姿态，漏检了用户指出的问题。
当前修正使用固定身体底图、局部眼睛压合及独立耳部转动。

## 时间与画面

- 闭合 900 毫秒；停留 450 毫秒；睁开 1200 毫秒。
- 密码失焦后的睁开为 1100 毫秒；中途改变焦点会从当前进度继续。
- 女孩与小羊呼吸周期分别为 7.6 秒、9.2 秒；耳朵随独立小羊周期缓慢转至 −4° 后返回。
- 循环禁止逐轮复位；减少动态效果或不在前台时立即转为静止状态。

实际浏览器睁开采样：

| 距触发时间 | 眼睛开度 | 身体透明度 |
| --- | --- | --- |
| 16 毫秒 | 约 0% | 100% |
| 288 毫秒 | 16% | 100% |
| 563 毫秒 | 52% | 100% |
| 838 毫秒 | 87% | 100% |
| 1113 毫秒 | 100% | 100% |

另一次闭合采样的小羊开度依次为 96%、87%、74%、59%、43%、28%、15%、6%、0%。
同一组采样中的背景 transform 始终为 none；耳朵旋转矩阵连续变化。
采样还覆盖了女孩在睁开到约 32% 时转向闭合，没有复位到全睁状态。

局部变换先裁切眼部，再压合；不会把图中其他部分缩进眼睛区域。
深浅主题均检查了闭合端点与可见中间姿态，身体外轮廓保持同一张底图。
手与蹄的呼吸锚点、卡片低拱和玻璃边缘沿用已确认布局。
