## 2. 变化的意义

上一版的验收没有验证动作过程，不能覆盖本次用户反馈。
本轮既检查动作时间，也检查真实画面中的中间状态；身体不再参与眨眼透明度切换。
没有新增素材或依赖，原有英文表单、密码闭眼与减少动态效果继续保留。
