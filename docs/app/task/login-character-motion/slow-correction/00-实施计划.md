# 人物慢动作修正

日期：2026-10-21；基线：7e6b1d75。用户否定上一版闪帧，要求有过程的慢速动作。

## 1. 需求

- R-1 连续慢动作：闭眼与睁眼都有可见过程，不能整个人物突然换图。
- R-2 局部动作稳定：身体与卡片保持稳定，小羊耳朵缓慢摆动。
- R-3 保留现有交互：密码闭眼、减少动态效果、停止清理及双主题仍有效。

## 2. 逐项做法

### R-1 连续慢动作

- 做法：固定身体底图，只在眼睛区域连续压合与展开；取消整图透明度切换。
- 涉及：登录人物装饰。
- 测试入口：现有人物组件、真实预览的时间采样。
- 验收：闭合与睁开均不少于 700 毫秒；中间能看到半闭眼；身体始终不透明。
- 难点：局部图像与原脸部配准，避免双眼轮廓重影。

### R-2 局部动作稳定

- 做法：耳朵独立遮罩与慢速转动，呼吸延长周期。
- 涉及：本地原画的代码遮罩，不生成新角色。
- 测试入口：双主题登录预览。
- 验收：耳朵有连续角度；手、蹄接触位置稳定；背景与卡片静止。
- 难点：耳根遮罩不能留下缝隙。

### R-3 保留现有交互

- 做法：动画中断后从当前进度转向目标，减少动态效果时立即静止。
- 涉及：装饰状态与现有登录表单。
- 测试入口：既有人物生命周期、登录回归。
- 验收：密码交互保留；减少动态时静止；离开与卸载清理；双主题与回归检查通过。
- 难点：循环重启、焦点切换不能把进度重置为睁眼。

## 3. Phase 1 看得到过程的轻动效

覆盖：R-1 连续慢动作、R-2 局部动作稳定、R-3 保留现有交互。
目标：用户在真实预览中看见完整、柔和的动作。

- 建立能抓住快速换图问题的时间回归。
- 改为眼部连续运动与耳朵局部转动。
- 验证中间状态、双主题与回归，交接并验收。

证明：时间回归、预览的开始/中间/结束状态及原有登录回归。
本轮不做：新角色、实时骨骼或真机帧率结论。
