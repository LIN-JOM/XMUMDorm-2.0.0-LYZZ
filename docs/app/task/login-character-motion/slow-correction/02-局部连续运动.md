# 局部连续运动

## 1. 任务位置

- Phase 1 看得到过程的轻动效，推进 R-1 连续慢动作、R-2 局部动作稳定。
- 前置：时间回归失败。后续：完整预览与交接。

## 2. 开发信息

先读：

- `app/src/features/auth/LoginCharacters.tsx` — 哪些层在换图？
- `app/assets/brand/SOURCE.md` — 原画坐标与透明素材来源是什么？
- `app/src/__tests__/login-curve-ui.test.tsx` — 密码交互如何保留？

已定：身体固定；眼睛与耳朵局部连续运动；背景和玻璃保持静止。
边界与入口：原有人物组件与预览，不改登录会话。
运行：人物与登录测试、`npm.cmd run typecheck`、`npm.cmd run lint`。
未知：眼部区域或耳根遮罩可能露缝；预览中校正后再交付。

## 3. 工作流

1. 阅读开发信息并重述局部动作目标。
2. 用原素材建立眼部和耳部遮罩。
3. 接入慢速闭合、停留、睁开以及耳朵转动。
4. 检查动画中途焦点变化及动态降级。
5. 通过时间回归与类型检查后提交。

## 4. 测试用例

| 用例 | 输入 | 预期 | 入口 |
| --- | --- | --- | --- |
| 中间状态 | 眼睛半闭 | 身体不透明，眼部连续压合 | 人物组件、预览 |
| 耳部 | 半个呼吸周期 | 耳朵角度连续变化 | 预览 |
| 密码焦点 | 动画中切换 | 从当前状态转向目标 | 人物组件 |
