# 登录人物自然轻动效

日期：2026-10-21；版本：1。沿用已确认的双主题构图，只让人物轻动。
按 easy-plan → easy-task-act → easy-summary → easy-audit 执行，使用 Markdown。

## 1. 需求

- R-1 人物自然轻动：用户选择“自然轻动效”，女孩与小羊轻微呼吸、错开眨眼，小羊偶尔轻动耳朵。
- R-2 输入时闭眼与动态开关：承接本轮提案，输入或显示密码时闭眼，减少动态效果时停用环境动画。
- R-3 保留登录行为与双主题：沿用英文学校邮箱、低拱玻璃边缘和真实登录表单，花园与卡片保持稳定。

## 2. 逐项做法

### R-1 人物自然轻动

- 做法：从现有确认稿拆出透明人物与静态底图，使用原生变换及睁闭眼图层。
- 涉及：登录装饰，不引入动画运行库。
- 测试入口：现有登录页组件、浏览器预览。
- 验收：两个人物独立呼吸；错开眨眼；小羊耳朵轻动；背景与玻璃不跟随变换。
- 难点：图层坐标、人物手部接触点以及透明边缘不能跳动。

### R-2 输入时闭眼与动态开关

- 做法：表单只传递闭眼布尔值；主题动态设置及应用前后台控制动画生命周期。
- 涉及：登录表单、共享输入的可选焦点回调、装饰动画。
- 测试入口：现有登录页组件及人物组件生命周期测试。
- 验收：密码聚焦或显示时闭眼；移开且隐藏时睁眼；减少动态效果时静止；后台、离开页面与卸载后停止并清理。
- 难点：压栈仍挂载的页面不能继续循环，密码值不能传给装饰。

### R-3 保留登录行为与双主题

- 做法：保持现有布局与提交链路，分别使用浅绿日间和夜蓝图层。
- 涉及：登录装饰资源、窄屏预览、构建与交接。
- 测试入口：现有登录交互测试及 Android 导出。
- 验收：深浅主题均清晰；英文及提交行为通过回归；矮屏收起人物且不丢输入；类型、lint 与 Android 导出通过。
- 难点：暂无真机，不能以浏览器检查代替设备帧率和键盘验证。

## 3. Phase 1 人物轻动且不干扰登录

覆盖：R-1 人物自然轻动、R-2 输入时闭眼与动态开关、R-3 保留登录行为与双主题。

目标：现有登录页展示克制的人物动态，表单与玻璃保持稳定。

任务：

- 拆分双主题人物素材并验证对齐。
- 接入呼吸眨眼、密码闭眼与生命周期控制。
- 完成双主题预览、回归、交接与验收。

证明：组件行为测试、动态预览与 Android 导出；逐项审计上方验收项。
本轮不做：头部追踪、实时骨骼、物理毛发或真机性能结论。
