# 双主题人物素材拆分

## 1. 任务位置

- Phase 1 人物轻动且不干扰登录：先证明人物能与原画稳定叠合。
- 推进 R-1 人物自然轻动与 R-3 保留登录行为与双主题。
- 前置：确认稿已存在。后续动画接线依赖本任务。

## 2. 开发信息

先读：

- `app/assets/brand/SOURCE.md` — 确认稿来源与构图约束是什么？
- `app/src/features/auth/LoginArtwork.tsx` — 接触线如何对齐？
- `docs/app/task/login-character-motion/00-实施计划.md` — 哪些视觉行为需要证明？

已定：保持浅绿与夜蓝两套设计；用内置 imagegen 编辑，不改变角色身份与表单。
边界与入口：本地素材与现有登录页预览，不涉及登录服务。
运行：素材尺寸、alpha 与预览检查；`cd app; npm.cmd run typecheck`。
未知：生成图坐标可能漂移；发现后先修对齐，不将问题转嫁给布局。

## 3. 工作流

1. 读取开发信息，用一句话重述拆分目标。
2. 检查现有原画，生成静态底图及透明人物。
3. 生成对齐的闭眼状态，检查姿势及接触点。
4. 保存资源与完整提示词，记录实际尺寸。
5. 检查透明边缘并提交素材。

## 4. 验证用例

| 用例 | 输入 | 预期 | 入口 |
| --- | --- | --- | --- |
| 日间 | 浅色素材 | 原构图、无额外角色 | 图片检查 |
