## 3. 工作流

1. 读取开发信息，用一句话重述验证目标。
2. 预览双主题、密码闭眼及窄屏，保存证据。
3. 运行回归、类型、lint、规则与 Android 导出。
4. 用 easy-summary 写交接，再用 easy-audit 双轴验收。
5. 修复验收发现，提交推送并更新当前 PR。
