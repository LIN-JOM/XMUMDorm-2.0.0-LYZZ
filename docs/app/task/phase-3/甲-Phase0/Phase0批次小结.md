## 2. 影响

发布注册表、提交描述符和通知解析器现在只提供 Expo Router 接受的字符串路由。
原先的四个类型错误已消失，发布回跳继续按既有行为执行。
设计真源现已固定为广场、工具、发布、消息、我的，避免迁移时再猜入口归属。

原生底栏现在把发布置于中央第 3 格并保留其动作语义；消息成为第 4 个可选中目的地，`/mailbox` 仍是稳定深链。
旧校园里 Tab 已撤除，树洞与万能墙迁入广场的顶部 Tab，`/campus` 及详情深链仍回到广场栈底；既有食堂入口保留在广场内容中。
旧顶栏信箱入口默认关闭，未读数只显示在原生消息格；“我的”只读取同一真源作统计，不再提供第二个消息入口。
消息页改为使用 `TAB_BAR_HEIGHT` 这一公共常量和 `bottomMode="tabbar"`；不会再把手势区 inset 与 Tab 栏高度重复相加。

代表页没有新增平行控件：广场继续通过 `TopTabStrip` 承接树洞和万能墙；广场搜索继续使用带读屏语义的 `SearchField`；参数化发布通过 `PublishMedia` 复用 `MediaPicker`，并把二手四图禁 GIF 与树洞三图可 GIF 的差别留在描述符层。P1/P2 既有控件用例继续负责错误态、令牌和无障碍；新增守卫只锁住这些页面到唯一真源的接线。

验证：导航、消息、社区、发布、食堂和安全区关联回归共 22 套件 / 318 用例通过；共享控件及逐屏账本回归 4 套件 / 81 用例通过；`npm run rulers` 与 `npm run typecheck` 通过；lint 为 0 错误 / 309 条既有警告（未在本项重新运行）。
