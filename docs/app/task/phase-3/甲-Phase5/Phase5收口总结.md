## 2. 这意味着什么

社团现在可从广场发现、进入主页、打开活动或帖子，并从“我的社团”进入权限受控的管理页。
关注、点赞和报名不在客户端推断人数或状态，而是只展示丙 Hook 的服务器回执。
通知映射忽略后端 Web 路径，只接受三种已注册社团目标。

## 3. 仍开放

- 社团评论缺少公共评论树与输入动作的适配层，因此详情页没有评论区。
- 报名名单 XLSX 缺少原生下载、保存和分享宿主，也没有 Android、iOS 真机证据。
- App 全量 Jest 仍有既有顶栏信箱断言失败，候选包不能视为全量自动化通过。
- 根目录全量 Jest 有 1 项失败：`frontend` 缺少 `eslint-plugin-react`。
- 没有 EAS 登录、Android/iOS 真机或真实账号端到端矩阵证据。
