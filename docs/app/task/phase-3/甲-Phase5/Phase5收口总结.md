## 2. 这意味着什么

社团现在可从广场发现、进入主页、打开活动或帖子，并从“我的社团”进入权限受控的管理页。
关注、点赞和报名不在客户端推断人数或状态，而是只展示丙 Hook 的服务器回执。
通知映射忽略后端 Web 路径，只接受三种已注册社团目标。
消息作为唯一一级入口，不再让表单和校方系统页显示重复的顶栏信箱动作。
Web job 使用锁文件安装依赖，防止前端插件缺失时把源码守卫误记为通过。
评论树只接受服务端顺序和创建回执；写入失败保留草稿，且未获权限投影时不展示删除。
