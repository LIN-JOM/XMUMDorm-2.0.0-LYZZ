## 2. What the developer needs to know

**Read first**

- `docs/app/task/phase-3/丙-批次6/P3C-06-01-丙域交接与最终验收边界.md` — 已交付与未关闭边界。
- `docs/app/task/phase-3/丙-任务阻塞册.md` — 只能关闭有真实证据的编号。
- `app/src/__tests__/p3-bing-club-follow.test.tsx` — 服务端回执的既有回归。
- `app/src/__tests__/p3-bing-club-like.test.tsx` — 点赞回执的既有回归。
- `app/src/__tests__/p3-bing-club-registration.test.tsx` — 报名回执的既有回归。

**Settled**

- 只以测试、真实路由或真机记录关闭阻塞项。
- XLSX、真实账号和真机未有证据时保持未完成。
- 甲不修改丙领域模型、Hook 或服务端状态机。

**Edges and seam**

- 接触集成测试、任务阻塞册和 Phase 5 总结。
- 不扩大为发布、消息、账号或公共组件重构。

**Run**

- `npm run verify && npm run lint -- --quiet`
- `npm test -- --runInBand --silent`（仓库根目录）

**Unknowns**

- development build 与设备可用性由外部账号和硬件决定。
- 任一全量命令失败时停止移交，并把失败原样写入总账。

## 3. The workflow

1. 阅读第二部分，并复述为“证据不足的工作保持未完成”。
2. 逐条执行广场到列表到详情再返回的回归。
3. 执行社团深链、权限展示和三类服务端回执回归。
4. 运行 App 完整验证、lint 和根目录后端/共享测试。
5. 更新阻塞册，只关闭已被自动化或设备证据证明的条目。
6. 生成 Phase 5 总结，列出提交、结果、未完成项和下一步。
7. 单独提交验收记录。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 广场链路 | 广场进入二手、跑腿、指南 | 各到列表并能返回广场 | 路由与返回栈 |
| 社团深链 | 冷启动 `/clubs/activity/1` | 详情可载入或明确不可用 | Expo Router |
| 权限展示 | 两个 `canManage` 值 | 仅真值显示管理入口 | 社团主页 |
| 关注回执 | 服务端关注响应 | 人数和状态等于响应值 | `useClubFollow` |
| 未完成证据 | 缺真机或 XLSX 宿主 | 阻塞项保持未关闭 | 阻塞册 |
