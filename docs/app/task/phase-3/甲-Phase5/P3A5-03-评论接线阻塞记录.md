# P3A5-03 社团评论接线阻塞记录

日期：2026-10-11
任务：P3A5-03 社团活动与帖子详情接线

## 结论

活动与帖子详情、报名和点赞已接线。评论保持未接线。

## 已核验的事实

- `shared/api/clubs.js` 有活动与帖子的评论读取、创建和删除接口。
- `CommentThread` 只呈现已转换的评论树。
- 当前 App 没有可直接消费这两个接口的评论输入与回复适配层。

## 保持未接线的原因

直接把原始服务端评论行塞进 `CommentThread` 会绕过作者、删除和回复动作的适配。
这会新增一套域内评论呈现逻辑，不符合 P3A5-03 的公共组件边界。

## 影响

详情页会显示服务器确认的点赞与报名状态，但不会显示或写入评论。

## 恢复条件

公共评论适配层能够接收社团评论树，并提供创建、回复和删除动作的统一入口。
