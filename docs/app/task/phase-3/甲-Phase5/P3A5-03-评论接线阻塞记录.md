# P3A5-03 社团评论接线阻塞记录

日期：2026-10-11
任务：P3A5-03 社团活动与帖子详情接线

## 当前结论

活动和帖子详情已经接入评论读取、创建和一级回复。
删除入口仍不显示，直到读取契约下发每条评论的删除权限。

## 已核验的事实

- `shared/api/clubs.js` 有活动与帖子的评论读取、创建和删除接口。
- `CommentThread` 只呈现已转换的评论树。
- `P3A5-07` 新增社团域适配层，复用 `CommentThread`、`CommentComposer` 和 `DetailScreen`。
- 创建成功只追加服务端回执，不在客户端虚增详情评论数。

## 已解决的阻塞

原始服务端行现在会被严格转换为公共评论节点。
活动与帖子共用同一社团域 Hook，因此没有复制评论 UI 或跨域状态 Hook。

## 仍开放

- 评论读取响应没有每条评论的 `canDelete` 字段。
- 会话只提供字符串标识，不能可靠比对服务端数值 `user_id`。
- 因此 App 不显示删除动作，避免把“点了再失败”当作权限控制。

## 恢复条件

服务端在评论读取响应提供 `viewer.canDelete` 后，可在现有公共线程上传入删除动作。
