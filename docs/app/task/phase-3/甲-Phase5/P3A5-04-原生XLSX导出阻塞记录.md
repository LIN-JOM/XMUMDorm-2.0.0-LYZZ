# P3A5-04 原生 XLSX 导出阻塞记录

日期：2026-10-11  
任务：P3A5-04 社团我的与管理入口接线

## 结论

报名名单的服务端 XLSX 接口已存在。App 原生下载、保存和分享保持未接线。

## 已核验的事实

- `shared/api/clubs.js` 提供 `exportClubActivityRegistrations(id)`。
- 服务端返回受权限保护的 XLSX 二进制与文件名。
- App 没有经验证的原生下载、文件保存和分享宿主。

## 保持未接线的原因

没有 Android 与 iOS 真机文件宿主证据时，不能把浏览器下载或空按钮称为导出完成。

## 影响

管理员可管理成员、活动和帖子，但不能从 App 获取报名名单文件。

## 恢复条件

受控的原生下载、保存和分享宿主可用，并分别提供 Android 与 iOS 真机证据。
