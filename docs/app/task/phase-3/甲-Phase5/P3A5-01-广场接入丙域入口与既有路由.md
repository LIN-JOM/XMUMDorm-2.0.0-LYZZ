# P3A5-01 广场接入丙域入口与既有路由

## 1. Where this task sits

- **甲 Phase 5 总集成进入上线收口**的目标是把已验收领域能力接入可验证 App 路径。
- **P3A5-01 广场接入丙域入口与既有路由**让广场进入二手、跑腿和指南，不重复树洞与万能墙入口。
- **开始前**：丙交付已合入且领域测试通过。**等待它**：社团发现路由完成后才展示社团入口。

## 2. What the developer needs to know

**Read first**

- `app/src/app/(tabs)/index.tsx` — 广场动作格的唯一注册点在哪里。
- `app/src/app/market/index.tsx` — 二手列表的已存在路径和导出方式。
- `app/src/app/errand/index.tsx` — 跑腿列表的已存在路径和导出方式。
- `app/src/app/guides/index.tsx` — 指南列表的已存在路径和导出方式。
- `docs/app/task/phase-3/丙-批次0/交付-P3C-00-01-广场入口与路由接线清单.md` — 哪些入口由甲接线。

**Settled**

- 广场只展示已经存在的路由。
- 树洞与万能墙已由 `CampusListScreen` 承接。
- 标签复用已有双语键；本任务不新增领域页。

**Edges and seam**

- 接触 `SquareScreen` 的 `QuickActionGrid` 和已有 Expo Router 路径。
- 不改丙的列表、详情、API、模型或状态 Hook。

**Run**

- `npm run test:ci -- --runInBand <新增广场测试> --silent`
- `npm run typecheck && npm run lint -- --quiet`

**Unknowns**

- 图标必须来自项目已安装且已验证的 Lucide 导出。
- 若任一路径不能从广场到达详情并返回，停止并记录路由缺口。

## 3. The workflow

1. 阅读本简报的第二部分，并复述为“广场只链接已存在的丙域列表”。
2. 为二手、跑腿和指南写失败的广场动作测试。
3. 在广场动作注册表加入三项，复用现有双语键和已安装图标。
4. 运行测试，确认动作分别推入三个既有列表路径。
5. 人工检查树洞、万能墙仍由顶部页签承接，没有重复动作。
6. 运行本任务命令并单独提交。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 二手入口 | 点击二手动作 | 路由为 `/market` | `SquareScreen` |
| 跑腿入口 | 点击跑腿动作 | 路由为 `/errand` | `SquareScreen` |
| 指南入口 | 点击指南动作 | 路由为 `/guides` | `SquareScreen` |
| 已有社区 | 打开广场 | 仍渲染 `CampusListScreen` | `SquareScreen` |
