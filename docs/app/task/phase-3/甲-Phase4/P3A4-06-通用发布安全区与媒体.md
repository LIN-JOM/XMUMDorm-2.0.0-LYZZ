# P3A4-06 通用发布安全区与媒体

## 1. Where this task sits

- **甲 Phase 4 我的、发布与账号形成闭环**保证三类通用发布可完成。
- **P3A4-06 通用发布安全区与媒体**核对表单宿主和媒体限制。
- **开始前**：描述器和表单宿主存在。**等待它**：真实设备媒体验证。

## 2. What the developer needs to know

**Read first**

- `app/src/features/publish/PublishFormHost.tsx` — 表单宿主和提交区。
- `app/src/features/publish/usePublishForm.ts` — 提交与错误映射。
- `app/src/features/publish/PublishMedia.tsx` — 图片字段渲染。
- `app/src/features/marketplace/publishFields.ts` — 二手描述器。
- `app/src/features/errand/publishFields.ts` — 跑腿描述器。

**Settled**

- 所有通用发布沿用参数化宿主。
- 媒体选择不绕过每个描述器的数量和格式验证。
- 不新增发布路由。

**Edges and seam**

- 触及表单宿主或描述器。
- 留下系统相册权限和真机选图证据。

**Run**

- `npm run test:ci -- --runInBand p2x-bing-publish-host p2x-bing-wall-publish --silent`
- `npm run typecheck && npm run lint -- --quiet`

**Unknowns**

- 若安全区问题只在真机可复现，保留自动化基线并登记真机证据。

## 3. The workflow

1. 阅读第二部分，并复述为“所有发布都经过同一宿主”。
2. 为底部提交、媒体约束和失败保留输入写失败测试。
3. 在唯一宿主修正共性问题。
4. 确认三个描述器仍各自验证字段。
5. 回归发布宿主和类型检查。
6. 提交测试与实现。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 长表单 | 多字段 | 提交操作仍可达 | 表单宿主 |
| 图片超限 | 超过域上限 | 不发送请求 | 描述器 |
| 提交失败 | 网络错误 | 保留表单输入 | 发布表单 |
| 成功提交 | 有效回执 | 只按回执跳转 | 发布表单 |
