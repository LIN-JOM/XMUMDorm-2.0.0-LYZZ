# P3A4-02 个人内容页签

## 1. Where this task sits

- **甲 Phase 4 我的、发布与账号形成闭环**让用户查看自己留下的内容。
- **P3A4-02 个人内容页签**核对树洞、二手、跑腿和食堂点评分类。
- **开始前**：个人内容页路由存在。**等待它**：个人页入口稳定。

## 2. What the developer needs to know

**Read first**

- `app/src/features/me/PostsScreen.tsx` — 当前内容页的分类和加载边界。
- `app/src/features/me/posts.ts` — 服务端内容适配。
- `app/src/app/me/posts.tsx` — 路由参数来源。
- `shared/api/users.js` — 可读取的个人内容端点。
- `app/src/__tests__/p2c-04-posts.test.tsx` — 已有列表回归。

**Settled**

- 四类内容使用服务端已支持的真实类型。
- 不能用空白页假装未交付类型。
- 页签复用公共 `TopTabStrip`。

**Edges and seam**

- 触及个人内容适配和屏幕。
- 不改各域详情页或删除接口。

**Run**

- `npm run test:ci -- --runInBand p2c-04-posts --silent`
- `npm run typecheck && npm run lint -- --quiet`

**Unknowns**

- 若服务端不支持其中一个分类，停止实现并记录契约缺口。

## 3. The workflow

1. 阅读第二部分，并复述为“四类页签只展示真实可读内容”。
2. 为四类选择和空列表写失败测试。
3. 将服务端类型映射到已注册的页签。
4. 保留切换后的加载和错误状态。
5. 回归列表和类型检查。
6. 提交测试与实现。
