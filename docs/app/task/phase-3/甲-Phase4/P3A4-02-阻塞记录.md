# P3A4-02 个人内容页签：契约与收口记录

日期：2026-10-12
状态：已完成；四类个人内容均使用真实归属读取路径。

## 已确认

- 帖子继续使用 `GET /api/users/:id/profile`，先由登录态取得自己的用户 ID。
- 二手使用 `GET /api/marketplace/me/items`，服务端按 `seller_user_id` 过滤并排除软删除行。
- 跑腿使用 `GET /api/errands/me`，服务端按 `owner_user_id` 过滤并返回分页事实。
- 食堂点评复用 `GET /api/canteen/my-reviews`，App 适配器校验并归一化真实点评行。

## App 接线

`PostsScreen` 复用既有 `TopTabStrip` 和 `ListScreen`，提供帖子、二手、跑腿、点评四个页签。
每个页签都有独立分页、刷新、空态和错误重试；详情跳转只使用已有路由。
客户端不从公开列表反向筛选，也不把服务端缺行伪装为空态。
