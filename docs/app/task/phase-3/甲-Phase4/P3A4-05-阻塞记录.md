# P3A4-05 话题与媒体统一面板：阻塞记录

日期：2026-10-12
状态：完成；原阻塞已由 P3A3-04 关闭。

## 已确认

- `resolveDescriptor.tsx` 为树洞读取真实标签，并以标签 `id` 作为提交值。
- `PublishMedia.tsx` 是树洞和二手的唯一图片选择呈现。
- `GET /api/posts/tags` 支持 `q` 和 `limit` 参数化服务端搜索。
- `POST /api/posts/tags` 保留登录验证，允许登录用户创建双语话题并立即公开。

## 当前交付

App 通过公共发布宿主搜索真实远程话题。
创建成功后，回执 ID 会选中并进入 `tagIds`。
创建失败会保留输入，重复点击只发送一次请求。
树洞与二手媒体选择继续复用 `PublishMedia`。
