# P3A4-05 话题与媒体统一面板：阻塞记录

日期：2026-10-11  
状态：部分完成；远程话题创建等待服务端能力。

## 已确认

- `resolveDescriptor.tsx` 为树洞读取真实标签，并以标签 `id` 作为提交值。
- `PublishMedia.tsx` 是树洞和二手的唯一图片选择呈现。
- `routes/posts.js` 的 `POST /api/posts/tags` 仍只允许管理员。
- 普通发布者没有服务端 `canCreatePostTag` 能力字段。

## 当前交付

App 不会把本地已加载标签筛选称为远程搜索。
普通用户不看到会稳定返回 403 的创建话题入口。
树洞与二手媒体选择继续复用 `PublishMedia`。

## 恢复条件

服务端需要提供可创建人的能力字段、远程搜索契约、双语输入要求、slug 规则和创建回执。
届时新任务卡必须覆盖防抖、创建锁、失败保留输入与只按回执追加选项。
