# P3A4-07 条款版本提交门禁

## 1. Where this task sits

- **甲 Phase 4 我的、发布与账号形成闭环**要求未知或未接受条款时拒绝发布。
- **P3A4-07 条款版本提交门禁**使条款真源缺失时 fail closed。
- **开始前**：服务端条款状态和接受端点存在。**等待它**：法务正文变更。

## 2. What the developer needs to know

**Read first**

- `app/src/features/publish/complianceGate.ts` — 当前门禁和缺失源分支。
- `app/src/features/publish/useViewer.ts` — 条款状态读取。
- `shared/api/users.js` — 状态与接受端点。
- `routes/users.js` — 当前版本回执。
- `app/src/__tests__/p2a-04-publish-host.test.tsx` — 宿主门禁回归。

**Settled**

- 服务端明确 `true` 才允许提交。
- `false` 与缺失都跳转条款页。
- 条款可见性不影响发布入口可见性。

**Edges and seam**

- 触及 `complianceGate`、条款页和测试。
- 不改法务正文或服务端版本生成。

**Run**

- `npm run test:ci -- --runInBand p2a-04-publish-host p2a-02-viewer --silent`
- `npm run typecheck && npm run lint -- --quiet`

**Unknowns**

- 若条款页不能完成接受并刷新状态，停止并记录端点/页面接线缺口。

## 3. The workflow

1. 阅读第二部分，并复述为“只有明确接受才可提交”。
2. 为条款状态缺失写失败测试。
3. 在共享门禁将缺失分支改为拒绝。
4. 检查提示和修复入口指向条款页。
5. 回归 viewer、表单宿主和类型检查。
6. 提交测试与实现。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 已接受 | `acceptedTerms:true` | 可提交 | 条款门禁 |
| 未接受 | `acceptedTerms:false` | 阻止并给出条款入口 | 条款门禁 |
| 状态缺失 | `acceptedTerms:undefined` | 阻止并给出条款入口 | 条款门禁 |
| 服务端拒绝 | `TERMS_NOT_ACCEPTED` | 表单跳转条款页 | 提交错误映射 |
