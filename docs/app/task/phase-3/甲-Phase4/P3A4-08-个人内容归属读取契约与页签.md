# P3A4-08 个人内容归属读取契约与页签

## 1. Where this task sits

- 甲 Phase 4 要求“我的”展示用户发布的树洞、二手、跑腿和食堂点评。
- 既有 P3A4-02 只完成了真实帖子路径；复核发现食堂点评已有 `GET /api/canteen/my-reviews`，二手和跑腿数据表也已有明确归属字段，但缺少用户列表端点。
- 本任务补齐最小归属读取契约，再把四类真实数据接入同一顶部滑动 Tab 条。

## 2. What the developer needs to know

**Read first**

- `docs/app/task/phase-3/甲-Phase4/P3A4-02-个人内容页签.md`
- `app/src/features/me/PostsScreen.tsx`
- `routes/marketplace.js`
- `routes/errands.js`
- `routes/canteen.js` 的 `/my-reviews`
- `app/src/components/ui/TopTabStrip.tsx`

**Settled**

- 只显示服务端归属读取的真实内容；不从公开列表反向筛选。
- 二手使用 `seller_user_id`，跑腿使用 `owner_user_id`，食堂点评使用 `product_comments.user_id`。
- 四类页签共用 `TopTabStrip`，每类使用 `ListScreen` 的加载、空态、错误态和分页状态。
- 不改各域详情页、发布状态机或删除权限。

**Scope fence**

- 新增两个只读登录端点：`GET /api/marketplace/me/items`、`GET /api/errands/me`。
- 复用已有 `GET /api/canteen/my-reviews`，不重复建端点。
- App 只新增归属列表适配和页签；不新增原生工程或依赖。

## 3. Acceptance

- 未登录请求返回 401。
- 每个端点只返回当前用户的内容，删除/不可见内容不伪装成空成功。
- 分页响应包含 `page`、`pageSize`、`hasMore`，限制值在服务端有界并内联 SQL。
- App 四个 Tab 都请求各自真实端点，空结果显示业务空态，失败显示可重试错误态。
- 既有“我的帖子”删除和两步取数回归保持通过。

## 4. Verification

- 先写路由和归一化失败测试，再实现端点与页面。
- `npm test -- --runInBand --silent`。
- `cd app; npm run typecheck; npm run test:ci -- --runInBand p3a4-my-content p2c-04-posts --silent; npm run lint -- --quiet`。

## 5. Known boundary

- 本任务只提供读取契约；详情编辑、删除和媒体上传继续使用各域已有能力。
- Android/iOS 真机证据仍属于 P3A2-04/P3A5-04 的外部阻塞，不在本任务内伪造关闭。
