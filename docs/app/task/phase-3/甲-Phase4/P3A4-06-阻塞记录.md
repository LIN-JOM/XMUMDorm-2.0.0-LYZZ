# P3A4-06 通用发布安全区与媒体：阻塞记录

日期：2026-10-11  
状态：表单宿主已统一；跑腿媒体等待端点。

## 已确认

- `PublishFormHost.tsx` 使用唯一 `Form` 宿主，其安全区和底部提交区由 `Screen` 处理。
- 树洞最多 3 张图片，二手最多 4 张图片，均经 `PublishMedia` 与各自描述器校验。
- `createErrandPublishDescriptor` 没有 `mediaFields`。
- `shared/api/errands.js` 的创建请求没有图片上传参数。

## 不能补造的部分

跑腿增加本地媒体控件而服务端没有接收、存储与返回契约，会制造用户可选但永远不会保存的假功能。

## 恢复条件

服务端需要定义跑腿图片的文件字段、数量和格式限制、上传失败语义及详情读取回执。
有该契约后，再让跑腿描述器接入已有 `PublishMedia`；不新建第二个选图组件。
