# P3A4-04 退出与软删除回执

## 1. Where this task sits

- **甲 Phase 4 我的、发布与账号形成闭环**让用户安全退出或软删除账号。
- **P3A4-04 退出与软删除回执**核对回执、跳转和本地私有数据清理。
- **开始前**：鉴权中间件已拒绝停用令牌。**等待它**：真实账号验收。

## 2. What the developer needs to know

**Read first**

- `app/src/features/me/SettingsScreen.tsx` — 退出和删除账户动作。
- `app/src/features/auth/tokenStore.ts` — 令牌清理。
- `app/src/features/auth/handleAuthFailure.ts` — 统一失效处理。
- `shared/api/users.js` — 软删除端点与回执。
- `app/src/__tests__/p2c-05-settings-legal.test.tsx` — 设置页回归。

**Settled**

- 软删除成功后清理令牌和私有缓存。
- 停用令牌由共享鉴权中间件拒绝。
- 不编造恢复或数据保留政策。

**Edges and seam**

- 触及设置动作和会话清理入口。
- 留下服务端软删除数据保留策略。

**Run**

- `npm run test:ci -- --runInBand p2c-05-settings-legal --silent`
- `npm run typecheck && npm run lint -- --quiet`

**Unknowns**

- 若删除接口没有可验证成功回执，停止 UI 成功态实现并记录缺口。

## 3. The workflow

1. 阅读第二部分，并复述为“清理在共享会话边界完成一次”。
2. 为成功、失败和停用回执写失败测试。
3. 让设置动作只接受真实成功回执。
4. 成功后走统一私有状态清理与登录跳转。
5. 回归设置、鉴权和类型检查。
6. 提交测试与实现。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 退出 | 确认退出 | 清除会话并回登录 | 设置动作 |
| 软删除成功 | 有效回执 | 清除私有状态 | 设置动作 |
| 删除失败 | 网络错误 | 保留会话并显示失败 | 设置动作 |
| 停用令牌 | 403 回执 | 统一清理并回登录 | 鉴权失败处理 |
