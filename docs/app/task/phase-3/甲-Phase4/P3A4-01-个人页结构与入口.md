# P3A4-01 个人页结构与入口

## 1. Where this task sits

- **甲 Phase 4 我的、发布与账号形成闭环**让已登录用户管理资料和设置。
- **P3A4-01 个人页结构与入口**核对个人页的身份、内容和管理入口。
- **开始前**：既有 `MeScreen` 可加载。**等待它**：资料和内容页接线。

## 2. What the developer needs to know

**Read first**

- `app/src/features/me/MeScreen.tsx` — 个人页当前的区块和入口。
- `app/src/features/me/dashboard.ts` — 摘要数据是否仍被展示。
- `app/src/app/me/edit.tsx` — 编辑资料的真实路由。
- `app/src/app/me/settings.tsx` — 设置的真实路由。
- `app/src/__tests__/p2c-03-me.test.tsx` — 已有个人页不变量。

**Settled**

- 个人页只保留身份、内容和管理入口。
- 编辑资料与设置从已注册路由进入。
- 不新增个人页数据源。

**Edges and seam**

- 触及 `MeScreen` 与其测试。
- 留下待办、课表和通知的数据加载逻辑。

**Run**

- `npm run test:ci -- --runInBand p2c-03-me --silent`
- `npm run typecheck && npm run lint -- --quiet`

**Unknowns**

- 若计划所称“三块摘要”已不存在，记录证据后不作装饰性重写。

## 3. The workflow

1. 阅读第二部分，并复述为“只移除已废弃结构，不改数据真源”。
2. 在既有个人页 seam 写出入口和不展示废弃摘要的失败测试。
3. 仅移除或重排测试指出的旧结构。
4. 确认两个入口都指向现有 App 路由。
5. 回归个人页和类型检查。
6. 提交测试与实现。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 编辑入口 | 已登录资料 | 打开 `/me/edit` | `MeScreen` |
| 设置入口 | 已登录资料 | 打开 `/me/settings` | `MeScreen` |
| 旧摘要 | 三项摘要数据 | 不显示废弃摘要区 | `MeScreen` |
| 数据失败 | 单区请求失败 | 其他入口仍可用 | `MeScreen` |
