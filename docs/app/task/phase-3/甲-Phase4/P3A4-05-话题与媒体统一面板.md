# P3A4-05 话题与媒体统一面板

## 1. Where this task sits

- **甲 Phase 4 我的、发布与账号形成闭环**统一通用发布的输入体验。
- **P3A4-05 话题与媒体统一面板**复用已存在的远程选项和媒体入口。
- **开始前**：三类发布描述器已接入。**等待它**：服务端话题创建能力。

## 2. What the developer needs to know

**Read first**

- `app/src/features/publish/resolveDescriptor.tsx` — 话题选项的远程读取。
- `app/src/features/publish/PublishMedia.tsx` — 唯一媒体入口。
- `app/src/components/ui/MultiSelect.tsx` — 多选行为和上限。
- `app/src/features/campus/postPublishFields.ts` — 树洞图片字段。
- `docs/app/task/phase-3/甲-Phase3/P3A3-04-阻塞记录.md` — 创建话题前置。

**Settled**

- 已加载标签可筛选，但不能称为远程搜索。
- 普通用户不显示没有服务端能力支持的创建入口。
- 三类发布复用 `PublishMedia`。

**Edges and seam**

- 触及参数化描述器和公共控件。
- 不改标签创建 API 或虚构管理员判断。

**Run**

- `npm run test:ci -- --runInBand p2x-bing-publish-contract p3a-05-shared-controls --silent`
- `npm run typecheck && npm run lint -- --quiet`

**Unknowns**

- 若服务端仍未提供非管理员话题创建能力，本任务只收口统一面板，不实现创建。

## 3. The workflow

1. 阅读第二部分，并复述为“只复用真源，不伪造远程能力”。
2. 为共用媒体入口和本地标签筛选写失败测试。
3. 收敛描述器中重复的呈现代码。
4. 保留服务端 id 作为提交值。
5. 回归发布契约和类型检查。
6. 提交测试与实现。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 已加载标签 | 输入关键词 | 只筛选已加载项 | 选项控件 |
| 标签提交 | 选择标签 id | 提交真实 id | 发布描述器 |
| 三类媒体 | 三个描述器 | 都使用 `PublishMedia` | 描述器 |
| 创建缺失 | 普通用户 | 不显示创建入口 | 发布描述器 |
