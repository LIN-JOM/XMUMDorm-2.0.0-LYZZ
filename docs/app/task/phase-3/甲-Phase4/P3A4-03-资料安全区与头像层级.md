# P3A4-03 资料安全区与头像层级

## 1. Where this task sits

- **甲 Phase 4 我的、发布与账号形成闭环**让资料修改在移动端可读可提交。
- **P3A4-03 资料安全区与头像层级**核对头像、字段和底部安全区。
- **开始前**：编辑资料表单存在。**等待它**：账号生命周期验收。

## 2. What the developer needs to know

**Read first**

- `app/src/features/me/EditProfileScreen.tsx` — 头像和字段的现有结构。
- `app/src/features/me/profile.ts` — 提交字段与验证。
- `app/src/components/ui/MediaPicker.tsx` — 头像选择的公共边界。
- `app/src/components/ui/Screen.tsx` — 安全区和底部操作区。
- `app/src/__tests__/p2c-06-edit-profile.test.tsx` — 表单与选图回归。

**Settled**

- 头像使用已有 `MediaPicker`。
- 字段层级不改变服务端资料契约。
- 不创建第二个图片选择器。

**Edges and seam**

- 触及编辑资料屏幕和测试。
- 留下用户资料 API、媒体上传协议和全局安全区策略。

**Run**

- `npm run test:ci -- --runInBand p2c-06-edit-profile --silent`
- `npm run typecheck && npm run lint -- --quiet`

**Unknowns**

- 若现有安全区宿主已覆盖提交区，保留并记录，不加重复 padding。

## 3. The workflow

1. 阅读第二部分，并复述为“头像优先，字段不改真源”。
2. 为头像前置和提交区可见写失败测试。
3. 仅调整屏幕层级或安全区配置。
4. 确认离开确认和图片限制仍有效。
5. 回归编辑资料和类型检查。
6. 提交测试与实现。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 初始资料 | 有头像 | 头像在字段前 | 编辑资料屏幕 |
| 无头像 | 空头像 | 显示选择入口 | 编辑资料屏幕 |
| 底部提交 | 长表单 | 提交操作仍可见 | `Screen` |
| 超限图片 | 超过大小 | 保留验证错误 | `MediaPicker` |
