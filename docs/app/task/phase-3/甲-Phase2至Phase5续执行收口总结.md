## 2. 这意味着什么

树洞发布不再把预加载话题误作远程搜索。新话题只能由登录用户创建，且 App 只保存服务端回执的 ID。
社团、万能墙和发布宿主继续复用既有公共机制，没有新增第二套表单或本地话题真源。

## 3. 仍开放

- 课表与 Moodle 提醒已接统一 scheduler；仍没有 Android/iOS 真机证据证明通知送达。
- Android 与 iOS 真机仍未验证通知、媒体手势和 XLSX 保存／分享。
- 跑腿图片仍缺服务端上传、存储和详情读取契约。
- 法务正文、EAS 登录和真实账号矩阵仍未具备，候选包不能进入正式上线流程。
