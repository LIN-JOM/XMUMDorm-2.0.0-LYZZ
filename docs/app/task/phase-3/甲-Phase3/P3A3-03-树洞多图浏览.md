# P3A3-03 树洞多图浏览

## 1. Where this task sits

- **甲 Phase 3 社区与社团交付安全并入 App**需要一个公共多图浏览能力。
- **P3A3-03 树洞多图浏览**在列表和详情提供横滑、页码和读屏替代文本。
- **开始前**：图片数组契约已存在。**等待它**：树洞页面消费新组件。

## 2. What the developer needs to know

**Read first**

- `app/src/components/ui/MediaGrid.tsx` — 当前静态网格与 hero 边界。
- `app/src/features/campus/CampusScreens.tsx` — 树洞图片消费者。
- `app/src/components/ui/ListScreen.tsx` — 列表手势和性能约束。
- `app/src/__tests__/p2x-bing-campus.test.tsx` — 已有树洞回归。

**Settled**

- 单图继续使用既有呈现。
- 多图横滑有当前项提示和替代文本。
- 横滑不能触发列表误滚。

**Edges and seam**

- 新增公共浏览呈现并由树洞消费。
- 不重写上传或后端媒体契约。

**Run**

- `npm run test:ci -- --runInBand p2x-bing-campus --silent`
- `npm run typecheck && npm run lint -- --quiet`

**Unknowns**

- 图片替代文本来源不足时必须标记装饰。
- 手势冲突无法复现时保留真机验证项。

## 3. The workflow

1. 阅读第二部分，并复述为“多图浏览不复制第二套媒体层”。
2. 为 1、2、3、4+ 图写失败测试。
3. 在公共媒体层加入水平分页呈现。
4. 接入树洞列表和详情的多图数据。
5. 验证读屏和页码状态。
6. 运行命令并提交。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 单图 | 1 个 URL | 使用既有单图呈现 | 媒体层 |
| 双图 | 2 个 URL | 可滑到第 2 张 | 媒体层 |
| 多图 | 4 个 URL | 显示当前页状态 | 媒体层 |
| 无替代文本 | 缺少描述 | 图片不制造读屏噪音 | 媒体层 |
