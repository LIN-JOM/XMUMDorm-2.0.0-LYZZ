# P3A3-04 发布远程话题选择

## 1. Where this task sits

- **甲 Phase 3 社区与社团交付安全并入 App**要求发布宿主能搜索和创建真实话题。
- **P3A3-04 发布远程话题选择**为树洞发布提供远程搜索、创建和失败反馈。
- **开始前**：后端 `POST /api/posts/tags` 可用。**等待它**：发布页面接入。

## 2. What the developer needs to know

**Read first**

- `app/src/components/ui/MultiSelect.tsx` — 预加载选项的当前能力。
- `shared/api/posts.js` — 标签读取和创建契约。
- `app/src/features/publish/usePublishForm.ts` — 提交锁和错误口径。
- `app/src/app/publish/[type].tsx` — 参数化表单宿主。

**Settled**

- 搜索防抖，创建成功后立即选中。
- 网络失败不显示假成功。
- 远程状态收在公共发布宿主。

**Edges and seam**

- 接触发布选择器和树洞字段描述符。
- 不新增第二个表单或本地话题真源。

**Run**

- `npm run test:ci -- --runInBand publish-options --silent`
- `npm run typecheck && npm run lint -- --quiet`

**Unknowns**

- 创建接口的返回 ID 与名称必须匹配选择器模型。
- 若后端不返回创建结果，停止并记录契约缺口。

## 3. The workflow

1. 阅读第二部分，并复述为“选择成功以服务端回执为准”。
2. 为搜索、创建、失败和重复点击写失败测试。
3. 在公共选择器建立防抖请求和锁。
4. 将创建回执写入已选项。
5. 接入树洞发布描述符。
6. 运行命令并提交。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 搜索 | 输入关键词 | 显示服务端选项 | 远程选择器 |
| 创建 | 新名称回执 | 新话题被选中 | 远程选择器 |
| 失败 | 网络错误 | 显示失败，不选中 | 远程选择器 |
| 连击 | 两次创建点击 | 只发送一次请求 | 提交锁 |
