# P3A3-02 动态指南页签

## 1. Where this task sits

- **甲 Phase 3 社区与社团交付安全并入 App**要求指南分类消费后端真源。
- **P3A3-02 动态指南页签**让二级导航显示接口返回分类和稳定的“全部”。
- **开始前**：指南分类 API 可用。**等待它**：指南列表接线回归。

## 2. What the developer needs to know

**Read first**

- `shared/api/handbook.js` — 分类和文章请求的真实字段。
- `app/src/features/guides/GuidesScreens.tsx` — 当前指南筛选状态。
- `app/src/components/ui/TopTabStrip.tsx` — 静态 `MessageKey` 的限制。
- `app/src/i18n/zh.ts` — “全部”稳定词条的来源。

**Settled**

- “全部”保持本地词条。
- 动态标签只来自后端，并有安全读屏文案。
- 空分类不渲染空导航条。

**Edges and seam**

- 扩展公共二级导航的数据形状与指南消费者。
- 不把后端文本塞入静态 i18n 类型。

**Run**

- `npm run test:ci -- --runInBand p2x-bing-guides --silent`
- `npm run typecheck && npm run lint -- --quiet`

**Unknowns**

- 分类 ID 与显示名的服务端字段必须先确认。
- 若类别无稳定 ID，停止并记录契约缺口。

## 3. The workflow

1. 阅读第二部分，并复述为“动态标签不伪装成词条键”。
2. 为动态、空和长分类写失败测试。
3. 扩展公共 Tab 以接受安全标签。
4. 保留“全部”为现有词条。
5. 接入指南请求参数并回归列表。
6. 运行命令并提交。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 动态分类 | API 返回分类 | 标签可选择 | 指南 Tab |
| 全部 | 首次打开 | 使用本地“全部” | 指南 Tab |
| 空分类 | API 空数组 | 不显示空条 | `TopTabStrip` |
| 长名称 | 超长分类名 | 横滚可达 | `TopTabStrip` |
