# P3A3-01 公共双行筛选条

## 1. Where this task sits

- **甲 Phase 3 社区与社团交付安全并入 App**先补齐多消费者共用的筛选呈现。
- **P3A3-01 公共双行筛选条**替代二手和跑腿需要的单选、横滚、双行文字下划线筛选。
- **开始前**：丙已确认两个消费者。**等待它**：二手和跑腿页面接入。

## 2. What the developer needs to know

**Read first**

- `app/src/components/ui/FilterChips.tsx` — 当前多选筛选的边界。
- `app/src/components/ui/TopTabStrip.tsx` — 导航 Tab 不能被筛选复用。
- `app/src/features/marketplace/MarketScreens.tsx` — 二手类别状态的消费者。
- `app/src/features/errand/ErrandScreens.tsx` — 跑腿类型和状态的消费者。

**Settled**

- 新控件单选，不冒充二级导航。
- 超出宽度横向滚动，激活态使用品牌粗下划线。
- 业务请求参数仍由各领域维护。

**Edges and seam**

- 接触一个公共组件及二手、跑腿两个消费者。
- 不改 API 或复制两份领域控件。

**Run**

- `npm run test:ci -- --runInBand p2x-bing-market-errand-*-ui --silent`
- `npm run typecheck && npm run lint -- --quiet`

**Unknowns**

- 长标签在最大字号下的高度策略必须保留可点击区域。
- 若产品要求与现有分类语义冲突，停止并记录。

## 3. The workflow

1. 阅读第二部分，并复述为“筛选不是导航”。
2. 为单选、两行和横滚写失败组件测试。
3. 新建最薄公共控件，不复制 `TopTabStrip`。
4. 将二手类别和跑腿类型接入该控件。
5. 验证请求参数仍由两个领域状态发出。
6. 运行命令并提交。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 单选 | 连续点两项 | 只有后一项激活 | 公共控件 |
| 长标签 | 两行文本 | 文字可读且可点 | 公共控件 |
| 二手 | 切换书籍 | 请求带 `category=books` | 二手列表 |
| 跑腿 | 切换取送 | 请求带 `type=delivery` | 跑腿列表 |
