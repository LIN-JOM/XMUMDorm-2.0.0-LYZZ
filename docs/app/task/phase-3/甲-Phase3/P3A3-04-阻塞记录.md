## 已交付契约

| 位置 | 当前事实 | 保障 |
|---|---|---|
| `GET /api/posts/tags` | `q` 与 `limit` 走参数化服务端查询 | App 不把本地全量过滤说成远程搜索 |
| `POST /api/posts/tags` | 保留 `authenticateToken`，不再要求管理员 | 登录用户创建后立即公开 |
| 创建回执 | 返回 `id`、`slug`、`name_zh`、`name_en` | App 只选中服务端确认的话题 |
| `PostTopicPicker` | 300ms 防抖、失败保留输入、创建锁 | 不假报成功，不重复创建 |
| 删除与可见性管理 | 继续由管理员端点控制 | 本任务未放宽管理权限 |
