## 不能提前接线的原因

丙只交付了 `createClubActivity` 与社团领域模型、Hook。
它没有交付可消费的 `clubActivity` 发布描述器。
当前通知的目标路径来自 Web，不能直接作为 Expo Router 路径推入。
在社团路由出现前生成 App 深链会产生可点死链。

## 恢复条件

1. Phase 5 注册社团发现、主页、活动和帖子详情路由。
2. 社团活动发布方交付包含选社团、字段、媒体和回执验证的描述器。
3. 服务端通知目标提供稳定的社团目标类型与 id，或明确的 App 路径契约。
4. 以上条件满足后，新建后续任务卡，覆盖路由映射、普通用户隐藏、管理员可用、失效目标和网络失败。

## 已有安全行为

普通用户不会看到社团活动发布入口。
无法解析的通知不会被伪装成可达链接。
