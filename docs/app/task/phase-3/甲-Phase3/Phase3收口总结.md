# 甲 Phase 3 社区与社团交付安全并入 App：收口总结

窗口：2026-10-10 至 2026-10-11  
基线：`docs/app/task/Phase3开发计划-甲.md` 的甲 Phase 3。

## 1. 摘要

**本阶段将社区的筛选、指南、媒体和举报接入既有公共机制；社团发布与通知深链保留真实前置。**

| 编号 | 变化 | 位置 | 类型 | 状态 | 对读者的意义 |
|---|---|---|---|---|---|
| C-1 | 双行筛选条供二手和跑腿共用 | `components/ui/UnderlineFilter.tsx` | 新增 | 完成 | 两类服务使用同一筛选交互 |
| C-2 | 指南页签读取服务端分类 | `features/guides` | 已变更 | 完成 | 指南分类不再写死在 App |
| C-3 | 树洞列表和详情支持多图分页 | `features/campus` | 新增 | 完成 | 用户可滑看多图并获知页码 |
| C-4 | 二手、跑腿举报走统一端点 | `features/reports` | 已修复 | 完成 | 三类内容复用同一举报状态机 |
| C-5 | 远程话题创建等待服务端能力 | P3A3-04 | 已变更 | 进行中 | 普通用户不会看到必然 403 的入口 |
| C-6 | 社团发布和消息目标等待路由 | P3A3-06 | 已变更 | 进行中 | App 不会生成社团死链接 |

例行变更：为上述消费者补充了局部回归、类型检查和 lint。

## 2. 这意味着什么

社区页面现在复用公共筛选、媒体和举报边界，而没有新增一套域内机制。
指南分类和举报目标都以服务端回执为准。
社团仍须由 Phase 5 先建立真实路由，再让通知目标成为可点路径。

## 3. 仍开放

- P3A3-04 缺少普通用户可创建话题的服务端能力和搜索契约。
- P3A3-06 缺少社团活动发布描述器、App 路由和通知目标契约。
- 横滑手势已完成自动化检查，仍缺 iOS 与 Android 真机证据。
