# T4 · 周次条与底部操作美化

## 1. Where this task sits

- **Phase 课表页重做**，目标：页面骨架不再"丑"：周次可读、控制集中、底部不堆横幅。
- **本任务移入** `R5 页面观感`：只改 `TimetableScreen` 的布局与样式，不碰网格/弹窗。
- **Starts after**：T2。**Waits on it**：T5（证据截图）。

## 2. What the developer needs to know

**Read first**

- `app/src/features/tools/TimetableScreen.tsx` — `WeekNumbers`（小号数字横排 + 每段跳 5 周）与底部 `InlineNotice` + `Button` + 说明文字三层堆叠。
- `app/src/__tests__/p1-16-timetable.test.tsx` — 要求保留 `timetable-weeks`、`timetable-prev`、`timetable-next`；空态仍要有 `timetable-empty` 与"课表导入"。
- `app/src/__tests__/p3y2-timetable.test.tsx` — `legacyControls=false` 时不得出现 prev/next；`week-number-14` 可点、标签 `第 14 周`。
- `app/src/components/ui/Button.tsx` / `Pressable.tsx` — 只用现成组件与令牌。

**Settled**

- 周次条：横向胶囊列表（所有周次），选中 = 品牌填充 + 反白文字，未选中 = 下沉底色；`week-number-N` 与 `第 N 周` 标签不变。
- 上一周 / 下一周按**1 周**步进（原为 5 周）；`legacyControls` 语义不变。
- 底部收成一行两个 ghost 按钮（导入课表 / 刷新）；移除 `InlineNotice` 与学期说明段落。
- 空态/错误态/离线 stale 条保持现有 testID 与文案。

**Edges and seam**

- 只动 `TimetableScreen.tsx` + 两个既有用例的必要断言；⛔ 不动取数、缓存与网格。
- 接缝：`WeekNumbers` 展示与 `Screen` 底部操作区。

**Run**

- `cd app && npx jest --testPathPattern "p1-16-timetable|p3y2-timetable"`
- `cd app && npx tsc --noEmit`

**Unknowns**

- 20 个周次胶囊在 411dp 下必然横向滚动：用 `ScrollView` + 自动滚到选中项（既有逻辑保留）。
- 字号放大时胶囊高度需 ≥48dp（触控下限），用 `touchTarget` 而不是固定高度。

## 3. The workflow

1. 读上述文件，复述本任务。
2. 重写 `WeekNumbers` 的选中态与胶囊样式，保留 testID 与滚动定位。
3. prev/next 步进改 1 周，词条改"上一周 / 下一周"。
4. 底部收成一行按钮；删除不再使用的 `InlineNotice`/说明引用。
5. 跑两个用例 + tsc；提交。
