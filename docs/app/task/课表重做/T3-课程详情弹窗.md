# T3 · 课程详情半屏弹窗

## 1. Where this task sits

- **Phase 课表页重做**，目标：点课程卡 → 半屏弹窗展示这门课的**全部信息**。
- **本任务移入** `R3 课程详情`：把点击从 Toast 改成 `O06 BottomSheet` + 课程详情内容。
- **Starts after**：T1（容器）、T2（卡片可点）。**Waits on it**：T4/T5 无强依赖。

## 2. What the developer needs to know

**Read first**

- `app/src/features/tools/TimetableScreen.tsx` — 现在点卡弹 Toast（`timetable.courseInfo`），改为选中态 + 弹窗。
- `app/src/components/ui/BottomSheet.tsx`（T1 产物）— 半屏容器 API 与关闭方式。
- `app/src/components/ui/Screen.tsx` 的 `useScreenInsets` — 弹窗 `bottomInset` 的来源（⛔ 不自读 insets）。
- `app/src/features/tools/timetable.ts` 的 `TimetableMeeting` / `TimetableWeek` — 可展示字段只有这些，⛔ 不编造。
- `app/src/i18n/zh.ts` — 词条表；`action.close` 已存在。

**Settled**

- 弹窗展示：课程名称、课程码、上课地点、上课时间、星期、授课教师、学分；再加"本周安排"（该课本周所有时段）。
- 缺少的字段显示"未标注 / 地点待定"（词条），⛔ 不显示 `null`。
- 关闭方式：遮罩 / 关闭键 / 系统返回；关闭后回课表，⛔ 不 push 路由。
- 弹窗不新增取数：全部信息来自已加载的本周数据。

**Edges and seam**

- 新增 `features/tools/CourseInfoSheet.tsx`；改 `TimetableScreen.tsx` 的点击回调；新增词条键。
- 接缝：`CourseInfoSheet({ meeting, occurrences, accent, onClose, bottomInset })`。

**Run**

- `cd app && npx jest --testPathPattern "p3a7-course-sheet|p1-16-timetable"`
- `cd app && npx tsc --noEmit`

**Unknowns**

- 弹窗挂在 `Screen` 内部还是外部：必须放在 `Screen` 子树里才有 `useScreenInsets`（用一个小的 host 组件取 insets 再传给容器）。
- `TimetableScreen` 的 `renderGrid` 契约保持不变（路线层继续自己渲染网格），弹窗由屏幕拥有。

## 3. The workflow

1. 读上述文件，复述本任务。
2. 落词条键（zh/en 成对）：课程码/地点/时间/星期/教师/学分/本周安排/未标注。
3. 写 `CourseInfoSheet`，红→绿（字段齐全、缺字段兜底）。
4. 在 `TimetableScreen` 用选中态替换 Toast，宿主组件取 insets；用例验证点卡开弹窗、关闭后消失、不 push。
5. 跑用例与 tsc；提交。
