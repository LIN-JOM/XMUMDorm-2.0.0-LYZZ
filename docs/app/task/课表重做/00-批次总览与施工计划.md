# 课表页重做 —— 批次总览与施工计划

> 2026-10-18 所有者指令（原话拆条）：
> ① 课程表页面**很丑**，要重做。
> ② **同一门课颜色一样，不同课程颜色不一样**。
> ③ 每张课程小卡**必须显示上课地点 + 课程名称**。
> ④ 点卡片 → **下方弹起半屏弹窗**，展示这门课的**全部信息**。
> ⑤ **仍然采用品牌色**。

## 1. 需求 → 方案

| # | 需求 | 方案 | 落点 |
|---|---|---|---|
| R1 | 课程配色 | 6 个**课程色** = 品牌/状态 soft 背景 + 对应文字色（全部来自令牌）；按**本周课程码排序**分配，同课同色、不同课不同色（≤6 门时必不重复） | `features/tools/timetableView.ts` |
| R2 | 卡片必须显示地点 + 名称 | 课表网格重排：5 列（周一–周五）× 时间行；卡片 = 课程名（加粗）+ 地点，整卡按课程色填充 | `proto/P11/TimetableGrid.tsx` |
| R3 | 点击弹半屏 | 新组件 `O06 BottomSheet`（半屏、遮罩、可下滑关闭的替代：点遮罩/关闭键/系统返回） + `CourseInfoSheet`（全字段 + 本周该课所有时段） | `components/ui/BottomSheet.tsx`、`features/tools/CourseInfoSheet.tsx` |
| R4 | 品牌色 | 课程色只取语义令牌；文字色与背景色**逐对实测 ≥4.5:1** | 令牌（不新增色值） |
| R5 | 页面观感 | 周次条改成品牌色胶囊（选中填充）、上一周/下一周按钮、底部操作收成一行 | `features/tools/TimetableScreen.tsx` |

## 2. 已定裁决（本批不得重开）

- 课程色**不新增调色板**：复用 `bg-brand-soft / bg-accent-soft / bg-success-soft / bg-warning-soft / bg-danger-soft / bg-sunken` + 对应 `text-*`；状态色在这里只作**课程身份色**，不表达状态语义。
- 颜色分配**按周**：本周出现的课程码升序 → 依次取色（模 6）。跨周课程集合不变时颜色稳定；集合变了允许位移（写进文档，不假装全局稳定）。
- 网格只显示**周一至周五**（既有 `VISIBLE_WEEKDAYS` 口径，`weekdayTimetableWeek` 已过滤周末）。
- 弹窗是**半屏**（`heightRatio = 0.5`），不是全屏、不是 Toast。
- 课表仍只从 `GET /api/schedule/week?week=N` 取数；⛔ 不新增端点、不改后端。
