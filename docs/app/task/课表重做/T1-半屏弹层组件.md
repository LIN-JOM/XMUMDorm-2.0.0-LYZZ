# T1 · `O06 BottomSheet`（半屏弹层）

## 1. Where this task sits

- **Phase 课表页重做**，目标：有一块可复用的半屏弹层，承载课程详情。
- **本任务移入** `R3 半屏弹窗` 的**容器**：只做"遮罩 + 半屏 + 关闭"，不碰课表业务。
- **Starts after**：无。**Waits on it**：`T3 课程详情弹窗`。

## 2. What the developer needs to know

**Read first**

- `app/src/components/ui/ActionSheet.tsx` — 既有 `Modal` + 底部容器的写法（遮罩、`accessibilityViewIsModal`、`onRequestClose`）。
- `app/src/components/ui/Screen.tsx` 的 `useScreenInsets` — 覆盖层要 insets 但⛔ 不自己读（S7）。
- `docs/app/design/App组件类型定义.md` §2.5 的 `O06 BottomSheet` 行 — 计划里已有此组件，本任务把它落地。
- `app/src/components/ui/Surface.tsx` / `IconButton.tsx` — 底色与关闭键只用现成组件。

**Settled**

- 半屏比例固定 `0.5`（所有者要求"半页面"）；不提供全屏形态。
- 关闭方式三种：点遮罩、点右上关闭键、系统返回（`onRequestClose`）。
- insets 由调用方传入 `bottomInset`（本组件不 import safe-area）。

**Edges and seam**

- 只新增 `components/ui/BottomSheet.tsx` + 新用例 + 组件文档 O06 行；⛔ 不改 Screen / ActionSheet。
- 接缝：`BottomSheet({ visible, title?, onClose, closeLabel, bottomInset?, heightRatio?, children })`。

**Run**

- `cd app && npx jest --testPathPattern "p3a7-bottom-sheet"`
- `cd app && npx tsc --noEmit`

**Unknowns**

- RN `Modal` 在 Jest 里的可见性行为：用 `visible` 驱动断言，不依赖动画结束。
- `accessibilityViewIsModal` 在 Android 上的效果要在真机确认（本批只保证属性存在）。

## 3. The workflow

1. 读上述文件，用一句话复述本任务。
2. 写用例 1（`visible=false` 不渲染内容），再实现 Modal 容器直到绿。
3. 写用例 2/3（标题与关闭键、点遮罩关闭），红→绿。
4. 写用例 4（`bottomInset` 进 padding、高度比例=0.5），红→绿。
5. 跑 jest 与 tsc；更新组件文档 O06 行（落地状态 + 消费者 `T-02`）。
6. 提交。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 1 | `visible={false}` | 不渲染 `*-sheet` 与内容 | `BottomSheet` |
