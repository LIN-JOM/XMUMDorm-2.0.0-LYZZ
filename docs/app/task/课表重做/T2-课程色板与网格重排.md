# T2 · 课程色板 + 网格重排

## 1. Where this task sits

- **Phase 课表页重做**，目标：课表一眼能读、每门课有稳定颜色、卡片上能看到名称与地点。
- **本任务移入** `R1 同课同色 / 异课异色` 与 `R2 卡片显示名称 + 地点`。
- **Starts after**：无。**Waits on it**：`T3`（弹窗从卡片点开）、`T4`（周次条）。

## 2. What the developer needs to know

**Read first**

- `app/src/features/tools/timetableView.ts` — 现有 `courseAccent`（只有 2 色、且网格没用上）。
- `app/src/proto/P11/TimetableGrid.tsx` — 当前行=开始时间、列=7 天、列宽 48dp；卡片已有地点但极窄。
- `app/src/app/tools/timetable.tsx` — `renderGrid` 只传了 3 个 prop，`getCourseAccent` 被丢了（这就是"没颜色"的直接原因）。
- `app/src/features/tools/timetable.ts` 的 `buildTimetableRows` — 行键是开始时间（⛔ 不造节次表）。
- `app/src/__tests__/p1-16-timetable.test.tsx` / `p3y2-timetable.test.tsx` — 必须保留的 testID 与结构约束（proto 内不得出现 `Modal`/hex/fontSize）。

**Settled**

- 6 色映射（背景/文字成对，均已实测 ≥4.5:1）：`bg-brand-soft/text-brand`、`bg-accent-soft/accent-text`、`bg-success-soft/text-success`、`bg-warning-soft/text-warning`、`bg-danger-soft/text-danger`、`bg-sunken/text-brand`；地点文字统一 `text-secondary`。
- 颜色按周分配：本周课程码升序取色（模 6）→ 同课同色、异课异色（≤6 门不重复）。
- 网格 5 列（`visibleWeekdays`），行仍是开始时间；卡内第一行课程名（加粗），第二行地点。
- 卡片 testID 保留 `${testID}-card-${courseCode}`，列头保留 `${testID}-head-${day}`。

**Edges and seam**

- 动 `timetableView.ts`、`proto/P11/TimetableGrid.tsx`、`app/tools/timetable.tsx` 与两个既有用例；⛔ 不动周切换逻辑与取数。
- 接缝：`COURSE_ACCENTS` / `courseAccentMap(week)` / `TimetableGrid` 的 `getCourseAccent`、`visibleWeekdays`。

**Run**

- `cd app && npx jest --testPathPattern "p1-16-timetable|p3y2-timetable|p3a-y-integration"`
- `cd app && npx tsc --noEmit`

**Unknowns**

- 5 列 + 时间槽在 411dp 下是否够宽：用 `flex:1` 而不是固定列宽；若字号放大到 2x 仍挤压，卡片名称允许 2 行、地点允许 1 行（⛔ 不缩字号）。
- 同名课程不同代码按代码区分（同一门课 = 同一 `courseCode`）。

## 3. The workflow

1. 读上述文件，复述本任务。
2. 在 `timetableView.ts` 落 `COURSE_ACCENTS` 与 `courseAccentMap`，红→绿（同课同色 / 异课异色 / ≤6 不重复）。
3. 改 `TimetableGrid`：props 增加 `visibleWeekdays`、`getCourseAccent`；列宽 flex；卡片按色填充 + 名称 + 地点。
4. 改 `app/tools/timetable.tsx` 把两个新 prop 传给网格；更新 p1-16/p3y2 断言（颜色 6 值、卡片文本）。
5. 跑两个用例文件 + tsc；提交。
