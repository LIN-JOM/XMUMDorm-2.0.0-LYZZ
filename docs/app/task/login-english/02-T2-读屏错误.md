## 1. 任务位置

Phase 1 英文学校邮箱登录，完成 R-1 英文登录的读屏及错误部分。
依赖局部英文上下文；保持其他控件默认读屏口径。

## 2. 开发入口

阅读：
- Input.tsx — 必填和错误如何进入读屏标签？
- ErrorSummary.tsx — 失败文案如何读取语言？
- p1-13-auth-session.test.tsx — 空账号和接口失败如何回归？

已定：读屏文案通过可选参数注入，错误仍由共享模型翻译。
接缝：现有登录、会话、控件回归；不为全 App 修改读屏语言。
运行：3 套相关测试及 npm.cmd run typecheck。
未知：若发现后端中文原文直出，先用现有错误模型收口，不写另一套错误组件。

## 3. 工作流

1. 阅读入口，确认必填与错误同时进入英文读屏标签。
2. 在现有回归中要求英文必填、英文失败摘要和英文读屏。
3. 为 Input 注入翻译后的词语与分隔符，保留默认值。
4. 运行回归并提交。
