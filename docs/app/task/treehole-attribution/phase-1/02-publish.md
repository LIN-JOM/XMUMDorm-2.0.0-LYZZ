## 3. 工作流

1. 阅读开发信息，复述：复用现有表单声明原创或 WX 转载。
2. 从描述符提交入口写失败用例，证明声明未被传递。
3. 添加原创与转载选项，以及条件显示的 WX 来源。
4. 补齐字段双语词条，传递规范化提交值。
5. 验证草稿保留声明，切回原创不提交残留来源。
6. 运行定向测试、类型检查和 lint，按意图提交。
