# 保留真实发布表单的空标签初始值

日期：2026-10-19；版本：1.0。

## 1. 任务位置

- Phase 1 “转载 · WX”完成端到端闭环：真实话题控件未选择时也能发帖。
- 支撑 R-1 发布时必须声明原创或转载，排除真实表单的提交阻碍。
- 前置：真实话题字段集成用例暴露失败；后继：阶段验证收口。

## 2. 开发信息

**先读**

- app/src/components/ui/FormField.tsx — 显式初始值为何变成 false？
- app/src/components/ui/Form.tsx — 初始化和重置是否共用入口？
- app/src/features/campus/postPublishFields.ts — 自定义话题字段如何声明空数组？
- app/src/__tests__/publish-attribution.test.tsx — 不选话题为何未触发 API？

**已定**

- 字段注释约定：initialValue 优先于按控件类型推导的默认值。
- Phase 1 边界不改变；仅修正空数组被错误解释为条件的问题。

**边界与测试缝**

- 使用现有表单初始化测试与发布宿主测试。
- 只修改公共默认值表达式，避免树洞专用补丁。

**运行**

- cd app && npm test -- --runInBand p1-10-form-skeleton publish-attribution --silent
- cd app && npm run typecheck && npm run lint -- --quiet

**未知项**

- 显式初始值也用于其他自定义字段；测试同时覆盖数组、布尔、数字和文本。

## 3. 工作流

1. 阅读开发信息，复述：保留显式默认值，让空话题可提交。
2. 补充初始化失败用例，保留真实话题控件的失败证据。
3. 为默认值回退表达式补齐括号。
4. 运行初始化与发布宿主测试，确认所有控件默认值兼容。
5. 完成类型检查与 lint，并单独提交修复。
