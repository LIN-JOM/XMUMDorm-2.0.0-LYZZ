**已定**

- README.md：选自定义时才显示文字输入，提交实际文字。
- README.md：来源不超过 100 字符，列表可摘要，详情显示完整来源。

**边界与测试缝**

- 使用现有描述符、表单宿主、展示模型和组件测试。
- 不增加页面、控件、数据表或请求机制。

**运行**

- cd app && npm test -- --runInBand publish-attribution p2x-bing-publish-contract p2x-treehole-post --silent
- cd app && npm run typecheck && npm run lint -- --quiet

**未知项**

- 自定义文字可能很长，摘要不能独占列表标题行；真机验收仍属下一阶段。

## 3. 工作流

1. 阅读开发信息，复述：自定义输入沿同一来源字段保存和展示。
2. 增加自定义表单发布和展示失败用例。
3. 添加自定义选项、条件输入和双语文案。
4. 规范化提交来源，并让展示模型接受合法自定义文字。
5. 限制列表摘要宽度，在详情保留来源全文。
6. 运行测试、类型检查和 lint，分别提交测试与实现。
