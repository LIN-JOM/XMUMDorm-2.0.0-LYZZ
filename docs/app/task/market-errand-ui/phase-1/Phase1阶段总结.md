# 二手与跑腿 UI 阶段 1 总结

> 时间范围：2026-10-15
> 基线：[App 二手与跑腿 UI 改进计划](../../../design/App二手与跑腿UI改进计划.md)
> 范围：Expo App 阶段 1「两类卡片一眼能读懂」

## 1. 本阶段完成了什么

**本阶段完成 5 项改动。二手和跑腿列表现在能直接呈现商品或任务的关键决策信息，相关测试 63 项全部通过，App 类型检查通过。**

| 编号 | 改动 | 位置 | 类型 | 状态 | 对用户的影响 |
|---|---|---|---|---|---|
| C-1 | 二手模型保留服务端分类 | `app/src/features/marketplace/model.ts` | 新增 | 已完成 | 商品卡可以显示真实分类 |
| C-2 | 商品卡突出分类、卖家和价格 | `app/src/features/marketplace/MarketScreens.tsx`、`EntityCard.tsx` | 变更 | 已完成 | 用户更快判断商品身份与价格 |
| C-3 | 任务卡显示类型、地点和截止时间 | `app/src/features/errand/ErrandScreens.tsx`、`model.ts` | 变更 | 已完成 | 用户可以在列表判断任务是否紧急、何时截止 |
| C-4 | 统一卡片点击层与布局样式 | `app/src/components/ui/EntityCard.tsx` | 修复 | 已完成 | 卡片点击、无障碍语义和布局测试保持一致 |
| C-5 | 二手和跑腿列表增加令牌间距 | 两个列表页面 | 变更 | 已完成 | 连续卡片之间有更清晰的阅读节奏 |

常规部分：新增 5 份任务简报，补充契约与 UI 用例，未改变接口、权限、分页和其他域卡片。

## 2. 这些改动意味着什么

商品和任务现在有了不同的信息优先级：二手先看价格和商品身份，跑腿先看类型、时间和报酬。
公共 `EntityCard` 的布局契约已收口，后续筛选和详情改造可以继续复用同一张卡片。

## 3. 仍未完成什么

- 二手价格筛选仍占据列表首屏，筛选入口尚未收纳。
- 跑腿类型和状态仍使用旧的下划线筛选样式，组名和清除反馈尚未调整。
- 二手详情和跑腿详情尚未重排首屏摘要与主操作区。
- Expo Go 真机检查尚未完成，当前结论来自自动化测试和类型检查。
