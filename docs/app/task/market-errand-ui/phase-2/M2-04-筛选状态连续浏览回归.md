## 2. What the developer needs to know

**Read first**

- `app/src/features/marketplace/MarketScreens.tsx` — 二手查询键、请求代次和滚动快照。
- `app/src/features/errand/ErrandScreens.tsx` — 跑腿查询键、追加与失败处理。

- `app/src/__tests__/p2x-bing-market-errand-market-ui.test.tsx` — 二手返回位置与旧请求隔离。
- `app/src/__tests__/p2x-bing-market-errand-errand-ui.test.tsx` — 跑腿追加、错误和缓存清除。

**Settled**

- 筛选变化必须使用独立缓存键并从第一页开始。
- 刷新失败不清除已有行；追加失败保留已有行并可重试同页。
- 返回列表恢复滚动位置；不改分页接口与缓存键形状。

**Edges and seam**

- 接缝是两类 `Feed` 的请求代次、快照、分页回调和 `ListScreen`。
- 触及回归测试与必要的最小修复；不触及详情或后端。

**Run**

- `npm test -- --runInBand src/__tests__/p2x-bing-market-errand-market-ui.test.tsx src/__tests__/p2x-bing-market-errand-errand-ui.test.tsx`
- `npm run typecheck`

**Unknowns**

- 若设备复现出测试未覆盖的恢复时序，记录最小复现后停下，请求确认是否扩大范围。

## 3. The workflow

1. 阅读本简报并复述：切筛选、失败和返回都不能串结果或滚动位置。
2. 先写红测覆盖切模块与筛选切换的旧请求隔离。
3. 写红测覆盖刷新失败、追加失败重试和追加成功。
4. 写红测覆盖返回位置恢复与缓存清除后的重新读取。
5. 只修共享状态边界，运行两套测试和类型检查。
6. 提交 `test(app-market-errand): guard continuous filtered browsing`。
