# M2-02 二手价格筛选收纳

日期：2026-10-15 · 版本：Phase 2 · 状态：待施工

## 1. Where this task sits

- **Phase 2 筛选清楚，结果不断流**：用户能编辑条件而不丢失当前结果。
- **本任务推进 R-3 二手筛选让商品优先出现**：收纳价格输入，分离编辑草稿与已应用条件。
- **开始前**：M2-01 已完成筛选入口；**等待**：M2-03 的跑腿筛选复用规则。

## 2. What the developer needs to know

**Read first**

- `app/src/features/marketplace/MarketScreens.tsx` — `min`、`max` 草稿与 `filters` 的当前关系。
- `app/src/components/ui/InputSheet.tsx` — 收纳输入的既有交互与提交方式。
- `app/src/components/ui/Input.tsx` — 数字输入、错误文本和无障碍标签。
- `app/src/__tests__/p2x-bing-market-errand-market-ui.test.tsx` — 无效价格和查询次数断言。

**Settled**

- 草稿值只在点击应用后进入 `Filters`。
- 最低价、最高价必须是有限非负数，最低价不得高于最高价。
- 无效输入不发请求，继续保留用户草稿与错误提示。

**Edges and seam**

- 接缝是 `MarketListScreen` 的价格草稿、应用动作和 `MarketFeed` 查询键。
- 触及价格控件和清除展示；不改后端价格参数或列表缓存协议。

**Run**

- `npm test -- --runInBand src/__tests__/p2x-bing-market-errand-market-ui.test.tsx`
- `npm run typecheck`

**Unknowns**

- 若 `InputSheet` 无法承载双字段校验，复用现有 `Input` 并保持最小改动；不要引入新依赖。

## 3. The workflow

1. 阅读本简报并复述：价格草稿未应用前不能影响查询结果。
2. 写红测，证明编辑最低价不会改变当前请求。
3. 写红测，覆盖空值、负数、非数字和区间倒置。
4. 将价格输入放入可展开或底部 sheet，显示已应用价格摘要。
5. 保持错误时不提交查询，运行测试与类型检查。
6. 提交 `feat(app-marketplace): contain price filter drafts`。
