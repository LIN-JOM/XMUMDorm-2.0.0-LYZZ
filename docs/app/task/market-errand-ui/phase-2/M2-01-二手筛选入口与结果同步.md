# M2-01 二手筛选入口与结果同步

日期：2026-10-15 · 版本：Phase 2 · 状态：待施工

## 1. Where this task sits

- **Phase 2 筛选清楚，结果不断流**：用户能看到已生效条件，筛选后结果与条件一致。
- **本任务推进 R-3 二手筛选让商品优先出现**：贯通搜索、分类、状态、价格的入口与请求。
- **开始前**：Phase 1 卡片字段已提交；**等待**：M2-02 的价格输入收纳。

## 2. What the developer needs to know

**Read first**

- `app/src/features/marketplace/MarketScreens.tsx` — 当前筛选状态、查询键与列表刷新边界。
- `app/src/components/ui/FilterChips.tsx` — 现有筛选芯片的选中与清除语义。
- `app/src/components/ui/ListScreen.tsx` — 刷新、追加和滚动恢复的组件契约。
- `app/src/__tests__/p2x-bing-market-errand-market-ui.test.tsx` — 二手筛选请求与返回行为。

**Settled**

- `Filters` 是已应用查询条件；请求仍使用现有 `listMarketplaceItems`。
- 筛选是 `FilterChips` 语义，不扩展 `UnderlineFilter`。
- 不改接口、排序、顶部模块导航或卡片域布局。

**Edges and seam**

- 接缝是 `MarketListScreen` 的筛选状态与 `MarketFeed` 查询键。
- 触及二手筛选入口、清除动作和列表重载；不触及价格校验实现。

**Run**

- `npm test -- --runInBand src/__tests__/p2x-bing-market-errand-market-ui.test.tsx`
- `npm run typecheck`

**Unknowns**

- 若现有芯片组件无法同时表达已应用条件与清除入口，先停下说明，不新增设计系统。

## 3. The workflow

1. 阅读本简报并用一句话复述：二手筛选入口必须与已应用查询同步。
2. 写组合筛选红测，覆盖搜索、分类、状态与清除动作。
3. 用现有 `FilterChips` 替换筛选视觉，保留现有查询字段。
4. 让清除动作只清已应用条件，并触发第一页刷新。
5. 运行本任务测试和类型检查，确认旧分页行为不变。
6. 提交 `feat(app-marketplace): sync compact filters with results`。
