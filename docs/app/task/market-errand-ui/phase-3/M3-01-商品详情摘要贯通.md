# M3-01 商品详情摘要贯通

日期：2026-10-15 · 版本：Phase 3 · 状态：待施工

## 1. Where this task sits

- **Phase 3 详情首屏能完成决策与操作**：商品详情首屏能看清交易信息。
- **本任务推进 R-5 商品详情突出交易信息与动作**：贯通媒体、标题、价格、卖家和状态。
- **开始前**：Phase 2 已总结；**等待**：M3-02 的交易操作区重排。

## 2. What the developer needs to know

**Read first**

- `app/src/features/marketplace/MarketScreens.tsx` — 商品详情数据读取和首屏 JSX 顺序。
- `app/src/components/ui/MediaGrid.tsx` — 媒体缺失与多图展示契约。
- `app/src/components/ui/DetailScreen.tsx` — 详情加载、错误和返回骨架。
- `app/src/__tests__/p2x-bing-market-errand-market-ui.test.tsx` — 商品详情数据与“想要”行为。

**Settled**

- 详情继续使用 `getMarketplaceItemDetail` 与 `readMarketDetail`。
- 价格、状态和卖家使用服务端数据；缺图时不制造占位内容。
- 不新增交易规则，不改游客和权限判断。

**Edges and seam**

- 接缝是 `MarketDetailScreen` 的 `DetailScreen` 内容排序。
- 触及摘要区和媒体区；“想要”写操作留给 M3-02。

**Run**

- `npm test -- --runInBand src/__tests__/p2x-bing-market-errand-market-ui.test.tsx`
- `npm run typecheck`

**Unknowns**

- 若详情媒体组件不支持首屏紧凑布局，保持其契约并只调整外层顺序。

## 3. The workflow

1. 阅读本简报并复述：商品详情先给决策摘要，再给描述正文。
2. 写红测，要求首屏出现图片、标题、价格、状态和卖家。
3. 调整详情内容顺序，复用现有媒体与文本组件。
4. 覆盖无图、缺卖家和长标题，保持正文可读。
5. 运行详情测试与类型检查。
6. 提交 `feat(app-marketplace): connect item detail summary`。
