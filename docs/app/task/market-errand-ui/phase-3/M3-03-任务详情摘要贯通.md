# M3-03 任务详情摘要贯通

日期：2026-10-15 · 版本：Phase 3 · 状态：待施工

## 1. Where this task sits

- **Phase 3 详情首屏能完成决策与操作**：任务详情首屏能判断是否接手。
- **本任务推进 R-6 任务详情突出任务信息与动作**：贯通报酬、地点、截止时间、状态和联系方式。
- **开始前**：Phase 2 已总结；**等待**：M3-04 的任务操作区重排。

## 2. What the developer needs to know

**Read first**

- `app/src/features/errand/ErrandScreens.tsx` — 任务详情数据和身份读取。
- `app/src/features/errand/model.ts` — 详情模型与截止时间格式化。
- `app/src/components/ui/ContactCopy.tsx` — 联系方式显示与复制语义。
- `app/src/__tests__/p2x-bing-market-errand-errand-ui.test.tsx` — 详情权限和联系方式边界。

**Settled**

- 联系方式只在详情展示，列表模型继续拒绝联系方式字段。
- 报酬、地点、截止时间和状态使用服务端值及本地格式化。
- 身份读取失败保留既有提示，不猜测当前用户身份。

**Edges and seam**

- 接缝是 `ErrandDetailScreen` 的摘要内容与 `ContactCopy` 区域。
- 触及详情阅读顺序；接单、完成和删除动作留给 M3-04。

**Run**

- `npm test -- --runInBand src/__tests__/p2x-bing-market-errand-errand-ui.test.tsx src/__tests__/p2x-bing-market-errand-contract.test.tsx`
- `npm run typecheck`

**Unknowns**

- 若联系方式过长，允许换行并保持复制入口，不把内容泄露到列表。

## 3. The workflow

1. 阅读本简报并复述：任务详情先展示报酬、地点、时间和状态摘要。
2. 写红测，要求有截止时间与无截止时间都可读。
3. 调整摘要区、正文区和联系方式区的顺序。
4. 核对复制入口、电话文本和非电话号码边界。
5. 运行详情、契约测试与类型检查。
6. 提交 `feat(app-errand): connect task detail summary`。
