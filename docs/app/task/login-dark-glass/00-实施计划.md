# 深色登录材质独立设计

日期：2026-10-21。基线：c796a27b。来源：用户要求深色液态玻璃重新设计，不沿用浅色。

## 1. 需求

- R-1 夜间材质：独立夜色插画、烟灰蓝玻璃与细反光，去除乳白拱边。
- R-2 主题完整：深色顶部、两侧与中央衔接；浅色外观与原登录行为保持。
- R-3 可复核：保留真实表单、适配和验证边界，以截图及回归证明实现。

## 2. 方案

### R-1 夜间材质

- 方案：制作独立夜间资源，保留角色姿势和低拱；烟灰蓝透明边缘过渡到石墨底。
- 范围：登录装饰素材和两侧反光，采用品牌描边与中性表面令牌。
- 接缝：真实登录组件深色截图、打包资源清单。
- 验收：[ ] 深色加载独立资源；[ ] 无乳白宽亮带；[ ] 两侧使用独立的细反光层次。
- 难点：保留纯白角色的可辨识度，避免玻璃变成霓虹线框。

### R-2 主题完整

- 方案：深色单独设置反光宽度和衰减位置，按主题选择背景并同步状态栏。
- 范围：登录专用组件，不重做输入和导航。
- 接缝：深浅对照、既有登录回归及状态栏用例。
- 验收：[ ] 深色中央实色可读；[ ] 浅色保留原稿；[ ] 登录及状态栏回归通过。
- 难点：主题切换不能重建真实字段或泄漏状态栏覆盖。

### R-3 可复核

- 方案：保存深浅、窄屏、短屏截图，运行类型、lint、设计尺子和 Android 导出。
- 范围：本批源码与现有回归；无可用原生设备的边界沿用。
- 接缝：截图、3 套相关回归、构建记录。
- 验收：[ ] 适配截图齐全；[ ] 类型、lint、设计尺子通过；[ ] Android 导出通过。
- 难点：静态材质及原生渐变不能等同于动态物理折射。

## 3. Phase 1 独立夜间材质

目标：深色登录使用完整夜间构图与烟灰蓝拱边，并能正常输入与切换主题。
涵盖：R-1 夜间材质、R-2 主题完整、R-3 可复核。

- 制作并登记独立夜间装饰素材。
- 接入主题资源、两侧细反光与状态栏配色。
- 完成截图、相关检查、交接和双轴验收。

证明：深色真实组件截图、现有回归与 Android 导出通过。
范围外：共享组件重做、注册重置页、后端、新依赖和动态物理折射。
