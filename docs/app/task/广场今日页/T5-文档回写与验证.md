# T5 · 文档回写 + 证据 + 全量验证

## 1. Where this task sits

- **Phase 广场今日页**，目标：把这一轮的所有者裁决写进设计文档（宪法 15.4-3），并留下可复核证据。
- **本任务移入** `文档回写与验收`：不是代码任务，但没有它这一轮不算交付。
- **Starts after**：T1–T4。**Waits on it**：无（本批收口）。

## 2. What the developer needs to know

**Read first**

- `docs/app/design/App页面骨架与布局规范.md` §1 顶部横幅 / §2 格位表 / §3 顶栏 — 三处都要写 2026-10-18 裁决。
- `docs/app/product/App页面清单与结构盘点.md` §2.5 D-1 — 广场首页从"7 模块"改为"今日 + 4 模块 + 3 独立页"。
- `docs/app/TODO.md` §六 — 若要登记"今日页依赖 Moodle 页同步"的已知限制，状态行计数必须同步改（守卫用例会核对）。
- `docs/app/task/广场今日页/00-批次总览与施工计划.md` — 本批验收清单，逐条打勾。
- `app/jest.config.js` — 全量跑法与时区固定。

**Settled**

- 文档只写"现在为真"的事实；⛔ 不写"第 N 轮""此前"进 TODO 正文。
- 证据放 `docs/app/task/img-square-today/`，命名 `after-*.png`，并在任务文档里引用。
- 四把尺子的命令与 CI 一致（在 `app/` 下 `npm run rulers`）。

**Edges and seam**

- 只动 `docs/app/**` 与本批任务文档；代码层如发现缺口，回 T1–T4 补，不在本任务顺手改代码。
- 接缝：文档（设计/页面清单/TODO）↔ 代码（`SQUARE_TABS`、`SquareModules`、`TodayPane`）。

**Run**

- `cd app && npx tsc --noEmit && npx jest --ci --runInBand`
- `cd app && npm run rulers`
- `cd app && npx expo lint`（仅确认 0 error；warning 沿用既有基线）

**Unknowns**

- 模拟器若起不来，用真机截图或明确写"未取到视觉证据"（⛔ 不拿设计稿冒充截图）。
- 全量 Jest 约 3–5 分钟；别在等待时改文件（避免跑的不是最终树）。

## 3. The workflow

1. 读上面 5 个文件/目录，复述本任务一句话。
2. 写 `脚手架规范` 的 2026-10-18 裁决段（品牌头 / 4 入口 / 5 tab / 打开即今日）。
3. 改页面清单 D-1 与格位表、路由表相关行。
4. 视需要登记 TODO 一条（含状态行计数）+ 变更记录；跑 `p2d-05-registry` 验证。
5. 补任务文档状态与证据引用；把 00 文档验收清单逐条打勾。
6. 跑全量验证 + 四把尺子，提交。
