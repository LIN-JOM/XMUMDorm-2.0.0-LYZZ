# T1 · 今日数据与纯逻辑（课表 + Moodle 最近 3 条）

## 1. Where this task sits

- **Phase 广场今日页**，目标：今日 tab 有真实数据可渲染。
- **本任务移入** `R1 今日所有课表` 与 `R2 Moodle 最近 3 条待交`：两段数据都收成纯函数 + 一个缓存订阅 hook。
- **Starts after**：无。**Waits on it**：`T3 今日 pane`。

## 2. What the developer needs to know

**Read first**

- `app/src/features/tools/timetable.ts` — 周次/时区/`useTimetableWeek` 的唯一入口，`todayWeekday` 在这里。
- `app/src/features/me/dashboard.ts` — `meetingsOf` 与 `formatClockTime`（`14:00:00` → `14:00`）。
- `app/src/features/tools/moodle/deadlines.ts` — 现成的 `partitionMoodleDeadlines`，别再写一套筛选。
- `app/src/features/tools/moodle/cache.ts` — `readMoodleCache` / `subscribeMoodleInvalidation` 的语义（冷启动为空是**设计**）。
- `app/src/features/tools/ToolsDashboard.tsx` — 现有"今日课程"取数口径（`currentWeek === null` 时传 `null`）。

**Settled**

- 时区一律用 `shared/config/semesters` 的 KL 时区；⛔ 不用设备时区。
- 截止时间展示用 KL 时区的日历日判断"今天 / 明天 / 其它"。
- 不新增网络请求：Moodle 只读本地缓存；课表复用 `useTimetableWeek`（缓存优先 + 远端）。

**Edges and seam**

- 只动 `features/square/`（新增两个文件）+ 新用例；⛔ 不改 timetable / moodle 模块。
- 接缝：`agendaCourses(week, now)`、`agendaDeadlines(states, events, courses, now, limit)`、`useMoodleAgenda(nowMs)`。

**Run**

- `cd app && npx jest --testPathPattern p3a6-today-agenda`
- `cd app && npx tsc --noEmit`

**Unknowns**

- `readMoodleCache()` 在冷启动返回空 → `synced=false` 由调用方显示同步入口（不是错误）。
- Moodle 事件缺少 `eventType` 的旧快照：交给 `partitionMoodleDeadlines` 现有规则，⛔ 不在本层补猜。

## 3. The workflow

1. 读上面 5 个文件，用一句话复述本任务。
2. 写 `todayAgenda.ts`：`agendaCourses` 先落用例（教学周内 / `currentWeek === null`）。
3. 落 `agendaDeadlines`（排序 + 去重 + `limit`），红→绿。
4. 落 `deadlineWhen`（KL 日历日 → `today|tomorrow|later` + `HH:mm`），红→绿。
5. 落 `useMoodleAgenda`（mount 读缓存 + 订阅失效），用例用假事件驱动。
6. 跑 `jest --testPathPattern p3a6-today-agenda` 与 `tsc --noEmit`，提交。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 1 | 周一 08:00、10:00 两节课，`now` 为周一 09:00，教学周内 | 两节都返回，按 08:00 → 10:00 | `agendaCourses` |
| 2 | 同上但 `currentWeek === null`（未开学） | `[]` | `agendaCourses` |
| 3 | 4 条未过期 DDL（乱序） | 只取最早 3 条、升序 | `agendaDeadlines` |
| 4 | `now` = 2026-10-18 21:57 KL，`dueAt` = 次日 09:00 KL | `{kind:'tomorrow', clock:'09:00'}` | `deadlineWhen` |
| 5 | 缓存空 → `readMoodleCache` 空；随后触发 invalidation 并写入 1 门课 1 条 DDL | 先 `synced:false, deadlines:[]`，再变 `synced:true` 且含 1 条 | `useMoodleAgenda` |
