# 广场「今日」页 + 品牌头 + 模块入口 —— 批次总览与施工计划

> 2026-10-18 所有者指令（原话拆条）：
> ① 广场页新增 tab「今日」：展示今天**所有**课表 + Moodle **最近 3 条**待交作业 / DDL。
> ② 去掉顶部 `Square` 面包屑；左上角校徽、其右紧挨文本 `XMUM Dorm`（**整行靠左**，已确认）。
> ③ 品牌头下方、Tab 条上方放 **4 个功能模块入口**（课表 / 校园攻略 / 二手 / 社团），Lucide 图标、**更大 + 有填充颜色**；点击直达对应页面。位置**所有 Tab 常驻可见**（已确认）。
> ④ 因此把 `校园攻略 / 二手 / 社团` 从 Tab 条抹去，做成独立页面（路由保留）。
> ⑤ 每次打开 App **固定定向到广场页的「今日」tab**。

## 1. 需求 → 方案（逐条）

| # | 需求 | 方案 | 落点 |
|---|---|---|---|
| R1 | 今日所有课表 | 复用 `useTimetableWeek` + `currentTeachingWeek` + `meetingsOf`；教学周外（`currentWeek === null`）按"今天没课" | `features/square/todayAgenda.ts` |
| R2 | Moodle 最近 3 条待交 | 复用 `readMoodleCache` + `partitionMoodleDeadlines`，取 `valid` 前 3；**不发新网络请求**，订阅缓存失效事件 | 同上 + `useMoodleAgenda.ts` |
| R3 | 去面包屑、品牌头 | `Screen` 新增 `header?: ReactNode`（仍由 Screen 唯一算 insets）；`SquareHome` 传 `SquareBrandHeader`（校徽 + `XMUM Dorm`） | `components/ui/Screen.tsx`、`features/square/SquareBrandHeader.tsx` |
| R4 | 4 个模块入口 | 新特性组件 `SquareModuleEntries`（注册表驱动，一源）——64dp 圆角填充块 + 32dp Lucide 图标 + 标签，一行 4 格 | `features/square/` |

## 2. 已定裁决（本批不得重开）

- 品牌头排版：**校徽靠左 + `XMUM Dorm` 紧挨其右**（所有者 2026-10-18 选定）。
- 模块入口位置：**品牌头下方、Tab 条上方，所有 Tab 常驻**（所有者 2026-10-18 选定）。
- Tab 集合：**今日 / 树洞 / 万能墙 / 食堂 / 跑腿**（所有者 2026-10-18 选定；跑腿保留）。
- 不做宫格入口**页**替代二级导航（宪法 4.8）：4 个入口是**页内功能入口**（`QuickActionGrid` 同性质），二级导航仍是 `TopTabStrip`。
- 颜色只取令牌：填充块用 `action-primary`（厦大蓝）/ `action-accent`（美团黄）交替，图标色用对应的 `text-on-fill` / `text-on-accent`。
- Moodle 数据边界不变：**冷启动不读盘**（Y0 隐私口径），今日页显示"未同步"入口；同步后回到今日页自动更新。

## 3. 验收（可机器判定）

1. `npx tsc --noEmit` 通过；`npx jest` 全绿；四把尺子全绿。
2. 默认（无 `?tab=`）渲染：`top-tab-today` 选中、`square-pane-today` 可见；`top-tab-market/guides/clubs` 不存在。
3. 4 个模块入口在任意 Tab 下都存在；点击分别 push `/tools/timetable`、`/guides`、`/market`、`/clubs`；不新增路由。
4. `screen-square` 内**不再出现** `广场` 面包屑；出现 `XMUM Dorm` 与校徽图。
5. 今日 pane：今日课程按开始时间升序全量展示；Moodle 只展示前 3 条、按 DDL 升序；无缓存时给出同步入口。
6. 模拟器截图证据：今日页（有课 / 无课至少各一张）+ 模块入口 + 点击后目标页。
