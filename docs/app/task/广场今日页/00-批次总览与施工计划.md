# 广场「今日」页 + 品牌头 + 模块入口 —— 批次总览与施工计划

> 2026-10-18 所有者指令（原话拆条）：
> ① 广场页新增 tab「今日」：展示今天**所有**课表 + Moodle **最近 3 条**待交作业 / DDL。
> ② 去掉顶部 `Square` 面包屑；左上角校徽、其右紧挨文本 `XMUM Dorm`（**整行靠左**，已确认）。
> ③ 品牌头下方、Tab 条上方放 **4 个功能模块入口**（课表 / 校园攻略 / 二手 / 社团），Lucide 图标、**更大 + 有填充颜色**；点击直达对应页面。位置**所有 Tab 常驻可见**（已确认）。
> ④ 因此把 `校园攻略 / 二手 / 社团` 从 Tab 条抹去，做成独立页面（路由保留）。
> ⑤ 每次打开 App **固定定向到广场页的「今日」tab**。

## 1. 需求 → 方案（逐条）

## 2. 已定裁决（本批不得重开）

- 品牌头排版：**校徽靠左 + `XMUM Dorm` 紧挨其右**（所有者 2026-10-18 选定）。
- 模块入口位置：**品牌头下方、Tab 条上方，所有 Tab 常驻**（所有者 2026-10-18 选定）。
- Tab 集合：**今日 / 树洞 / 万能墙 / 食堂 / 跑腿**（所有者 2026-10-18 选定；跑腿保留）。
- 不做宫格入口**页**替代二级导航（宪法 4.8）：4 个入口是**页内功能入口**（`QuickActionGrid` 同性质），二级导航仍是 `TopTabStrip`。
- 颜色只取令牌：填充块用 `action-primary`（厦大蓝）/ `action-accent`（美团黄）交替，图标色用对应的 `text-on-fill` / `text-on-accent`。
- Moodle 数据边界不变：**冷启动不读盘**（Y0 隐私口径），今日页显示"未同步"入口；同步后回到今日页自动更新。

### 6.4 已知限制（不冒充已完成）

- **今日课表需要登录**：本机会话在验收中过期且没有可用账号，因此"当日有课"的真机截图未取到；
  该分支由 Jest 用例（今日课表全量/空态/加载/错误）覆盖。未登录时该段显示权限 `ErrorState`
  （含"切换账号后重试"），这是既有错误文案，不是今日页新造。
- **Moodle 待交需先打开 `system/moodle` 同步**：冷启动不读盘是 Y0 隐私口径，登记为 **TD-78**。
- **独立页面无顶部返回按钮**：依赖 Android 系统返回 / iOS 侧滑返回（本批出界，见 §5）。
- **校徽用官方原色**（`#112D66`），与品牌 token 蓝 `#173874` 存在 6–10 级色差；未擅自重上色，
  来源与处理见 [`app/assets/brand/SOURCE.md`](../../../app/assets/brand/SOURCE.md)。
- 深色主题的校徽走反白变体（`xmu-emblem-light.png`），但**深色主题截图未取**（模拟器为亮色）。
