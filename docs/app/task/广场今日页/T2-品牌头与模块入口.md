# T2 · 品牌头 + 4 个模块入口 + `Screen.header`

## 1. Where this task sits

- **Phase 广场今日页**，目标：广场顶部不再是 `Square` 面包屑，而是品牌头 + 常驻模块入口。
- **本任务移入** `R3 品牌头` 与 `R4 四个模块入口`：容器侧只加一个"自定义顶栏"插槽，视觉全部是新特性组件。
- **Starts after**：无。**Waits on it**：`T4 广场骨架改造`。

## 2. What the developer needs to know

**Read first**

- `app/src/components/ui/Screen.tsx` — 安全区唯一容器；`headerPaddingTop` 已算好，插槽只能挂在它下面。
- `app/src/features/navigation/tabConfig.ts` — `getTabByPath` 与一级路由口径（入口是 push 不是切格）。
- `app/src/components/ui/Icon.tsx` — `IconTint` 枚举；本任务需要新增 `onAccent`。
- `app/src/features/square/SquareHome.tsx` — 现有 `Screen` 用法与 `TopTabStrip` 位置。
- `docs/app/task/广场今日页/00-批次总览与施工计划.md` §2 — 排版与配色裁决，别重开。

**Settled**

- 顶栏背景铺到屏幕顶边、内容从 inset 之下开始（宪法 17.2-1）由 `Screen` 负责，⛔ 组件不读 insets。
- 模块入口是**页内功能入口**，不是二级导航；入口注册表只有一份（新增 `squareModules.tsx`）。
- 图标逐子路径导入（宪法 16.5-1）；尺寸只取档位；填充色只取令牌。

**Edges and seam**

- 动 `Screen.tsx`（只加 `header?`，默认行为不变）+ `features/square/` 三个新文件 + `IconTint` 一项。
- 接缝：`Screen.header`、`SquareBrandHeader`、`SquareModuleEntries`、`SQUARE_MODULES`。

**Run**

- `cd app && npx jest --testPathPattern "p3a6-square-(brand-header|modules)"`
- `cd app && npx jest --testPathPattern p0-04-screen`
- `cd app && npx tsc --noEmit`

**Unknowns**

- `expo-image` 读本地 PNG 需要 `require('../../assets/...')` 的模块声明；`tsc` 若报 TS2307，在 `expo-globals.d.ts` 补 `declare module '*.png'`（⛔ 不改素材路径）。
- 校徽素材可能不是正方形 → 组件固定 36dp 方框 + `contentFit="contain"`，⛔ 不裁切变形。

## 3. The workflow

1. 读上述文件，复述本任务一句话。
2. 写 `SQUARE_MODULES` 注册表（4 项：课表 / 校园攻略 / 二手 / 社团；路由、图标、填充色）。
3. 写 `SquareBrandHeader`（校徽 36dp + `XMUM Dorm`），红→绿（文本与 testID）。
4. 给 `Screen` 加 `header` 插槽，用例验证"自定义头出现、无 `广场` 标题、inset 仍由 Screen 施加"。
5. 写 `SquareModuleEntries`（64dp 填充块 + 32dp 图标 + 标签，一行 4 格），红→绿（4 个 push 目标）。
6. 跑用例与 `tsc`，提交。
