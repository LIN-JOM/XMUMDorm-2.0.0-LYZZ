## 1. Where this task sits

- **Phase 2 整条树洞流可连续浏览和筛选**，目标是搜索与浏览有一致的帖子阅读结构。
- **T2-04 搜索结果复用帖子层级**让搜索结果也使用树洞帖子行和详情入口。
- **Starts after**：Phase 1。**Waits on it**：T2-05 集成回归。

## 2. What the developer needs to know

**Read first**

- `app/src/features/campus/CampusSearchScreen.tsx` — 搜索提交和历史。
- `app/src/features/campus/CampusScreens.tsx` — 树洞帖子行与查询分支。
- `app/src/__tests__/p2x-bing-campus-search-ui.test.tsx` — 搜索请求和高亮回归。

**Settled**

- 搜索保留关键词高亮和独立快照。
- 搜索结果使用与树洞流相同的身份、正文、媒体和互动层级。
- 搜索页不复用常规流的标签选择，防止两种筛选状态串联。

**Edges and seam**

- 只改搜索结果渲染分支。搜索输入、历史和详情路由不改。
- Seam：`CampusFeed` 的 `query` 行渲染。

**Run**

- `cd app; npx jest --runInBand p2x-bing-campus-search-ui p2x-bing-campus`。
- `cd app; npm run typecheck`。

**Unknowns**

- 若卡片无法承载高亮节点，保留文字高亮并在卡片中使用同一字段顺序。

## 3. The workflow

1. 阅读第 2 部分，并复述：搜索改变数据范围，不降低帖子信息层级。
2. 为搜索卡片的身份与互动内容写失败用例。
3. 复用树洞行或其字段适配，不新建平行卡片。
4. 保留关键词文字高亮。
5. 验证点击仍进入对应详情。
6. 运行测试和类型检查。
7. 提交本任务。
