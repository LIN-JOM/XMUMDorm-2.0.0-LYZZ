## 2. 这意味着什么

树洞筛选现在使用 `/api/posts/tags` 和既有 `tagId` 请求参数，没有前端伪造标签或本地过滤。
“全部”和每个已访问标签分别保存条目、页码、是否还有下一页和滚动位置。
搜索结果继续保留关键词高亮，同时复用树洞的作者、正文、媒体、点赞和回复层级。

万能墙仍保持匿名投影和独立游标；标签失败时，用户仍可阅读未筛选的树洞流。
