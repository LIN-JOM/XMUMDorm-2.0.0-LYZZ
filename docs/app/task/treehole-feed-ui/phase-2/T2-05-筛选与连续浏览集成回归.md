## 1. Where this task sits

- **Phase 2 整条树洞流可连续浏览和筛选**，目标是筛选、返回和横滑模块切换不中断阅读。

## 2. What the developer needs to know

**Read first**

- `app/src/__tests__/p2x-bing-campus.test.tsx` — 树洞、万能墙和状态回归。
- `app/src/__tests__/p2x-bing-campus-search-ui.test.tsx` — 搜索独立状态回归。
- `app/src/__tests__/p3a5-square-integration.test.tsx` — 首页横滑容器回归。
- `app/src/features/square/SquareHome.tsx` — 模块切换不卸载已访问内容。

**Settled**

- 万能墙匿名投影和其独立游标不改。
- 全局发布入口仍是唯一发布入口；不加树洞 FAB。

**Edges and seam**

- 只添加或修正本阶段测试。首页模块实现与后端不改。
- Seam：标签化 `CampusFeed`、搜索页和广场横滑容器。

**Run**

- `cd app; npx jest --runInBand p2x-bing-campus p2x-bing-campus-search-ui p3a5-square-integration`。
- `cd app; npm run typecheck; npm run rulers`。

**Unknowns**

- 真机手势和读屏不能由 Jest 证明；将它们列给 Phase 3，而不伪造结果。

## 3. The workflow

1. 阅读第 2 部分，并复述：筛选不能改变匿名和模块边界。
2. 写筛选切换、返回和追加的集成用例。
3. 运行树洞、搜索和广场专项测试。
4. 运行类型和设计规则检查。
5. 记录自动验证不能覆盖的真机项目。
6. 提交本任务。
