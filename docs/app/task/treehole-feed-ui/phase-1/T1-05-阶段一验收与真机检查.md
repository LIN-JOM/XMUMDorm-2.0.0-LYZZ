## 3. The workflow

1. 阅读第 2 部分，并用一句话复述本任务。
2. 运行完整自动化验证，产出命令与结果记录。
3. 用 Expo Go 打开局域网开发服务，产出目标设备与构建信息。
4. 检查树洞多图横滑、广场横滑、纵向滚动和返回详情，产出逐项观察。
5. 检查读屏标签、触控目标和万能墙匿名边界，产出通过或待处理结论。
6. 按 `easy-summary` 写阶段总结，运行 Run 中命令并提交本任务。
