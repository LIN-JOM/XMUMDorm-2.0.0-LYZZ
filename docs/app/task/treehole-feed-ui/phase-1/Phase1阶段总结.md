## 2. What it means

树洞流现在复用一个帖子域卡片，而不是再维护一套业务卡片；这让媒体、无障碍语义和令牌仍由原有 App
组件体系管理。点赞逻辑已从详情动作中提取为共享最小单元，列表不会因此加载评论；万能墙继续在投影层清除作者、标题和媒体身份信息。

`npm run typecheck` 与 `npm run rulers` 通过。完整串行验证未全绿，原因见下节。
