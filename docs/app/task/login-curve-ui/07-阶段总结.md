## 2. 变化的意义

登录沿用原会话和令牌存储链路，只重排页面与辅助入口。
表单高度和可用视口决定上方留白，小视口优先收起留白，再允许滚动。
所有颜色来自主题令牌；两层同 canvas 底色，未加入 Logo、渐变或品牌头。
