# 验证并交接

## 1. 任务位置

Phase 2 草图对齐：以源码预览证明修正效果。
覆盖 R-1 还原草图比例、R-2 收紧登录区、R-3 可信预览。
依赖布局提交完成；不把浏览器截图当原生截图。

## 2. 开发入口

阅读：
- docs/app/task/login-curve-ui/10-修正计划.md — 验收项有哪些？
- app/src/__tests__/login-curve-ui.test.tsx — 交互是否回归？
- docs/app/task/login-curve-ui/09-验证记录.md — 原有证据缺口是什么？

已定：Markdown；交接与验收分开；保留用户 y8 草稿。
接缝：既有测试、源码组件预览及双轴审核。
运行：npm.cmd run typecheck；npm.cmd run lint；相关 Jest 用例。
未知：模拟器不可用时明确原生验证缺口。

## 3. 工作流

1. 阅读计划，列出需要证据的验收项。
2. 验证深浅主题、输入及布局尺寸。
3. 运行既有回归与静态检查。
4. 保存截图与记录。
5. 完成 easy-summary 交接并提交。
6. 对提交差异执行 easy-audit，修复可复现问题。

## 4. 验证案例

| 输入 | 期望 | 接缝 |
|---|---|---|
| 浅色与深色 | 相同构图、输入可见 | 浏览器组件 |
| 标签和值 | 输入后标签不消失 | 登录组件 |
| 既有会话测试 | 成功失败链路通过 | Jest |
| 原生证据缺失 | 报告不宣称真机完成 | 交接 |
