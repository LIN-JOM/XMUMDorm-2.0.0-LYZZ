## 偏差来源

原预览将 390×844 的画布高度限制为面板高度减 110。
在 466×686 面板中，实际画布变成 390×576，而宽度未同步缩放。
登录布局随后从剩余高度中减去整份表单，导致顶部留白消失。
外置标签、大标题及重复说明进一步抬高了表单。

## 预览修正

本地工具位于 app/.scratch/login-preview，不进入生产包。
改为 390×708 的固定画布，与草图的 540×980 接近同一比例。
窄面板只缩放整个画面；布局宽高不随预览缩放变化。
直接加载正式 LoginScreen；只有会话与路由使用预览适配，不发送账号。
