# 登录曲面 UI 实施计划

日期：2026-10-20。基线：`71355830`，分支：`dev-yps`。
本计划依据用户确认的双层草图，替代旧 y8 计划中的品牌头和卡片布局；旧文件保留原样。

## 1. 需求

- R-1 双层曲面：上方空白、下方凸曲面承载登录表单，背景层暂不放 Logo。来源：用户草图。
- R-2 纵向表单：下划线输入、蓝色主按钮、注册次按钮、找回密码及条款入口。来源：确认设计图。
- R-3 登录仍可用：保留错误、过期提示、提交及跳转；适配键盘、小屏、深浅主题。来源：现有链路。

## 2. 逐项方案

### R-1 双层曲面

- 方案：保留空背景层；表层顶部用现有 SVG 依赖绘制中间隆起、两端下落的曲线。
- 范围：登录页布局；两层均消费 canvas 主题令牌。
- 验证接缝：登录页实际渲染与设备截图。
- 验收：[ ] 顶部无文字图案；[ ] 曲面方向符合草图；[ ] 深浅两层同底色。
- 难点：上方留白不能挤出表单，按实际内容和可用高度缩短。

### R-2 纵向表单

- 方案：复用既有输入、按钮、文字与图标原语，不再横排三个按钮。
- 范围：登录页装配；共享控件默认样式不变。
- 验证接缝：登录页面的密码切换、次级入口与法务导航。
- 验收：[ ] 下划线输入及纵向主次按钮；[ ] 密码切换不丢值；[ ] 四个辅助入口可导航。
- 难点：标签外置保留无障碍；主按钮仅在本页去掉硬偏移，以符合确认稿。

### R-3 登录仍可用

- 方案：安全区与键盘由 Screen 负责；内容测高决定留白；窄屏与放大字号时可滚动。
- 范围：保留会话接口与令牌层，不改后端。
- 验证接缝：既有登录会话用例及页面交互测试。
- 验收：[ ] 登录成功/失败与必填校验通过；[ ] 重复提交受阻；[ ] 小屏与键盘可到达表单；[ ] 类型、lint、规则通过。
- 难点：没有连接设备时，明确区分自动化和设备验证证据。

## 3. Phase 1 登录页按草图落地

目标：在双层曲面下完成一次登录，并保留全部辅助入口。
涵盖：R-1 双层曲面、R-2 纵向表单、R-3 登录仍可用。

- 接入双层曲面布局并保留既有登录提交链路。
- 改为纵向下划线表单并接通密码切换及法务入口。
- 完成回归、视觉检查、交接与双轴验收。

证明：登录会话及新增交互测试通过；设备可用时保存实际截图；文档记录验证范围。
范围外：Logo 制作、注册/重置页重做、后端条款同意逻辑、全局配色调整。
