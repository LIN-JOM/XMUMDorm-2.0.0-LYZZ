## 2. 开发入口

阅读：
- app/.scratch/login-preview/index.html — 哪条高度限制压矮画布？

已定：画布 390×708；整体缩放；不连接真实登录；本地工具不提交。
接缝：实际预览 DOM 尺寸；记录诊断于验证文档。
运行：浏览器检查画布尺寸；最终 npm.cmd run typecheck。
未知：若组件兼容失败，明确记录，不用设计图代替源码预览。

## 3. 工作流

1. 阅读入口，用一句话确认失真原因。
2. 改为固定尺寸画布。
3. 缩放整幅画面，保留可读控制条。
4. 记录 DOM 尺寸及诊断。
5. 提交诊断记录。
