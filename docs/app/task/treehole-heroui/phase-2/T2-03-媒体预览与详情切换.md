## 1. Where this task sits

- **Phase 2 一套帖子组件贯通列表与详情**，目标是媒体行为随变体正确切换。
- **R-7 列表静态预览、详情同源切换**落地媒体组件。
- **Starts after**：T2-01。**Waits on it**：T2-05。

## 2. What the developer needs to know

**Read first**

- `app/src/components/ui/MediaGrid.tsx` — 单图及栅格语义。
- `app/src/components/ui/MediaCarousel.tsx` — 当前切图行为和无障碍标签。
- Web 树洞媒体实现 — 详情交互的同源参考。

**Settled**

- 列表多图只显示静态叠卡和数量。
- 详情才提供按钮、拖拽、回弹和预览。
- 系统减弱动效时保留切换，不播放位移动画。

**Edges and seam**

- 触及树洞媒体组件，不修改公共 `MediaCarousel`。
- Seam：`TreeholeMedia` 的 `mode` 属性。

**Run**

- `npm test -- treehole-media --silent`
- `npm run typecheck`

**Unknowns**

- 若 Web 动效无法映射 HeroUI，优先保证顺序和无障碍。

## 3. The workflow

1. 阅读第 2 节，并复述：列表不可切图，详情可以切图。
2. 写三图列表无切换控件的失败测试。
3. 写详情循环顺序、按钮和预览入口的失败测试。
4. 实现静态叠卡和详情媒体控制器。
5. 实现减弱动效分支。
6. 运行测试和类型检查。
7. 提交。
