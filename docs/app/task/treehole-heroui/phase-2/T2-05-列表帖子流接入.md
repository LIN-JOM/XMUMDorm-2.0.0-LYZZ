## 2. What the developer needs to know

**Read first**

- `app/src/features/campus/CampusScreens.tsx` — `CampusFeed` 分页和路由。
- `app/src/features/campus/CampusSearchScreen.tsx` — 搜索对 `CampusFeed` 的复用。
- `app/src/features/campus/useCampusActions.tsx` — 列表点赞入口。

**Settled**

- confession 列表使用紧凑帖子变体。
- 多图列表没有切图、预览或拖拽入口。
- 筛选、分页、缓存和 wall 路径不变。

**Edges and seam**

- 接入 `CampusFeed` 的 confession 行渲染。
- Seam：单条 `row` 到列表版帖子组件。

**Run**

- `npm test -- p2x-bing-campus p2x-bing-campus-search --silent`
- `npm run typecheck`

**Unknowns**

- 若行高影响滚动恢复，保留现有测试并停止扩展范围。

## 3. The workflow

1. 阅读第 2 节，并复述：列表只显示静态媒体预览。
2. 写 confession 行使用列表变体的失败测试。
3. 替换 confession 行视觉，保留按压进入详情。
4. 断言 wall 行和搜索数据路径不变。
5. 覆盖纯文字、长文和三图列表。
6. 运行测试和类型检查。
7. 提交。
