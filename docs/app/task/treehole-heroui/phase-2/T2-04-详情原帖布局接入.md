- `app/src/features/campus/CampusScreens.tsx` — 详情加载、路由和报告边界。
- `app/src/features/campus/useCampusActions.tsx` — 点赞和评论能力边界。
- `app/src/features/campus/useCampusReport.ts` — 举报边界。

**Settled**

- 只替换 confession 详情的原帖视觉。
- `wall`、发布页、报告和动作 hooks 不重写。
- 现有 API 与路由参数保持不变。

**Edges and seam**

- 接入点是 `CampusDetailScreen` 的 confession 正文。
- Seam：详情拿到 `post` 后的内容区域。

**Run**

- `npm test -- p2x-bing-campus --silent`
- `npm run typecheck`

**Unknowns**

- 若旧详情动作依赖布局节点，保持其回调不变。

## 3. The workflow

1. 阅读第 2 节，并复述：只迁移树洞详情原帖视觉。
2. 写 confession 使用业务组件、wall 不使用的失败测试。
3. 接入详情版 `TreeholePost` 和详情媒体。
4. 保留原有加载、错误、点赞、评论和报告入口。
5. 覆盖长文和三图详情。
6. 运行测试和类型检查。
7. 提交。
