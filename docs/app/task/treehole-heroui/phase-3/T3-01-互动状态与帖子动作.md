## 1. Where this task sits

- **Phase 3 讨论和反馈完成闭环**，目标是新详情页保留真实互动语义。
- **T3-01 互动状态与帖子动作** 将真实点赞状态和计数接到 HeroUI 帖子动作。
- **Starts after**：Phase 2 帖子组件。**Waits on it**：T3-05 互动回归。

## 2. What the developer needs to know

**Read first**

- `app/src/features/campus/useCampusActions.tsx` — 点赞锁、认证和计数的唯一真源。
- `app/src/features/campus/TreeholePost.tsx` — 详情动作的公开接缝。
- `app/src/features/campus/CampusScreens.tsx` — 详情将状态传给帖子的地方。
- `app/src/__tests__/p2x-bing-campus.test.tsx` — 点赞和详情既有行为。

**Settled**

- `useCampusLike` 不重写；成功响应和刷新结果仍是唯一真源。
- 计数缺失显示占位，不能在客户端推算。

**Edges and seam**

- 接缝是 `TreeholePost` 的 `onLike` 与展示 props；不改 API 或列表请求。

**Run**

- `npm test -- p2x-bing-campus.test --silent`。
- `npm run typecheck`。

**Unknowns**

- 若 HeroUI 动作控件无法暴露既有 testID，停止并记录兼容限制。

## 3. The workflow

1. 阅读第 2 部分并复述：详情动作只显示已有互动状态。
2. 写 case 1 的失败测试，断言真实 liked 状态传入详情帖子。
3. 最小化接通 `useCampusActions` 的互动 props 并运行测试。
4. 写 case 2 的失败测试，断言缺失计数保持占位。
5. 保留请求锁并让测试通过。
6. 运行命令并提交。
