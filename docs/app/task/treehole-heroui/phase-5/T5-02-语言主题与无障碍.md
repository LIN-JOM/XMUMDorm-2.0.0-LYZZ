## 2. What the developer needs to know

**Read first**

- `app/src/features/campus/TreeholePost.tsx` — 业务组件可见文案。
- `app/src/i18n/zh.ts` — 中文词条来源。
- `app/src/i18n/en.ts` — 英文词条来源。

**Settled**

- 不新增页面内硬编码中英文；无替代文本的图片保持装饰语义。

**Edges and seam**

- 接缝为树洞业务组件 props；不改全局语言系统。

**Run**

- `npm test -- p2x-bing-campus.test p2x-bing-campus-search-ui.test --silent`。
- `npm run typecheck`。

**Unknowns**

- TalkBack 和 200% 字号需要 Android 真机检查。

## 3. The workflow

1. 阅读第 2 部分并复述：所有树洞可见词语必须可翻译。
2. 写英文帖子的失败测试。
3. 把硬编码业务文案移到 labels 或 i18n。
4. 检查控件无障碍标签。
5. 运行验证并提交。
