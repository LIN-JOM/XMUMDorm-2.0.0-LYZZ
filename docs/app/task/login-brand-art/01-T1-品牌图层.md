# 接入品牌图层

## 1. 任务位置

Phase 1 品牌登录可操作。推进 R-1 品牌图层，并验证 R-2 边缘玻璃的素材接缝。
本任务先行；素材需无文字控件，后续材质适配依赖它。
不将整张设计图伪装成交互页面。

## 2. 开发入口

阅读：
- app/src/features/auth/LoginLayout.tsx — 装饰放在哪层？
- app/assets/brand/SOURCE.md — 资源来源如何登记？
- app/src/app/login.tsx — 表单从哪里开始？

已定：使用确认稿的角色和浅绿背景；本地打包；装饰不拦触摸。
接缝：既有登录渲染与实际截图；复用现有 Image/SVG 依赖。
运行：npm.cmd run typecheck；npm.cmd exec -- eslint src/features/auth/LoginLayout.tsx。
未知：若提取图仍带控件，重新提取，不以裁切遮掩账号输入。

## 3. 工作流

1. 阅读入口，确认背景与真实控件的边界。
2. 提取不含控件的装饰素材。
3. 保存素材及来源记录。
4. 接入登录页并打开真实组件预览。
5. 确认角色不挡操作后提交。
