# 两侧边缘与清晰度修正

日期：2026-10-21。基线：e36fee31。来源：用户指出两侧无材质、顶部插画发糊。

## 1. 需求

- R-1 连续边缘：顶部玻璃延续到表单左右两侧，中央仍为实色。
- R-2 清晰插画：检查原图、采样及预览缩放，保留角色与原构图。
- R-3 可操作：装饰不挡触摸或朗读，窄屏、横屏及原登录行为继续正常。

## 2. 方案

### R-1 连续边缘

- 方案：用原生 SVG 窄幅镜像渐变延续反光边；限制在字段外侧留白内。
- 范围：登录专用装饰，不改共享输入与按钮。
- 接缝：真实页面截图、现有登录布局回归。
- 验收：[ ] 左右边缘均可见；[ ] 中央完全实色；[ ] 深浅主题都衔接。
- 难点：控制反光宽度，避免形成整条浓色竖带。

### R-2 清晰插画

- 方案：先对照原尺寸预览，消除二次缩小；原生图片明确高质量缩放。
- 范围：登录图片及本地预览；只有原图仍不清晰时才重新制作素材。
- 接缝：原图检查、浏览器尺寸与图片属性、同尺寸截图。
- 验收：[ ] 原尺寸预览可用；[ ] 图片无模糊滤镜；[ ] 原构图与角色保留。
- 难点：不把缩略预览的软化误认为原生图像采样问题。

### R-3 可操作

- 方案：边缘装饰不接收事件、不进入无障碍树；复跑现有回归及构建。
- 范围：现有登录组件；保留既有真机证据缺口。
- 接缝：相关 3 套回归、类型、lint、Android 导出。
- 验收：[ ] 相关回归通过；[ ] 窄屏与横屏截图可用；[ ] 类型、lint、导出通过。
- 难点：没有可用原生设备，不能用浏览器证明真机效果。

## 3. Phase 2 边缘连续且可清楚查看

涵盖：R-1 连续边缘、R-2 清晰插画、R-3 可操作。
目标：从顶部拱边到两侧都能看见材质，并能以原尺寸检查插画。

- 补齐两侧窄幅渐变并对照浅深截图。
- 修正图片采样与预览缩放。
- 完成检查、交接及双轴验收。

证明：同尺寸前后截图、相关回归和 Android 导出通过。
范围外：动态光学折射、注册重置页、后端及新组件库。
