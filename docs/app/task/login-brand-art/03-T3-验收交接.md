# 验证并交接

## 1. 任务位置

Phase 1 品牌登录可操作，覆盖本批全部需求。
依赖实现提交；不把浏览器截图当原生截图。

## 2. 开发入口

阅读：
- docs/app/task/login-brand-art/00-实施计划.md — 验收项是什么？
- app/src/__tests__/login-curve-ui.test.tsx — 既有行为是否正常？
- app/assets/brand/SOURCE.md — 资源是否能离线分发？

已定：Markdown；交接与验收分开；原有 y8 草稿保留。
接缝：既有测试、源码截图和 Android 导出。
运行：npm.cmd run typecheck；npm.cmd run lint；npm.cmd run rulers；npm.cmd exec -- expo export --platform android --output-dir .scratch/login-brand-export。
未知：无可用设备时明确原生视觉验证缺口。

## 3. 工作流

1. 阅读计划，确认所有验收项都有证据位置。
2. 保存深浅、窄屏与英文截图。
3. 运行相关回归及规定检查。
4. 完成 Android 导出。
5. 写 easy-summary 交接并提交。
6. 按 easy-audit 对固定提交差异并行审核。
