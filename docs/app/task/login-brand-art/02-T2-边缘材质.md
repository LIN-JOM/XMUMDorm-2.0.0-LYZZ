# 完成边缘材质与适配

## 1. 任务位置

Phase 1 品牌登录可操作。推进 R-2 边缘玻璃和 R-3 真实登录。
依赖品牌素材；不改变共享组件和会话接口。

## 2. 开发入口

阅读：
- app/src/features/auth/LoginLayout.tsx — 圆拱和表单高度怎样相接？
- app/src/__tests__/login-curve-ui.test.tsx — 哪条旧空白断言需随品牌图更新？
- app/src/components/ui/Screen.tsx — 键盘及安全区由谁负责？

已定：只有边缘玻璃化，中央不透明；低圆拱、平面按钮与真实表单保留。
接缝：既有登录测试及源码预览；不另造会话层。
运行：npm.cmd test -- --runInBand --cacheDirectory .scratch/jest-preview src/__tests__/login-curve-ui.test.tsx；npm.cmd run typecheck。
未知：小屏优先保证输入与提交可达，原生设备证据仍待补。

## 3. 工作流

1. 阅读入口，确认材质不得进入表单中心。
2. 更新受品牌装饰影响的既有回归。
3. 完成深浅主题的边缘衔接。
4. 检查常规、窄屏与英文布局。
5. 运行相关回归后提交。
