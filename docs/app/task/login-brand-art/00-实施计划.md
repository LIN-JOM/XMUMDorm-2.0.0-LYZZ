# 品牌登录设计落地计划

日期：2026-10-21。基线：8958ad71。分支：dev-yps。
来源：用户确认 exec-9d222077-bb66-4b5c-b46b-4f8fb3b39f16.png 并要求代码实现。

## 1. 需求

- R-1 品牌图层：浅绿花卉背景、女孩、纯白微笑小羊，小耳朵与简化绒毛。来源：确认稿。
- R-2 边缘玻璃：低圆拱边缘柔和玻璃渐变，中心乳白实色，按钮简洁。来源：最后两次设计反馈。
- R-3 真实登录：输入、密码切换、提交及辅助导航继续可用，窄屏与键盘可达。来源：现有登录链路。

## 2. 逐项方案

### R-1 品牌图层

- 方案：从确认稿提取不含文字控件的装饰素材，随 App 打包；记录素材来源。
- 范围：登录背景与品牌资源。
- 验证接缝：真实登录页面渲染和截图。
- 验收：[ ] 女孩和小羊可见且不遮控件；[ ] 无烘焙的账号文字或按钮；[ ] 离线可加载。
- 难点：不同高度下保持角色与卡片上沿接触。

### R-2 边缘玻璃

- 方案：原生绘图与装饰素材共同呈现边缘折射及渐变，中央保持主题 canvas 的不透明底色。
- 范围：登录专用表层，不改共享组件默认外观。
- 验证接缝：真实页面深浅截图与渲染属性。
- 验收：[ ] 玻璃只在边缘；[ ] 中央及表单清晰实色；[ ] 低圆拱和简洁主次按钮保留。
- 难点：Plasma UI 的 WebGL/DOM 实现不能直接用于原生 App，需要还原视觉而非接入网页运行时。

### R-3 真实登录

- 方案：复用原会话、输入、导航和安全区；装饰不接收触摸、不参与朗读，高度不足时整幅收起。
- 范围：登录布局和现有回归，不改变后端。
- 验证接缝：既有登录、控件、会话测试及组件预览。
- 验收：[ ] 登录回归通过；[ ] 小视口可滚动；[ ] 类型、lint、设计尺子与 Android 导出通过。
- 难点：当前缺原生设备，明确记录键盘及安全区证据缺口。

## 3. Phase 1 品牌登录可操作

目标：看到确认稿中的角色与边缘材质，并能使用真实登录表单。
涵盖：R-1 品牌图层、R-2 边缘玻璃、R-3 真实登录。

- 提取装饰素材并接入真实登录布局。
- 完成边缘渐变、表单衔接与适配。
- 回归、保存截图并完成交接和双轴验收。

证明：源码预览与相关回归、类型、lint、设计尺子和 Android 导出通过。
范围外：注册/重置页重做、后端变更、Plasma WebGL 运行时、动态物理折射与动画。
