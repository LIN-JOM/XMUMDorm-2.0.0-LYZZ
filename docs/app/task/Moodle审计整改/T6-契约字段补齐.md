# T6 契约字段补齐（AJAX 部分）

## 1. 任务位置

- Phase B 收掉审计里不依赖真机的四项，目标见 [第二批总览](08-第二批总览.md)。
- 本任务推进 P-6 契约字段补齐：把 `core_course_get_enrolled_courses_by_timeline_classification`、
  `core_courseformat_get_state` 已返回、但投影层没取的 7 个字段补进契约。
- 起始：无前置。后续：T7 维护窗口（同动宿主）。缺陷：D-6 提取对象契约缺 19 个字段（严重，本任务收 7 个）。

## 2. 开发者需要知道

**Read first**

- `app/src/features/tools/moodle/contract.ts` — 三个投影分别在哪、哪些字段已有、兼容写法是什么？
- `app/src/__tests__/fixtures/moodle/*.json` — 合成样本能扩哪些官方字段？
- `app/src/__tests__/p3y0-moodle-contract.test.ts` — 现有字段断言与失败分支。
- `app/src/__tests__/fixtures/moodle/README.md` — 官方来源 URL 的记法。

**Settled**

- 字段名与类型以官方 4.5 导出器为准；来源写进 `contract.ts` 注释（`course_summary_exporter` 的 `isfavourite`/`progress`、
  section state 的 `sectionurl`/`visible`/`current`、cm state 的 `hascmrestrictions`/`completionstate`/`isoverallcomplete`）。
- 新字段一律可空/带默认，旧快照恢复不能因缺字段失败（`cache.restoreMoodleSnapshot` 会重放解析）。
- 只补 AJAX 来源的字段；详情 DOM 与 HEAD 字段不在本任务。
- 原始响应与凭据仍不进入契约对象。

**Edges and seam**

- seam：`parseMoodleResponse` 的三条投影分支与 `MoodleCourse/Section/Module` 类型。
- 触 `moodle/contract.ts`、`fixtures/moodle/*.json`、`p3y0-moodle-contract.test.ts`；不动桥、缓存、宿主。

**Run**

- `cd app; npx jest --ci --testPathPattern "p3y0-moodle-contract|p3y0-moodle-cache|p3y3-moodle-sync"`。
- `cd app; npx tsc --noEmit`。

**Unknowns**

- `progress` 只在 `hasprogress === true` 时可信；若校园版本缺 `hasprogress`，进度按 `null` 处理，不猜 0。
- `completionstate` 只在活动被追踪且有完成条件时出现；缺失即 `null`，不写 false。

## 3. 工作流

1. 读四个入口，用一句话复述本任务。
2. 写红测试：课程含 `isfavourite`、`progress` 时投影保留；缺 `hasprogress` 时 progress 为 null。
3. 实现课程两个字段，跑绿。
4. 写红测试：章节 `sectionurl`/`visible`/`current` 与模块 `hascmrestrictions`/`completionstate`/`isoverallcomplete`；再实现。
5. 扩夹具并跑本域测试，确认旧字段与失败分支不变。
6. 分别提交测试与实现。

## 4. 测试用例

| Case | Input | Expected | Seam |
|---|---|---|---|
| 1 | 课程带 `isfavourite: true` | `favourite === true` | courses 投影 |
| 2 | 课程带 `hasprogress: true, progress: 42.6` | `progress === 42` | courses 投影 |
| 3 | 课程无 `hasprogress`、`progress: 88` | `progress === null` | courses 投影 |
| 4 | 章节带 `sectionurl/visible/current` | 三字段原样保留，URL 同源过滤 | state 投影 |
| 5 | 模块带 `hascmrestrictions/completionstate/isoverallcomplete` | `restrictions` 布尔、`completion` 对象 | state 投影 |
| 6 | 模块缺完成字段 | `completion === null` | state 投影 |
