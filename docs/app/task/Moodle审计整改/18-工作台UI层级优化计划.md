# Phase G 第七批计划 · Moodle 工作台 UI 层级

日期：2026-10-20　版本：v1.0　性质：**计划**（不含实现）
上游：[Moodle 模块能力边界审计](../../evaluation/Moodle模块能力边界审计-2026-10-19.md) · [第六批总览](16-第六批总览.md)
下游：`easy-task-act` 逐 phase 出任务书

## 判定

工作台的问题不是配色，是结构：一屏里所有东西都在同一层 —— 课程是按钮墙，类型筛选也是按钮，章节标题用页面标题的字阶抢戏，模块行下面再挂一条整行宽的「打开原页」，截止区把四个桶当裸文本念出来，四态用正文行冒充。用户因此读不出「哪里是状态、哪里是挑选、哪里是内容」。

本计划把工作台拆成**状态 / 课程 / 内容 / 截止**四层，全部复用既有组件，不改数据层、不改行为。成本约 **2 人日**（三个 phase 各 0.5–0.7 人日，详情页与回写 0.5 人日）+ 真机验收 0.5 人日。

**下一步**：批准 Phase 1，先立骨架（tracer bullet），一屏就能看出四层。

## 0. 词汇

| 词 | 含义 |
|---|---|
| 分区 | 一屏内的一段，由分区标题开头 |
| 卡 | 一个分区的内容容器，用表面色与圆角表达层级 |
| 行 | 卡内或分区内的一条，可点进下一步 |
| 工具行 | 屏幕顶部放置同步、取消、进入工作台等动作的横排 |
| 芯片 | 可点选的小标签，只用于筛选 |
| 徽标 | 行内表示类型的短词 |
| 原页动作 | 打开 Moodle 原始页面 |
| 四态 | 加载 / 空 / 错误 / 无网 |

## 2. 逐条做法

### R-1 一屏分四层

- **做法**：把工作台屏幕重排成四段：状态段（工具行 + 相位 + 离线/维护提示）、课程段（当前课程 + 切换 + 芯片筛选）、内容段（章节卡）、截止段（四个桶）。段与段之间用间距档位，段内用卡或表面色。
- **触及**：工作台屏幕；宿主页的截止区从页脚挪进截止段。
- **测试接缝**：工作台屏幕的现有屏幕级测试（渲染完整快照）。不新增接缝。
- **验收**：- [ ] 快照渲染后自上而下能数出四段　- [ ] 每段有且只有一个分区标题　- [ ] 段间不靠分隔线也能看出边界
- **难点**：章节多（一门课十来个）时内容段会很长，四段的分界在长滚动里是否还看得出来。

### R-2 标题只留一级

- **做法**：删掉页内页面标题字阶的元素与入口说明行；同步 / 取消 / 进入工作台 / 清除数据收进一条工具行，主次用按钮变体区分。系统名与页面标题只由顶栏画一次。
- **触及**：工作台屏幕、宿主页顶部行、词条层（若需新短标签）。
- **测试接缝**：工作台屏幕现有测试里的按压与文案断言。
- **验收**：- [ ] 页内没有页面标题字阶的元素　- [ ] 工具行只含动作，不含说明文字　- [ ] 顶栏不再重复同一系统名
- **难点**：`清除 Moodle 数据` 是破坏性动作，收进工具行后不能和主行动一样显眼，也不能藏到看不见。

### R-3 课程切换一个控件

- **做法**：课程段上方给一句当前课程名（可换行、不截断），下面给一个切换动作，点开列出全部课程；选中后类型筛选重置回「全部类型」，内容回到顶部。
- **触及**：工作台屏幕课程段；词条层（切换课程、当前课程）。
- **测试接缝**：工作台屏幕现有测试（切课后断言模块集合变化）。
- **验收**：- [ ] 当前课程名两行内完整显示，无省略号　- [ ] 21 门课都能选到　- [ ] 切课后类型筛选回到全部类型
- **难点**：切换控件的形态（横滚芯片还是底部选择器）属页面级布局，须所有者或真机定；本计划先按横滚芯片做，形态变化不算返工。

### R-4 筛选用芯片

- **做法**：类型筛选改成一行横向可滚的芯片，选中态用芯片自己的选中样式；「全部类型」是第一枚。
- **触及**：工作台屏幕课程段；复用既有芯片组件。
- **测试接缝**：现有测试按测试标识按压 `moodle-type-*`；选中态断言新增。
- **验收**：- [ ] 筛选是芯片不是按钮　- [ ] 一行内横滚，不换行成多排　- [ ] 选中态与未选中态可分辨
- **难点**：类型多时（十种以上）横滚的可发现性 —— 首屏要能看出还能往右滑。

### R-5 章节成卡、行内带徽标

- **做法**：章节标题升为卡头，模块行放卡内；行尾放类型徽标，原页动作收进行内（行尾动作或第二个小动作），不再整行宽。
- **触及**：工作台屏幕内容段；复用行、章节头、卡、徽标。
- **测试接缝**：现有测试（`moodle-module-*` 与 `moodle-original-*` 的按压）。
- **验收**：- [ ] 每个章节一张卡　- [ ] 每行有类型徽标　- [ ] 原页动作不占整行　- [ ] 行仍可点进详情
- **难点**：徽标与「详情」入口在同一行时，行尾点谁要一眼分清；章节卡是否折叠属新交互，本轮不做。

### R-6 截止区独立分区

- **做法**：截止区从宿主页页脚收进工作台屏幕的截止段；四个桶各有小标题与行，空桶整段不渲染，全空给一句空态；提醒状态留在段内。
- **触及**：工作台宿主（截止区从页脚挪进屏幕）、工作台屏幕截止段、词条层。
- **测试接缝**：宿主测试（既有的截止分区断言）。
- **验收**：- [ ] 四个桶各有标题与行　- [ ] 空桶不出现空标题　- [ ] 提醒状态在截止段内　- [ ] 截止段与内容段之间看得出分界
- **难点**：截止数据来自事件与模块两处，桶为空与数据缺失长得很像；提醒状态是异步结果，位置不能跳。

### R-7 四态归位

- **做法**：加载在内容段给骨架；空态分「首次无数据」与「筛选无结果」两种，各有各的动作；错误用页内提示条带一个动作；无网用提示条，不占主滚动。
- **触及**：工作台屏幕状态段与内容段；复用既有提示条、加载、空态组件。
- **测试接缝**：现有屏幕测试（空态、错误态断言）+ 四态用例。
- **验收**：- [ ] 加载时内容段有占位，不是空白　- [ ] 两种空态文案与动作不同　- [ ] 错误给出一个可执行动作　- [ ] 离线提示不挤走内容
- **难点**：现在两个空态共用同一个测试标识，拆分会让既有断言失败，需要同步改测试；相位与空态会同时成立，要定优先级。

### R-8 详情页同层级

- **做法**：详情页页头收成一行（返回图标 + 标题 + 原页动作）；元信息成组（作业状态、时间、锁定）；文件从三行一段变成一行一条；公告、帖子、作业、文件夹、资源五类共用同一层级。
- **触及**：详情屏幕；词条层（返回、原页）。宿主页的详情回退行同步收敛。
- **测试接缝**：详情屏幕的现有屏幕测试；宿主详情流程测试。
- **验收**：- [ ] 页头只占一行　- [ ] 文件是一条一行　- [ ] 五类详情首屏都能看出层级　- [ ] 返回与原页各只有一个入口
- **难点**：五类信息结构不同却要共用一个层级，容易做成一张「字段平铺」的清单。

### R-9 行为不变、可回滚

- **做法**：只动展示层（屏幕、宿主页布局、词条），不碰同步、缓存、桥接、合同。测试标识保留，语义变化处同步改断言；四个 phase 各自独立可回滚。
- **触及**：屏幕与宿主页；词条层（新增短标签需中英齐平）。
- **测试接缝**：既有屏幕级测试 + 四把尺子 + 类型检查，全部沿用。
- **验收**：- [ ] `npm run verify` 全绿　- [ ] 同步、选课、打开原页、详情回调行为不变　- [ ] 每个 phase 单独提交可回滚　- [ ] 新增文案中英齐平且按钮短标签 ≤6 汉字
- **难点**：词条契约是共享的（类型 + 中英两份），改一处会牵动宿主页的类型检查。

## 3. 阶段

### Phase 1 工作台先立层

**覆盖**：R-1 一屏分四层、R-2 标题只留一级、R-4 筛选用芯片。

**目标**：打开工作台，一屏能数出状态 / 课程 / 内容三层，标题不再打架，类型筛选是一行芯片。

**任务**

- 用既有分区标题与卡搭出三层骨架，接真实快照跑通（tracer bullet）
- 把同步、取消、进入工作台、清除数据收进一条工具行
- 删掉页内页面标题字阶与入口说明行，章节标题降到分区标题
- 把类型筛选从按钮换成一行横滚芯片
- 补屏幕测试：段顺序、芯片选中态、工具行动作

**证明**：工作台屏幕测试全绿；`npm run verify` 与四把尺子绿；真机一张截图（长课程名 + 21 门课）。
**不在这里**：课程切换形态、章节卡、截止区、详情页、四态重排。

### Phase 2 课程与内容

**覆盖**：R-3 课程切换一个控件、R-5 章节成卡、行内带徽标。

**目标**：当前课程全名常显，切课一次点；每个章节是一张卡，模块行带类型徽标与原页动作。

**任务**

- 课程段换「当前课程名 + 切换」控件，点开列出全部课程（tracer bullet）
- 切课后类型筛选回「全部类型」并把内容滚回顶部
- 章节改成一卡一段：卡头章节名、卡内模块行
- 模块行加类型徽标，原页动作收进行内
- 真机回归：21 门课、长课程名、十来个章节的课程

**证明**：工作台屏幕测试全绿；真机截图两张（课程段、章节卡）。
**不在这里**：章节折叠、课程搜索、跨课程收藏。

### Phase 3 截止区与四态

**覆盖**：R-6 截止区独立分区、R-7 四态归位。

**目标**：截止区成为独立分区，四个桶各有行；加载、空、错误、无网各有自己的位置。

**任务**

- 截止区重写为四桶分区：待办 / 已过期 / 远期异常 / 无截止（tracer bullet）
- 空桶不渲染，全空给一句空态；提醒状态挪进截止段
- 把截止区从宿主页页脚挪进工作台屏幕的截止段
- 四态归位：骨架、两类空态、错误提示条、无网提示条
- 拆开重复的空态测试标识，补四态用例

**证明**：宿主测试与工作台屏幕测试全绿；真机截图两张（有截止与无截止）。
**不在这里**：截止排序策略、提醒送达验证（设备项）、跨 App 的今日页联动。

### Phase 4 详情页与回写

**覆盖**：R-8 详情页同层级、R-9 行为不变、可回滚。

**目标**：五类详情首屏都能看出层级，文档与证据回写。

**任务**

- 详情页页头收成一行：返回图标 + 标题 + 原页动作（tracer bullet）
- 元信息成组，文件从三行一段改成一行一条
- 五类详情真机回归：公告、帖子、作业、文件夹、资源
- 真机截图四张，与优化前首屏对照
- 把分层写回页面清单的 T-05 行与组件定义的消费表
- 跑 `npm run verify` 与四把尺子，出本批总结

**证明**：详情测试全绿；四张真机截图；`npm run verify` 绿；本批总结文档落盘。
**不在这里**：详情页内附件下载、成绩单页、跨课程聚合。
