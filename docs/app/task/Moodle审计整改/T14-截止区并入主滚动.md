# T14 截止区并入主滚动

## 1. 任务位置

- Phase D 只做两件能立即验的事，目标见 [第四批总览](12-第四批总览.md)。
- 本任务推进 P-11 余项：删掉 `space_6 * 8` 自造尺寸与嵌套滚动，把截止区交给主滚动。
- 起始：T13。后续：无。缺陷：D-11（轻微）。

## 2. 开发者需要知道

**Read first**

- `app/src/features/tools/moodle/WorkspaceHost.tsx:173-192` — 截止 ScrollView 与 `maxHeight`。
- `app/src/features/tools/moodle/WorkspaceScreen.tsx` — 主 ScrollView 在哪、收尾在哪。
- `app/src/__tests__/p3y3-moodle-host.test.tsx` — 截止与提醒状态的断言。
- `docs/app/constitution/App设计宪法.md` 1.4.1 — 尺寸只来自令牌。

**Settled**

- 一屏只保留一个纵向滚动容器；截止区作为工作台滚动的内容尾部（footer 插槽）。
- 不再给截止区设固定高度（自造尺寸消失），行数多时随主滚动。
- 已有 testID 与文案保留（`moodle-deadlines`、`moodle-reminder-status`）。

**Edges and seam**

- seam：`MoodleWorkspaceScreen` 新增 `footer` 插槽；宿主把截止区 JSX 传进去并删除外层 ScrollView。
- 触两个文件与宿主测试；不动行数据结构与提醒回调。

**Run**

- `cd app; npx jest --ci --testPathPattern "p3y3-moodle-host|p3a8-moodle-states|p3y3-moodle-workspace"`。
- `cd app; npx tsc --noEmit`。

**Unknowns**

- footer 传 `ReactNode` 后，宿主内 `theme` 的间距要自己带；若测试按 `maxHeight` 断样式，停下改断言而不是恢复尺寸。
