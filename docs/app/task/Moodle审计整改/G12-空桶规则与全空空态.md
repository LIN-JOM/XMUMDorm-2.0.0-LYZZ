# G12 空桶规则与全空空态

## 1. 本任务的位置

- **Phase 3 截止区与四态**，目标：截止区只显示有内容的桶。
- **本任务推进 R-6 截止区独立分区**：空桶整段不渲染，四个都空时给一句话。
- **开工前置**：G11 截止段由屏幕承载。**等待**：无。

## 2. 开发者需要知道

**先读**

- `app/src/features/tools/moodle/WorkspaceHost.tsx` — 四桶现在无条件拼进视图模型的地方。
- `app/src/features/tools/moodle/WorkspaceScreen.tsx` — 截止段里组与行的渲染位置。
- `app/src/i18n/zh.ts` — 新短文案加在哪，中英要齐平。

**已定**

- 空桶不渲染标题，也不留空白占位。
- 四桶全空且没有其他事件时，截止段给一句话（不塞插画）。
- 新文案 ≤6 汉字，走词条层，不在屏幕里拼。

**边界与接缝**

- 动宿主（过滤空桶）、屏幕（全空分支）、词条层与宿主标签类型。
- 接缝：宿主测试。

**运行**

- `cd app; npm.cmd run test:ci -- --runInBand p3g12`，再 `npm.cmd run typecheck`。

**未知**

- 宿主标签类型是共享的（路由与宿主测试各一份装配），加字段要一次改齐。

## 3. 工作流

1. 读第二节，把本任务复述成一句话。
2. 写失败用例（红）：只有一个桶有数据时，另外三个桶的标题都不出现。
3. 宿主按行数过滤桶；屏幕加全空分支。
4. 加「暂无截止」词条，中英齐平。
5. 用例转绿，跑 `p3y3` / `p3a8` 全组与类型检查。
6. 提交。

## 4. 测试用例

| 用例 | 输入 | 预期 | 接缝 |
|---|---|---|---|
| 1 | 只有一条待办 | 只出现待办桶标题 | 宿主 |
| 2 | 四桶都空 | 出现「暂无截止」一句话 | 宿主 |
| 3 | 四桶都空 | 不出现任何桶标题 | 宿主 |
| 4 | 只有无截止 | 只出现无截止桶 | 宿主 |
| 5 | 词条 | 中英两份都有该短文案 | 词条 |
