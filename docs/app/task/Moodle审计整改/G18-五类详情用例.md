# G18 五类详情用例

## 1. 本任务的位置

- **Phase 4 详情页与回写**，把五类详情的行为钉在测试里。
- **本任务推进 R-8 详情页同层级、R-9 行为不变**：结构改了，五类内容仍各自成立。
- **开工前置**：G16、G17。**等待**：无。

## 2. 开发者需要知道

**先读**

- `app/src/features/tools/moodle/DetailScreen.tsx` — 五类分支现在的结构与测试标识。
- `app/src/__tests__/p3a8-moodle-states.test.tsx` — 既有空态与原页断言，不许破。
- `app/src/__tests__/p3y3-moodle-host.test.tsx` — 宿主详情流程：公告、公告详情、附件原页。

**已定**

- 五类各一条用例：公告列表、公告详情、作业、文件夹、资源。
- 只加断言不改行为；发现缺陷另开任务。
- 详情数据用真实抽取样本形状（字段与真站一致），不自造字段。

**边界与接缝**

- 只动测试文件与本 phase 小结。
- 接缝：详情屏幕测试。

**运行**

- `cd app; npm.cmd run test:ci -- --runInBand p3g18`，再 `npm.cmd run typecheck`。

**未知**

- 真站样本里字段名与本地类型对不上时会暴露类型缺口；先如实记录，不在这个提交里改类型。

## 3. 工作流

1. 读第二节，把本任务复述成一句话。
2. 五类各写一条用例（红按当前结构判断）。
3. 补齐断言直到五条全绿。
4. 跑 `p3a8`、`p3y3` 全组。
5. 类型检查。
6. 提交。

## 4. 测试用例

| 用例 | 输入 | 预期 | 接缝 |
|---|---|---|---|
| 1 | 公告列表（两条） | 两行公告，标题与作者都在 | 屏幕 |
| 2 | 公告详情 | 帖子标题、正文、时间都在 | 屏幕 |
| 3 | 作业 | 状态标签、字段行、附件行都在 | 屏幕 |
| 4 | 文件夹（三个文件） | 三条文件行，原页动作在行内 | 屏幕 |
| 5 | 资源（单文件） | 一条文件行；无文件时给空态 | 屏幕 |
