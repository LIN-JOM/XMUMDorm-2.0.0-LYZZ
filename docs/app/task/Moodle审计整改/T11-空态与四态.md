# T11 空态与四态

## 1. 任务位置

- Phase C 收掉不依赖真机的三项产品化缺口，目标见 [第三批总览](10-第三批总览.md)。
- 本任务推进 P-10 空态与四态：空态给动作，补无网态。
- 起始：T10（同改词条）。后续：无。缺陷：D-10 空态无动作、四态缺无网（轻微，本任务收状态层）。

## 2. 开发者需要知道

**Read first**

- `app/src/features/tools/moodle/WorkspaceScreen.tsx` — 空态现在渲染什么、有哪些动作可用？
- `app/src/features/tools/moodle/DetailScreen.tsx` — 三处空态位置。
- `app/src/features/tools/requestError.ts` — 现有离线判定（`onlineManager.isOnline()`）。
- `app/src/shared/queryClient.ts` — NetInfo 如何接到 `onlineManager`。

**Settled**

- 空态必须给一个动作（宪法 10.2/10.5-5）；空间有限时只给文字与一个动作。
- 无网态用 TanStack `onlineManager` 的订阅读，不引入新依赖。
- 列表/详情复用 `ListScreen`/`proto/P3` 不在本任务（另立任务）。
- 文案只走唯一 `t`。

**Edges and seam**

- seam：`MoodleWorkspaceScreen` 的 cells：`online` 与空态动作；`MoodleDetailScreen` 的空态动作。
- 触两个屏幕、labels 类型、i18n、`system/[id].tsx`、测试；不动 WebView 与缓存。

**Run**

- `cd app; npx jest --ci --testPathPattern "p3a8-moodle-states|p3y3-moodle-workspace|p3y3-moodle-host"`。
- `cd app; npx tsc --noEmit`。

**Unknowns**

- 若 `onlineManager` 在 Jest 里默认在线、订阅回调异步，测试里用 `onlineManager.setOnline(false)` 并在结束时恢复 true。

## 3. 工作流

1. 读四个入口，用一句话复述本任务。
2. 写红测试：离线时屏上出现离线文案；恢复在线后消失。
3. 实现订阅与离线文案，跑绿。
4. 写红测试：没有课程时空态带「同步课程」动作；筛选后无模块带「全部类型」动作。
5. 跑本任务命令。
6. 分别提交测试与实现。

## 4. 测试用例

| Case | Input | Expected | Seam |
|---|---|---|---|
| 1 | `onlineManager.setOnline(false)` | 屏上出现离线文案 | `WorkspaceScreen` |
| 2 | 恢复在线 | 离线文案消失 | 同上 |
| 3 | 快照 ready 但无课程 | 空态 + 「同步课程」动作 | 同上 |
| 4 | 类型筛选后无模块 | 空态 + 「全部类型」动作 | 同上 |
| 5 | 详情无公告 | 空态 + 原页动作 | `DetailScreen` |
