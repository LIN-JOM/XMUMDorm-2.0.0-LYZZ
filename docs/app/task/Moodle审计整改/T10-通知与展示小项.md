# T10 通知与展示小项

## 1. 任务位置

- Phase C 收掉不依赖真机的三项产品化缺口，目标见 [第三批总览](10-第三批总览.md)。
- 本任务推进 P-11 通知与展示小项：删英文兜底、渠道改中性名、按钮缩到 6 字内。
- 起始：无前置。后续：T11（同改词条）。缺陷：D-11 通知与展示层四处小越线（轻微，本任务收三项）。

## 2. 开发者需要知道

**Read first**

- `app/src/features/tools/reminders/native.ts` — `CLASS_LABELS`/`MOODLE_LABELS` 还有谁在用？
- `app/src/features/notifications/permissions.ts` — Android 渠道 ID 与名字在哪、谁注册？
- `app/src/i18n/zh.ts` — `tools.moodle.backToNative` 现在几个字？
- `app/src/__tests__/notification-native-client.test.ts` — 渠道与文案断言。

**Settled**

- 通知文案只来自唯一 `t`，函数不再提供英文默认值（调用方必须传 labels）。
- 渠道是课表与 Moodle 共用，名字必须中性（覆盖两域），ID 同步改。
- 按钮中文 ≤6 汉字（宪法 10.5-3）；较长说明留在正文。
- 尺寸项（`space_6 * 8`）不在本任务：令牌层没有大间距档，登记在 TD-79。

**Edges and seam**

- seam：`replaceMoodleReminders`/`refreshClassReminders` 的 labels 变为必传；渠道常量单点改名。
- 触 `reminders/native.ts`、`features/notifications/permissions.ts`、i18n、两个测试；不动调度器与权限申请流程。

**Run**

- `cd app; npx jest --ci --testPathPattern "notification-native-client|p3a6|p0-03-i18n|p2y-e02"`。
- `cd app; npx tsc --noEmit`。

**Unknowns**

- 若还有调用点没传 labels，停下逐个补，不要恢复默认值。

## 3. 工作流

1. 读四个入口，用一句话复述本任务。
2. 写红测试：渠道 ID/名字为中性值。
3. 改渠道与测试，跑绿。
4. 删英文默认值、调用点补 labels，改按钮文案，跑本域测试。
5. 跑本任务命令。
6. 分别提交测试与实现。
