## 3. 一个环境坑（这次踩到并解决）

上一轮用的 `npx expo start --host localhost` + `adb reverse` 这次失败：App 连的是 `ws://10.0.2.2:8081`，而 Metro 只绑 `127.0.0.1`，红屏 `Unable to load script`。

解决办法：`npx expo start --host lan`（绑 `0.0.0.0`），dev client 用 `xmumdorm://expo-development-client/?url=http%3A%2F%2F10.0.2.2%3A8081`。这条与 2026-10-19 记的 `--host localhost` 不同，下次直接用 lan + `10.0.2.2`。

截图命令要二进制安全：`cmd /c "adb exec-out screencap -p > file.png"`（PowerShell 重定向会写坏 PNG）。
