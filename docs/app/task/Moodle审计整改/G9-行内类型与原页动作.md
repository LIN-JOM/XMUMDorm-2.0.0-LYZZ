# G9 行内类型与原页动作

## 1. 本任务的位置

- **Phase 2 课程与内容**，目标：模块行带上类型徽标，原页动作收进行内。
- **本任务推进 R-5 章节成卡、行内带徽标**的后半：删掉每行下面那条整行宽的「打开原页」。
- **开工前置**：G8 章节卡。**等待**：无。

## 2. 开发者需要知道

**先读**

- `app/src/features/tools/moodle/WorkspaceScreen.tsx` — 模块行下面那条整行宽的打开原页，是这次要收掉的。
- `app/src/components/ui/ListItem.tsx` — 行尾插槽 `trailing` 与行尾次要文案 `meta` 的差别，以及整行语义。
- `app/src/components/ui/Chip.tsx` — 只展示的标签形态（`static`），用来表达模块类型。
- `app/src/components/ui/IconButton.tsx` — 纯图标按钮必须给可读标签，命中区不得小于 48。

**已定**

- 类型用只展示的标签放在行尾，不用会带硬偏移的徽标组件（它会与列表行的层级打架）。
- 原页动作是行尾图标按钮，`moodle-original-<模块 id>` 测试标识不变。
- 点击原页不触发进入详情；点击行本身仍进入详情。

**边界与接缝**

- 只动内容段的模块行；不动详情屏幕（Phase 4 再收）。
- 接缝：屏幕级测试，按行、按原页按钮分别按压。

**运行**

- `cd app; npm.cmd run test:ci -- --runInBand p3g9`，再 `npm.cmd run typecheck`。

**未知**

- 行内嵌套一个可点图标会让读屏出现两个按钮；若测试或评审认为不可接受，改为行尾只留图标、类型走行尾文案。
- 标签高 48 会把行撑高；撑得难看就只在有原页动作的行放标签。

## 3. 工作流

1. 读第二节，把本任务复述成一句话。
2. 写失败用例（红）：行尾有类型标签；原页按钮在行内；按压只触发原页回调。
3. 行尾改为「类型标签 + 原页图标按钮」，删掉整行宽链接。
4. 用例转绿，跑 `p3g`、`p3y3` 全组与类型检查。
5. 提交。

## 4. 测试用例

| 用例 | 输入 | 预期 | 接缝 |
|---|---|---|---|
| 1 | 有 url 的作业模块 | 行尾出现类型标签 | 屏幕 |
| 2 | 同上 | 原页按钮在模块行的后代里 | 屏幕 |
| 3 | 按原页按钮 | 只调用原页回调，不进入详情 | 屏幕 |
| 4 | 按行本身 | 进入详情 | 屏幕 |
| 5 | 没有 url 的模块 | 不出现原页按钮 | 屏幕 |
