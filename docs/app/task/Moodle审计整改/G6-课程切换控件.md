# G6 课程切换控件

## 1. 本任务的位置

- **Phase 2 课程与内容**，目标：当前课程全名常显，切课一次点。
- **本任务推进 R-3 课程切换一个控件**：课程从按钮墙变成「当前课程名 + 切换」。
- **开工前置**：Phase 1 全部提交。**等待本任务**：G7 切课后筛选归零、G9 行内动作都在这份结构上改。

## 2. 开发者需要知道

**先读**

- `app/src/features/tools/moodle/WorkspaceScreen.tsx` — 课程段现在的按钮墙与当前课程的判定方式。
- `app/src/components/ui/ListItem.tsx` — 课程列表每行用哪条行原语，行上哪些语义已由它承担。
- `app/src/i18n/zh.ts` — 「切换课程」这类短标签加在哪，中英两份要齐平。

**已定**

- 当前课程名用分区内标题字阶，允许换行，⛔ 不用省略号掩盖放不下。
- 切换是屏内展开的列表，不是底部选择器（形态留给真机再定）。
- 测试标识 `moodle-course-<id>` 保留，只是从按钮移到列表行上。

**边界与接缝**

- 只动工作台屏幕课程段与词条层（新增一个短标签）。
- 接缝：屏幕级测试。不新增接缝。

**运行**

- `cd app; npm.cmd run test:ci -- --runInBand p3g6`，再 `npm.cmd run typecheck`。

**未知**

- 长课程名换行会占两行，切换按钮可能被挤到第二行；若挤到第二行后不像一个动作，就把按钮单独一行。
- 词条类型是共享的：加了字段会牵动宿主与七个测试标签对象，一次改齐。

## 3. 工作流

1. 读第二节，把本任务复述成一句话。
2. 写失败用例（红）：初始只显示当前课程全名，切换后列出全部课程行。
3. 加短标签词条与标签字段，改齐宿主与测试标签对象。
4. 课程段改为名称 + 切换，列表用行原语。
5. 用例转绿，跑 `p3g`、`p3y3`、`p3a8` 全组与类型检查。
6. 提交。

## 4. 测试用例

| 用例 | 输入 | 预期 | 接缝 |
|---|---|---|---|
| 1 | 两门课的快照 | 当前课程全名可见，且不显示第二门课 | 屏幕 |
| 2 | 按切换 | 两门课都成为可选行 | 屏幕 |
| 3 | 按第二门课 | 当前课程名换成第二门，列表收起 | 屏幕 |
| 4 | 五门课的快照 | 切换后五行都在，姓名不被省略号截断 | 屏幕 |
| 5 | 未打开切换 | 不出现课程行，只有名称与切换 | 屏幕 |
