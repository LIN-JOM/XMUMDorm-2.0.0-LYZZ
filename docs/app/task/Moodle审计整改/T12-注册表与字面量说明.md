## 2. 开发者需要知道

**Read first**

- `docs/app/design/App组件类型定义.md` — P18 现在标什么（§3.5、§4 落点、§8.3）？
- `app/src/features/tools/moodle/contract.ts` — 哪些函数会被注入 WebView（`toString`）？

- `app/src/features/tools/SchoolSystemWebView.tsx` — 注入点在哪。

**Settled**

- 注入脚本必须自包含 → 域名与 URL 白名单字面量**不能**改成模块常量引用；本轮把理由写进代码注释，不再拆函数。
- P18 已由 P0-08/P1-14 实现，组件文档状态回填为「已实现」，§8.3 待决项按实现关闭。
- 不重写 URL 白名单成一份（两份函数分属投影与只读校验，语义不同；合并留待有设备证据时评估）。

**Edges and seam**

- seam：组件文档 P18 三处状态 + 注入函数头的说明注释。
- 触 `docs/app/design/App组件类型定义.md`、`moodle/contract.ts`、`moodle/detail.ts`、`moodle/identity.ts`；不改行为。

**Run**

- `cd app; npx jest --ci --testPathPattern "p3y0-moodle-bridge|p3y3-moodle-detail|p3y3-moodle-identity|p2d-05"`。
- `cd app; npx tsc --noEmit`。

**Unknowns**

- 组件文档如果还有别处引用「建议新增」，一起清；数量口径（15 原型）不要改错。
