## 2. 构建/连接层的三个坑（已绕过）

| # | 现象 | 处理 |
|---|---|---|
| 1 | Windows 上构建失败：ninja 在 `VectorIconsMaterialDesignIcons_autolinked_build` 目录报 `No such file or directory`（路径超 MAX_PATH，`LongPathsEnabled=0`） | 临时在 `app/package.json` 的 `expo.autolinking.exclude` 排除 `@react-native-vector-icons/material-design-icons`（markdown-display 的传递依赖；App 不使用其原生图标）；构建成功后已还原该配置 |
| 2 | Metro 只监听 `::` / `::1`，模拟器走 `10.0.2.2` 或 `adb reverse`（IPv4）连不上 | `NODE_OPTIONS=--dns-result-order=ipv4first` + `expo start --host localhost` + `adb reverse tcp:8081 tcp:8081`，dev client 用 `http://localhost:8081` 打开 |
| 3 | 设备无 MCP 工具直连时 | 本地 MCP 通过 `mcporter call mobile-mcp.<tool>` 驱动；自定义 scheme 的深链走 `adb shell am start` |

## 3. 阻塞：Android 13 不信任校方站点的证书链

WebView 打开 `https://l.xmu.edu.my/` 显示：

```text
Error loading page
Error Code: 3
Description: SSL error: The certificate authority is not trusted
```

链与根：`*.xmu.edu.my` ← `Sectigo Public Server Authentication CA DV R36` ← **`Sectigo Public Server Authentication Root R46`**（root 自签，证书有效期至 2026-10-26 之后）。
在模拟器（Android 13）上：`/system/etc/security/cacerts/e071171e.0` **不存在** → 系统信任库没有 R46 根，Chrome 与 WebView 同样无法访问。

影响：若校方在**校外/公网解析**时确实下发这条 R46 链，Android 13 及更早的系统上内嵌 Moodle 会直接打不开（身份探针、同步、详情全部走不到）。
校内解析是否下发不同证书链尚未验证（本次测试走的是公网出口）；需要在校内网络或 Android 14+ 设备上复核。

## 4. 复现命令（不含凭据）

```text
adb shell am start -a android.intent.action.VIEW -d "xmumdorm:///system/moodle"
# WebView 报 SSL error code 3
# 根证书校验：openssl x509 -in <root>.pem -noout -subject_hash_old  → e071171e
adb shell "ls /system/etc/security/cacerts/e071171e.0"   # 不存在
```
