## P-2 实站链路（逐项打勾）

| # | 步骤 | 通过判据 |
|---|---|---|
| 1 | 打开 `/system/moodle`，学号登录 | 登录成功，`M.cfg.userId` 探针返回本人 id |
| 2 | 登录后不退出，杀进程再打开 | 会话仍在，直接进入系统页 |
| 3 | 点「同步课程」 | 三种 AJAX 全部成功，课程分页无缺页 |
| 4 | 勾选课程后确认 | 只请求所选课程的 state/events |
| 5 | 打开公告 / 作业 / 文件夹 / 资源详情 | 四类详情至少各一例成功；失败显示可理解状态 |
| 6 | 点「打开原页」 | 系统浏览器打开；返回 App 后会话与返回栈正常 |
| 7 | 通知授权后等一条截止提醒 | 权限被拒时界面显示「通知未授权」；授权时按提前 30 分钟送达 |
| 8 | 吉隆坡 03:00–04:30 访问 | 显示维护态，不是普通失败 |
