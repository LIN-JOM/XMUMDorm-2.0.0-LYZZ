## 2. 变化意味着什么

菜品创建、主点评、回复都使用公共 Form 状态机和草稿机制；回复草稿额外包含父ID，避免覆盖主点评。创建/点评检查真实服务器数字ID回执，在写入后、缓存处理后和最终 onSettled 时检查账号 epoch，旧回执不会在新会话跳转。写入失败保留输入并给出既有错误行动；服务端仍权威验证父点评属于本菜品、未删除且为一级，不伪造无评级的回复。

CanteenImageInput 默认直接复用已有乙域 pickReviewImage（SDK57 expo-image-picker），保留 pickImage 注入以便测试。当前菜品与局部回复默认即可进入选图；无需甲额外接入选图器。createProduct 对浏览器 File/Blob 使用存在性守卫，对 RN 描述对象校验 uri/type/name，避免原生没有 File 全局时抛 ReferenceError。自动化证明客户端及上传载荷边界，尚未证明真实设备/真实后端上传。

原型声明以 docs/app/design/App组件类型定义.md §2.7 与 docs/app/product/App页面清单与结构盘点.md 为准：Home P7 + feed P1，Region/Shop P2，榜单 P9，Dish P3，AddDish/Review/Reply P4。此前已固定 briefs 中 P2详情/P3表单等编号错误保留原文，本交接更正；源码 AddDish/Review/RegionRanking 注释已更新。每次局部切换只有一个 Screen/Form 页面壳。

Home P7 ── Article feed P1
  └─ Region P2 ── Rank P9 / Shop P2
                         ├─ category filter + EntityCard(food)
                         ├─ AddDish P4 (typed contribution 注入)

公共 CommentThread 没有评级/图片插槽，本域通过其纯分组/层级/展开函数与 CommentItem 组合扩展，无公共UI复制或改动。公共复用清单还包含 Screen、Form/useForm、FormField DSL、RatingScale、MediaPicker、IconButton、Button、Surface、Text、Empty/Error/LoadingState。全区排行仍是Y4本域局部视图；没有制造新的路由。
