# 原生课程工作台

## 1. 任务位置

- Phase Y3 Moodle 工作台：所选课程对象可在原生页浏览。
- 本任务推进：提供选课、课程/类型筛选和章节模块浏览。
- 前置：前一任务已提交；后续：本批领域集成与甲接线。

## 2. 开发者需要知道

**先读**

- `app/src/features/tools/moodle/cache.ts — 页面可读哪些本机对象？
- `app/src/components/ui/Checkbox.tsx` — 可访问选课怎样展示？
- `app/src/components/ui/ListItem.tsx` — 模块动作怎样复用？

**已定**

- Markdown；仅乙工具域；不改公共词条、导航、鉴权、依赖。
- 设备门记录为待验，不阻止本轮已授权本地实施。
- 官方4.5合成样本不是校园实站证据。
- 默认远期366日、提前30分钟为可配置工程保护值。

**边界与接缝**

- 接缝：screen，沿用现有 WebView 与缓存代次。
- 页面词条由甲的唯一 t 注入；原生通知由外部 adapter 回调。

**运行**

- `cd app; npm.cmd run test:ci -- --runInBand p3y3`
- `npm.cmd run typecheck`；既有四个甲域错误单列。

**未知**

- 校园版本与插件差异、Cookie保持和锁屏提醒仍需设备证据。
- 未知结构显示未知，不猜账号、成绩或本地化日期。

## 3. 工作流

1. 读第二节，将本任务复述为一句话。
2. 在既定接缝写独立预期的失败用例并提交。
3. 实现最小行为，验证该用例。
4. 加边界用例并跑本任务回归。
5. 运行类型与增量 lint，记录基线缺口。
6. 按单一意图提交实现。
