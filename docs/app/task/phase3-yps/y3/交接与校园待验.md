## 甲接线位置

从 `@/features/tools/moodle` 导入 `MoodleWorkspaceHost` 和 `MoodleWorkspaceHostLabels`。
`app/src/app/system/[id].tsx` 已是校方系统宿主；仅在 Moodle 分支将内容换成 Host。
路由继续提供唯一 `Screen`、顶栏、返回、信箱入口与安全区；AC 读课表和其他系统保持各自行为。
`ToolsDashboard` 与 `SchoolSystemList` 的现有 `/system/[id]` 入口无需新增同义路由。

Host 的 props 契约：

```ts
{
  labels: MoodleWorkspaceHostLabels;
  onOpenOriginal: (url: string) => void;
  onReminderPlan?: (plan: { id: string; fireAt: number }[]) => void | Promise<void>;
  onClearReminders?: () => void | Promise<void>;
  deadlinePolicy?: { maxFutureDays?: number; leadMinutes?: number };
  now?: () => number;
}
```

`onOpenOriginal` 接用户点击后的已校验只读 URL；甲选择已有校方浏览器接收方式并验证返回栈。
它不表示自动下载或写入学校状态；首次登录入口仍由 Host 中的学校 WebView 提供。
不要为详情重建第二个登录 WebView。

## 原型、组件与实际入口

按宪法 9.1，主工作台属于 P7 仪表盘，课程/章节属于 P2 列表，活动详情属于 P3 详情。
原型编号来自 `docs/app/design/App组件类型定义.md`；P1 是信息流，不是仪表盘。
P7 在真源中允许页面组合；本实现不增加新原型或 UI 套壳。

| 组成 | 复用或领域职责 |
| --- | --- |
| 路由 `Screen` | 唯一屏幕容器与公共顶栏 |
| `MoodleWorkspaceHost` | 登录、可信恢复、原生工作台与详情切换 |
| `SchoolSystemWebView` | 现有校方会话与只读桥 |
| `MoodleWorkspaceScreen` | 课程选择、课程/类型筛选、章节活动 |
| `MoodleDetailScreen` | 结构化活动详情与原链接 |
| `Button` / `Checkbox` / `Text` | 现有公共组件 |
| `useTheme` / `ScrollView` / `View` | 令牌与原生布局，无新增样式库 |

```text
公共路由 Screen
└─ MoodleWorkspaceHost
   ├─ SchoolSystemWebView：首次登录；原生模式仍挂载、隐藏
   └─ 原生工作台：课程 → 类型 → 章节 → 活动详情 → 原链接
```

首次进入显示学校 WebView。当前页面证明学校身份后，匹配本机快照才显示恢复工作台。
已确认新账户显示空的原生工作台，用户手动同步；`login` 按钮重新显示同一个学校页面。
隐藏时 WebView 保持挂载，以保留校方会话和 AJAX 页面；无可信证明时不展示私有快照。

动态课程与类型按钮筛选领域数据，语义不是导航子栏目。
它们不伪造 `MessageKey`，也不重建公共 `TopTabStrip`；公共固定子栏目仍由甲统一接线。

## 文案单一来源

`labels` 是 required。甲从应用唯一 `t` 注入全部应用文案，不加工具本地字典或 inline 双语。
学校课程标题、正文和文件名作为学校内容显示，不转成应用词条。

| labels 分组 | 字段 |
| --- | --- |
| 入口与动作 | firstLogin、restoredNative、nativeWorkspace、login、sync、cancel |
| 课程与浏览 | confirmSelection、chooseCourses、courses、allTypes、empty |
| 详情共用 | original、details、unknownSection、back、locked、fileUnknown |
| 宿主区域 | clear、backToNative、deadlines、otherEvents |
| 领域状态函数 | phase、failure、moduleType、detailStatus、deadlineBucket |
| 作业与文件函数 | submissionStatus、gradingStatus、formatTime、fileMetadata |
| 事件与提醒函数 | eventType、actionableStatus、reminderStatus |

`clear` 文案定为“清除本地课程数据”。此动作不清除校方 Cookie，也不等于退出学校账户。
现有 `clearSchoolSession('moodle')` 清本机会话标记并清 Moodle 数据，同样不证明 Cookie 已清除。
若产品需要真正学校退出，另接经过验证的学校退出或 Cookie 清理流程。

`reminderStatus('planned')` 文案定为“提醒计划已交付”。它只证明回调完成，不证明系统已安排或提醒已触发。
`unavailable` 表示未提供适配器；`failed` 表示回调拒绝；`cleared` 表示清理回调完成。

## 认证、快照与清理

项目 logout、expiry、user switch 的公共生命周期立即调用 `clearMoodleCache()`。
这些路径同时调用 Moodle 提醒清理适配器，覆盖 Host 未挂载时的情况；生产 tokenStore 不新增私有订阅。
领域读取的项目 epoch 校验仅作补充，不能替代公共认证即时清理。

学校身份只读 `M.cfg.userId` 的正整数，并要求同源页面存在已认证 usermenu、没有登录/password 节点。
原生端还配对 requestId、generation 与当前页面 URL。每次 AJAX/详情读的前后都验证相同学校身份。
未知主题结构返回 unknown；不读密码、Cookie、项目 JWT 或整个 M.cfg。

快照按 `l.xmu.edu.my` 的学校 userId 分区。每次打开先隐藏本机数据，取得本次同账户证明后才恢复。
快照只存白名单 courses/states/events/selectedIds；队列和 epoch 防止 clear 后迟到写入或恢复复活。
登录页、过期、跨源、换账户与主动 clear 都清数据。
默认 Y0 导航/卸载清理仍有效；仅 Host 的 `preserveSnapshotOnClose` opt-in 允许已确认同学校身份的正常关闭保存快照。

## 截止与原生提醒适配

截止保护值来自 Host 的 `deadlinePolicy`，默认 `maxFutureDays=366`、`leadMinutes=30`。
这是工程保护选择，不推断学校学期。甲在公共配置确定可配置来源和文案。
学校时间为秒；计划 `fireAt` 为毫秒，标识为 `moodle:<courseId>:<eventId>`。

自动计划要求：选中课程可见活动的精确只读 URL 关联、可靠机器截止类型、`action.actionable === true`。
机器类型限定 assign+due、quiz+close、expectcompletionon。
open、gradingdue、缺类型、未知类型、不可操作和未知可操作状态仍可浏览，不自动提醒。
已过期、无截止、超过保护天数和提前量已过的对象不产生计划；不解析标题语言。
4.5 AJAX instance 是 cm.id，数据库原始 calendar instance 含义不同；因此不靠单独数字匹配活动。

Y2 适配 `onReminderPlan` 时只替换 Moodle 命名空间，不触碰 classes 提醒。
`onClearReminders` 只清 Moodle。宿主将计划与清理回调串行交付。
适配器显式处理 permission-denied、stale、deferred 与 native failure；失败不能仅 resolve 后显示交付成功。
本域不导入原生通知实现或尚不存在的 scheduler 文件。

## 只读详情与来源

支持 forum 公告列表、discussion 正文、assign 结构化状态、folder 文件和 resource 同源 HEAD。
其他活动显示有限状态并提供原活动链接，不伪装成已解析详情。
请求必须精确对应缓存中选中课程的可见 module id/type/url；discussion 只能来自已验证公告列表。
pluginfile 只接受该活动详情发现的文件，不接受调用者任意文件 URL。
GET/HEAD 使用 same-origin、same-origin credentials、manual redirect；遇到重定向即终止。
HEAD 只回传 MIME、文件名、字节数、修改时间；不回传 raw HTML、raw headers 或会话数据。

详情 selectors 与官方源码已记在 `app/src/__tests__/fixtures/moodle/details/README.md`。
这些 fixture 是官方 4.5 结构合成页，测试执行真实生成脚本与 jsdom，不是校园实站抓取。
