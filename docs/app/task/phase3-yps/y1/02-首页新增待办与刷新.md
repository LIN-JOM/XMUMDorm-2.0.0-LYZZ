## 1. Where this task sits

- **Phase Y1 工具首页闭环**：用户查看今天并新建待办。
- **This task moves R-Y2 工具首页与待办闭环**：首页新增入口与成功回显可用。
- **Starts after**：今日待办三项摘要。**Waits on it**：本批首页交接。

## 2. What the developer needs to know

**Read first**

- `app/src/features/tools/ToolsDashboard.tsx` — 首页摘要与入口在哪里？
- `app/src/features/todos/TodoFormScreen.tsx` — 保存成功如何广播？
- `app/src/features/todos/todos.ts` — 订阅与刷新如何联动？
- `app/src/__tests__/p2y-b02-tools-dashboard.test.tsx` — 既有首页行为如何验证？

**Settled**

- 使用既有 `/tools/todos/new` 与公共词条 `tools.todos.create`。
- 保存成功才广播；失败不伪造回显。
- 首页保留一句总数，移除两块指标卡。

**Edges and seam**

- 接缝：既有工具摘要、待办表单和 `notifyTodosChanged`。
- 不修改 App 路由、共享 UI、公共词条或个人域。

**Run**

- `cd app; npm.cmd run test:ci -- --runInBand p3y1-dashboard p2y-b01 p2y-b02`
- `npm.cmd run typecheck`

**Unknowns**

- 页面返回行为由现有路由处理；本任务不改变导航壳。
- 真后端写入证据不以模拟保存替代。

## 3. The workflow

1. 读第二部分，重述首页新增到摘要刷新路径。
2. 写首页入口和真实表单成功广播的失败测试。
3. 提交失败测试。
4. 首页增加新增按钮并精简指标摘要。
5. 校验保存后摘要重读和既有完整列表入口。
6. 跑用例、类型检查和增量 lint，提交修复。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 1 | 点击首页新增 | 打开既有新增路径 | 工具首页 |
| 2 | 表单成功保存 | 摘要重读并展示新标题 | 表单与摘要广播 |
| 3 | 表单保存失败 | 原摘要保留，无成功广播 | 表单与摘要广播 |
| 4 | 摘要有计数 | 一句总数，不显示两块指标 | 工具首页 |
| 5 | 点击完整待办 | 进入既有列表 | 工具首页 |
