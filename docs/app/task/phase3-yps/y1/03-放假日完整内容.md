## 1. Where this task sits

- **Phase Y1 工具首页闭环**：用户查看今天并新建待办。
- **This task moves R-Y2 工具首页与待办闭环**：课表下可进入完整放假日内容。
- **Starts after**：首页新增与刷新。**Waits on it**：甲的可选独立路由接线。

## 2. What the developer needs to know

**Read first**

- `shared/config/holidays.js` — 本地日历提供哪些日期？
- `shared/config/semesters.js` — 学校日期如何独立设备时区？
- `app/src/features/tools/todaySummary.ts` — 最近放假日如何选择？
- `app/src/features/tools/ToolsDashboard.tsx` — 课表摘要之后如何接内容？

**Settled**

- 复用 ALL_HOLIDAYS 与既有公共词条，不新增本地双语字典。
- 首页局部打开完整内容，返回按钮和 Android 返回键都关闭。
- 导出 HolidaysContent 与 HolidaysScreen，独立路由留给甲。

**Edges and seam**

- 接缝：既有放假日日期选择与工具摘要。
- 只改乙域内容；不改日历真源、App 路由或公共 UI。

**Run**

- `cd app; npm.cmd run test:ci -- --runInBand p3y1-holidays p3y1-dashboard p2y-b02`
- `npm.cmd run typecheck`

**Unknowns**

- 日历数据范围有限；无后续日期显示现有空态。
- Android 真机返回与布局记录留在发布门。

## 3. The workflow

1. 读第二部分，重述最近日期到完整内容的路径。
2. 写进入、日期边界和返回的失败测试。
3. 提交失败测试。
4. 导出完整内容与独立屏幕，复用学校日期与词条。
5. 移动首页卡片并接入局部内容与返回处理。
6. 跑域回归、类型检查和增量 lint，提交修复。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 1 | 首页点击放假日 | 显示全部后续日历 | 工具首页 |
| 2 | 学校日期到节假日末日 | 当天仍在列表 | 放假日日期选择 |
| 3 | UTC 日期与学校日期不同 | 以学校日期过滤 | 放假日日期选择 |
| 4 | 点击返回或 Android 返回 | 恢复工具摘要 | 完整内容 |
| 5 | 本地日历已过期 | 显示现有无后续日期空态 | 完整内容 |
