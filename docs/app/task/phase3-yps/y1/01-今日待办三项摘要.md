## 1. Where this task sits

- **Phase Y1 工具首页闭环**：用户查看今天并新建待办。
- **This task moves R-Y2 工具首页与待办闭环**：首页只显示三项有效、未完成、唯一待办。
- **Starts after**：既有今日摘要接口。**Waits on it**：首页新增与刷新路径。

## 2. What the developer needs to know

**Read first**

- `app/src/features/todos/useTodayTodos.ts` — 摘要如何读取与刷新？
- `routes/todos.js` — 今日接口如何过滤与排序？
- `app/src/features/me/dashboard.ts` — 既有摘要字段是什么？

**Settled**

- 上游全面治理计划 R-5 重做工具首页、待办与放假日要求最多三项。
- 当前接口省略完成标记；省略时保持接口的未完成语义。
- 不修改个人域摘要规则、公共词条或请求底座。

**Edges and seam**

- 接缝：既有 `useTodayTodos` 读取与规范化。
- 修改乙域；保留计数字段、服务端顺序与错误行为。

**Run**

- `cd app; npm.cmd run test:ci -- --runInBand p3y1-today-todos p2y-b02`
- `npm.cmd run typecheck`

**Unknowns**

- 异常响应可能带显式完成标记；只过滤确定已完成的条目。
- 若接口改变必需字段，保留错误态，不猜新增契约。

## 3. The workflow

1. 读第二部分，重述三项有效未完成摘要规则。
2. 在今日摘要接缝写超量与重复条目的失败测试。
3. 提交失败测试。
4. 增加乙域规范化，保留计数与接口顺序。
5. 覆盖完成标记与异常条目边界。
6. 跑用例、类型检查和增量 lint，提交修复。
