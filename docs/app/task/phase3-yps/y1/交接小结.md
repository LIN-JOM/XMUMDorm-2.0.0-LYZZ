## 2. What it means

工具首页复用原待办表单与成功广播，没有建立第二套待办写入路径。
保存失败不会刷新成虚假成功；三项摘要保留服务端顺序与总数。
放假日直接从首页打开局部完整内容，返回按钮恢复摘要。
全仓返回守卫发现原生返回监听违反宪法，已删除监听；系统返回继续由导航壳处理。

完整内容复用公共日历、双语词条和 UI 令牌，不新增路由或公共文件。
独立路由可使用导出 `HolidaysScreen`；已有首页路径使用同一份 `HolidaysContent`。
无后续日期使用现有空态，日期末日按吉隆坡时间保留。
