# 美食文章内容流

## 1. 任务位置

- Phase Y4 食堂浏览闭环，目标是搜索、排行、区域可进入菜品详情。
- 本任务推进 R-Y5 食堂浏览与点评闭环：接通首页文章分页；复用已有帖子卡片和详情路由。
- 起点：上一任务完成或本批第一项；后续任务复用本任务交付。设备记录留作发布门。

## 2. 开发者需要知道

**先读**

- app/src/features/square/shared/api/canteen.js — 文章页码与hasMore怎样返回？
- components/ui/ListScreen.tsx — 分页状态怎样复用？
- components/ui/EntityCard.tsx — 帖子卡片怎样复用？

**已定**

- docs/app/task/Phase3全面治理工程计划.md 固定乙域和食堂验收范围。
- 复用已有组件、API与令牌；公共路由和词条由甲接入。
- 新词条通过 typed label/tabs props 注入；不建立本地字典。

**边界与接缝**

- 接缝为现有食堂API、规范化、缓存和组件调用。
- 不改公共UI、i18n、导航、鉴权、后端挂载。

**运行**

- app目录：npm.cmd run test:ci -- --runInBand p3y4-food-articles
- npm.cmd run typecheck；npm.cmd run lint -- --no-cache

**未知项**

- 未提供设备，双栏真机证据仍为空。
- 新路由需求以屏幕导出或局部二级视图交接；不伪造路径。

## 3. 工作流

1. 阅读第二部分，用一句话复述本任务。
2. 写独立输入和字面量期望的失败测试。
3. 提交失败测试。
4. 在既有接缝完成最小实现。
5. 跑任务行为测试、lint与typecheck，记录基线失败。
6. 提交实现，并保留交接事实。
