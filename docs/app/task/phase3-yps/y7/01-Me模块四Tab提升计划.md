# Me 模块改造：四 Tab 提升到一级页 —— 施工计划

日期：2026-10-18；分支：`dev-yps`；角色：乙（yps）。
需求来源：所有者 2026-10-18 当面提出的三条改造。
本文使用自己的 R-M 编号。

**本轮三条已拍板决策**：

- 横滑方案用 `react-native-pager-view`（Expo 官方支持的原生分页），不自写 ScrollView 分页；
- `/me/posts` 子页面**删除**，内容并入主页，不做深链接兜底；
- 本轮需求**覆盖** 2026-10-12 的 R6 裁决（"内容区不做横滑"）——「我的」一格此后允许内容横滑，R6 注释同步改写。

## 1. Requirements

- **R-M1 主页删掉"设置"列表项** — 所有者需求①；设置的唯一入口收为右上角齿轮。
- **R-M2 "关于与法律"移出主页、并入设置页** — 所有者需求①；点齿轮进设置页后能看到它。
- **R-M3 四个二级 Tab 提升到主页"更多"区块** — 所有者需求②；树洞 / 二手 / 跑腿 / 点评不再是子页面里的局部切换。
- **R-M4 内容区横向滑动切换** — 所有者需求②③；点 Tab 和手指横滑双通道，双向同步。
- **R-M5 删除 `/me/posts` 子页面** — 本轮决策；消除主页与子页的双入口冗余。
- **R-M6 契约测试与词条同步** — 工程派生；旧结构被四个自动化用例锁死，改结构必须同步改契约。

## 2. The approach, requirement by requirement

### R-M1 主页删掉"设置"列表项

- **Approach**：主页入口是数据驱动的登记表，删掉对应行即可；顶栏齿轮保留为唯一入口。
- **Touches**：「我的」域的入口登记与主页组合。
- **Test seam**：现有的主页渲染用例（断言入口行消失、齿轮仍在）。
- **Acceptance**: [ ] 主页列表里没有"设置"　[ ] 右上角齿轮仍进设置页　[ ] 入口账本校验仍全绿
- **Hard part**：主页"更多"区块被 R-M3 整个换掉后，这一条的落点其实随之消失——两条要一起拆。

### R-M2 "关于与法律"并入设置页

- **Approach**：设置页的"更多"区块改为只保留"关于与法律"一行；主页登记表里对应行随 R-M1 一起删。
- **Touches**：「我的」域的设置页组合与入口登记。
- **Test seam**：现有的设置页渲染用例（断言"关于与法律"行在、其余不在）。
- **Acceptance**: [ ] 设置页"更多"下只有"关于与法律"　[ ] 点它仍能进法务聚合页　[ ] 主页列表里没有它
- **Hard part**：登记表本身留着账本机制给未来入口用，删行不删机制，别把校验函数一起拆掉。

### R-M3 四个二级 Tab 提升到主页

- **Approach**：主页"更多"区块从列表换成 Tab 条 + 分页内容区；四份内容列表（取数、分页、空态、删帖）从子页面原样迁入四个分页。集合声明收进二级 Tab 注册表（C-05 就此拍板：「我的」用二级 Tab）。
- **Touches**：「我的」域的主页与子页面组合、二级 Tab 注册表、二级 Tab 状态仓库。
- **Test seam**：现有子页面用例迁为主页用例；注册表不变量用例同步更新。
- **Acceptance**: [ ] 主页"更多"区块下是四个 Tab　[ ] 每个 Tab 的列表、分页、空态与子页面时期一致　[ ] 树洞 Tab 的删帖与本地先移除行为保留　[ ] 切走再切回，滚动位置与分页游标还在
- **Hard part**：四个列表各自独立取数，迁入后要保住"各自的分页游标与滚动位置按 (me, tab) 存"这条——容器换了，键不能换。

### R-M4 内容区横向滑动切换

- **Approach**：引入 `react-native-pager-view`，四个分页各挂一份内容列表；pager 的选中态与 Tab 条双向同步。
- **Touches**：「我的」域的主页组合、组件层的分页容器。
- **Test seam**：jest 用 pager-view 官方 mock 断言选中同步；真机手势走发布门验证。
- **Acceptance**: [ ] 手指横滑翻页且 Tab 条跟随　[ ] 点 Tab 翻页且 pager 跟随　[ ] 列表内部的垂直滚动不被横滑抢走
- **Hard part**：pager 与内部 FlatList 的手势冲突，以及 Expo dev build 需要重新构建才能带原生模块——这是整条计划里唯一会"推翻计划"的风险，所以放第一棒。

### R-M5 删除 `/me/posts` 子页面

- **Approach**：子页面路由与页面文件随内容迁出后删除；主页入口登记表不再有任何指向它的行。
- **Touches**：路由层、「我的」域。
- **Test seam**：入口账本的"路由文件必须存在"校验反向兜底——登记删了，校验不再找它。
- **Acceptance**: [ ] `/me/posts` 路由不存在　[ ] 代码库里没有对已删页面的引用
- **Hard part**：删除前先把内容逻辑完整迁走，顺序反了会出现一段"哪都打不开"的中间态。

### R-M6 契约测试与词条同步

- **Approach**：随结构改动同步更新四份用例与相关词条、注释口径。
- **Touches**：测试域、词条表、「我的」域注释。
- **Test seam**：就是这四份用例本身。
- **Acceptance**: [ ] 四份相关用例全绿　[ ] 二级 Tab 注册表用例断言「我的」为四集合　[ ] R6 注释改写为本轮裁决　[ ] 全量 jest 无回归
- **Hard part**：注册表用例里"只有广场一格非空"的断言是显式锁，改集合必须同批改锁，漏了就是红。

## 3. Phases

### Phase 1 — 横滑骨架先跑通（covers R-M4，架起 R-M3）

**Goal**：主页"更多"区块出现四个 Tab，手指横滑能翻四页占位内容，Tab 条跟随。

**Tasks**

- 用 Expo 安装 `react-native-pager-view`，并确认 jest mock 就位
- 在二级 Tab 注册表登记「我的」的四集合（C-05 拍板），同步改掉"只有广场非空"的锁
- 主页"更多"区块换骨架：Tab 条 + pager + 四页占位文本
- 双向同步接线：点 Tab 翻页、滑动翻页回写 Tab 条

**Proof**：dev build 上四页可横滑、Tab 跟随；注册表用例与主页渲染用例绿。
**Not here**：真实内容列表、入口收拢、子页面删除。

### Phase 2 — 内容搬家（covers R-M3）

**Goal**：四个 Tab 在主页上就是原来的四个列表，行为逐项对齐。

**Tasks**

- 把四份内容列表（取数/分页/空态）迁为四个分页内的可复用组合
- 树洞分页接上删帖弹窗与本地先移除逻辑
- 状态仓库键位核对：四份列表的滚动与分页仍按 (me, tab) 存取
- 空态文案与"去发布"引导在主页语境下复核一遍

**Proof**：主页四 Tab 的列表、下拉刷新、触底加载、空态、删帖全部可用；切走切回位置保持。
**Not here**：`/me/posts` 的删除（此时新旧并存，是刻意的中间态）。

### Phase 3 — 入口收拢（covers R-M1、R-M2、R-M5）

**Goal**：主页只剩资料卡与 Tab 区；设置页"更多"只剩"关于与法律"；`/me/posts` 不存在。

**Tasks**

- 删除主页入口登记表里的"设置"与"关于与法律"行，主页不再渲染入口列表
- 设置页"更多"区块收窄为"关于与法律"一行
- 删除 `/me/posts` 路由与页面文件
- 全库扫一遍对已删路由的引用并清除

**Proof**：主页无设置/关于列表项，齿轮进设置页可见"关于与法律"，旧路由 404 无处可达。
**Not here**：法务文档正文（那是另一条线的占位文本替换）。

### Phase 4 — 契约与口径收尾（covers R-M6）

**Goal**：四份相关用例改写后全绿，注释与词条口径一致，全量 jest 无回归。

**Tasks**

- 改写主页用例：断言 Tab 区在、入口列表不在
- 把子页面用例迁为主页内容区用例
- 改设置页用例与注册表用例的断言
- 改写 R6 裁决注释，补词条（如需）
- 跑全量 jest 与类型检查，收尾提交

**Proof**：全量测试绿；双轴验收表能填。
**Not here**：真机手势的深度体验调优（归发布门）。
