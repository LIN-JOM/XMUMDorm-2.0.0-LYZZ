## 2. What the developer needs to know

**Read first**

- `app/src/features/navigation/secondaryTabs.ts` — 注册表机制、SQUARE_TABS 先例、C-05 注释位置。
- `app/src/__tests__/p2a-03-secondary-tabs-config.test.tsx` — 锁在哪：「me 空集合」断言与"只有 square 非空"断言。
- `app/src/i18n/zh.ts` 的 `me.content.*` 段 — 四个 labelKey 已存在（树洞/二手/跑腿/点评），不新造词条。
- `app/src/features/me/PostsScreen.tsx` 的 `CONTENT_TABS` — 现有 key 顺序的唯一参照。

**Settled**

- 集合只声明在 `secondaryTabs.ts` 一处（P2A-03 源码扫描盯着）。
- key 用 `posts / marketplace / errands / reviews`，与内容域既有键一致，不改名。
- labelKey 复用 `me.content.posts` 等既有词条，⛔ 不新增、不用 `secondary.*` 前缀（那是广场的名字空间）。

**Edges and seam**

- 只碰注册表与它的用例。不碰页面。
- Seam：p2a-03 的纯函数与注册表断言。红先绿后，两个 commit。

**Run**

- `cd app && npx jest p2a-03 --runInBand`。

**Unknowns**

- 源码扫描绘"非空格只有 square"的断言措辞要看准再改。若还有别处断言 me 为空集合（搜 `getSecondaryTabs('me')`），一并改掉。

## 3. The workflow

1. 读上面文件，一句话重述本任务。
2. 红：把用例里 me 的断言改为"四集合、顺序 posts→marketplace→errands→reviews"，"只有 square 非空"改为"square 与 me"，跑测试确认红。
3. Commit 红的契约（`test(nav): ...`）。
4. 绿：在注册表声明 `ME_CONTENT_TABS` 并挂到 `SECONDARY_TABS.me`，删掉 C-05 待确认注释（改写为拍板记录），跑测试确认绿。
5. Commit 实现（`feat(nav): ...`）。
