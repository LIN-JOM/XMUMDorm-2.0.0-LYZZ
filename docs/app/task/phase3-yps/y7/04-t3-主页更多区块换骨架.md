# T3 主页"更多"区块换骨架：Tab 条 + pager + 四页占位

## 1. Where this task sits

- **Phase 1 横滑骨架先跑通**。
- **本任务把 R-M3 的壳立起来**：主页"更多"区块从入口列表换成 Tab 条 + pager + 四页占位文本。
- **Starts after**：T1（pager-view 就位）、T2（集合在注册表里）。**Waits on it**：T4 双向同步。

## 2. What the developer needs to know

**Read first**

- `app/src/features/me/MeScreen.tsx` — 现状结构：资料卡 + 入口列表，顶栏齿轮与铅笔。
- `app/src/components/ui/Screen.tsx` — ⛔ 先确认它内部有没有包 ScrollView：包了的话 pager 不能直接塞进去，这是本任务唯一的结构风险。
- `app/src/components/ui/TopTabStrip.tsx` — 消费方式（tabs/selectedKey/onSelect）。
- `app/src/__tests__/p2c-03-me.test.tsx` 的 4A 用例 — 现状断言哪些入口行在。

**Settled**

- 主页保留资料卡与顶栏双按钮，不动。
- 四页内容是**占位文本**，真实列表在 Phase 2 才迁入——本任务不许顺手搬内容。
- 入口列表整体撤下（含"我的帖子"），不是只删某一行。

**Edges and seam**

- 只碰主页组合与它的用例。子页面、注册表、词条都不动。
- Seam：p2c-03 的 4A 主页渲染用例。红先绿后。

**Run**

- `cd app && npx jest p2c-03 --runInBand`，然后 `npm run typecheck`。

**Unknowns**

- Screen 若为滚动容器：pager 需要固定高度的 flex 布局，包在滚动容器里会塌。若读下来确实如此，**停下**，回来报结构冲突，不擅自改 Screen（那是公共组件，甲的地盘）。

## 3. The workflow

1. 读上面文件，一句话重述本任务。
2. 红：改 4A 用例——断言四个 Tab 标签出现（树洞/二手/跑腿/点评）、`me-entry-*` 入口行消失、资料卡与顶栏按钮仍在。跑测试确认红。
3. Commit 红的契约。
4. 绿：主页"更多"区块换成 SectionHeader + TopTabStrip + pager（集合从注册表读），四页放占位文本。
5. 跑用例确认绿，再过 typecheck。
6. Commit 实现。
