# 登录页（A-02）主题色优化 —— 计划

**来源**：用户 2026-10-19「登录界面按照我们的主题色进行 UI 优化（仅 App）」
**主题色**：厦大蓝（官方锚点 `brand-700 #173874`；CTA 填充 `brand-600 #2452a6`；暗色强调 `brand-300 #7fa9f3`）
**现状**：`app/login.tsx` 是 P1-13 的「最小链路」版 —— 标题 + 两个输入框 + 一行三个按钮，无品牌识别、无主题色块。它自己的注释写明「P15 鉴权原型（品牌头 + 表单卡 + 条款链接）属后续任务」—— 本轮就是把 P15 捡起来。

---

## 1. Requirements

- **R-1 品牌头**：登录页顶部有品牌识别区（「厦马小筑」+ 厦大蓝），不再是裸标题 — 用户需求 + P15 原型
- **R-2 表单卡片化**：登录表单放进 `Card`，不再是平铺平铺的输入框 — 用户需求 + P15 原型
- **R-3 主题色点缀**：标题、主按钮、文字链接用厦大蓝；**纯令牌、零渐变、零硬编码色值** — 用户需求 + 宪法 1.3 / 2.1
- **R-4 次级入口排版**：注册 / 找回密码从「一行挤三个按钮」改为主按钮 + 下方文字链接 — 用户需求
- **R-5 条款露出**：登录页底部露出服务条款 / 隐私政策入口（A-05）— P15 原型

## 2. The approach, requirement by requirement

### R-1 品牌头
- **Approach**：登录页顶部加一块品牌区：应用名「厦马小筑」用品牌色，下方一句 slogan；视觉锚点用色块或描边，不用图片渐变。
- **Touches**：`app/login.tsx`，可能拆一个 `features/auth/BrandHeader`。
- **Test seam**：现有 `p1-13-auth-session.test.tsx`（登录页结构）。
- **Acceptance**：登录页顶部出现「厦马小筑」品牌区　[ ] 品牌区文字用 `text-brand` 令牌　[ ] 无渐变、无硬编码色值
- **Hard part**：品牌色在暗/亮两套主题下取值不同（亮色 600/700、暗色 300/400），必须用令牌不能写死。

### R-2 表单卡片化
- **Approach**：把两个输入框 + 主按钮包进 `Card`，品牌区与表单卡分离；表单卡有留白与描边。
- **Touches**：`app/login.tsx`，`Card` 组件。
- **Test seam**：同 `p1-13`。
- **Acceptance**：表单被 `Card` 包裹　[ ] 卡片有描边与内边距　[ ] 提交按钮仍是 `primary` 变体
- **Hard part**：`Card` 在 `Screen` 的安全区内的对齐与间距，别把表单卡撑满全宽。

### R-3 主题色点缀
- **Approach**：标题、文字链接、焦点态一律走 `text-brand` / `brand-*` 令牌；逐处核对对比度（令牌已 textSafe）。
- **Touches**：`app/login.tsx`，词条在 `i18n/zh.ts`、`en.ts`。
- **Test seam**：`p0-03`（词条门禁）+ `npm run rulers`（对比度/无字面量）。
- **Acceptance**：所有品牌色取自令牌　[ ] `rulers` 的对比度门与无字面量门都过
- **Hard part**：别引入任何 `#hex` 字面量，否则尺子 1 直接判死。

### R-4 次级入口排版
- **Approach**：登录是 `primary` 主按钮；「注册新账号」「找回密码」从 ghost 按钮降级为文字链接，放在表单卡下方，视觉权重拉开。
- **Touches**：`app/login.tsx`。
- **Test seam**：同 `p1-13`。
- **Acceptance**：主按钮独立突出　[ ] 两个次级入口是文字链接样式　[ ] 三个入口的语义不变
- **Hard part**：文字链接的触控面积 ≥44pt/48dp（宪法 13.1），不能做成纯文字点到手抖。

### R-5 条款露出
- **Approach**：表单卡下方加一行小号文字 + 两个链接，指向 `/me/legal/terms` 与 `/me/legal/privacy`。
- **Touches**：`app/login.tsx`，词条 zh/en。
- **Test seam**：同 `p1-13`。
- **Acceptance**：登录页底部有条款入口　[ ] 点击能进对应法务页　[ ] 词条双语齐全
- **Hard part**：法务路由已存在（M-18/M-19/M-20），只是接上；词条字数要过门禁。

## 3. Phases

### Phase 1 — 品牌头与表单卡骨架（covers R-1、R-2）
**Goal**：登录页一眼能认出品牌、表单在卡片里，不再是裸功能页。

**Tasks**
- 拆/建品牌头区块（厦马小筑 + slogan）
- 表单包进 Card，调好卡片留白与对齐
- 品牌区与表单卡接通现有登录链路，行为不动

**Proof**：登录页有品牌区与表单卡，`p1-13` 结构断言通过。
**Not here**：主题色细化、次级入口排版、条款。

### Phase 2 — 主题色与次级入口（covers R-3、R-4）
**Goal**：标题/链接/按钮全是厦大蓝令牌，主次入口拉开层级。

**Tasks**
- 标题与品牌区文字换 `text-brand`
- 注册/找回降级为文字链接，主按钮独立
- 逐处核对对比度与触控面积

**Proof**：品牌色来自令牌，文字链接可点且面积达标，`p1-13` 通过。
**Not here**：条款、门禁收尾。

### Phase 3 — 条款与门禁收尾（covers R-5）
**Goal**：登录页底部有条款入口，词条双语齐全，全量无回归。

**Tasks**
- 加条款行与两个链接，接通 `/me/legal/terms`、`/me/legal/privacy`
- 词条 zh/en 补齐，过字数门
- 全量 jest + typecheck + rulers，改测试断言对齐新结构

**Proof**：条款能点进去，全量与门禁全绿。
**Not here**：注册/找回页的同款优化（A-03/A-04 另起一轮）。
