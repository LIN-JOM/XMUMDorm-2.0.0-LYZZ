## 1. Where this task sits

- **Phase Y2 课表闭环**：完成导入、今日课程收缩和提醒接线。
- **This task moves R-Y3 课表与课前提醒**：数字横滑、同课稳定色和周一至五。
- **Starts after**：既有按周缓存。**Waits on it**：甲的 P11 与路由最小扩展。

## 2. What the developer needs to know

**Read first**

- `app/src/features/tools/timetable.ts` — 按周读取、缓存与失效如何复用？
- `app/src/app/tools/timetable.tsx` — 四态和课程点击如何保留？
- `app/src/proto/P11/TimetableGrid.tsx` — 现有网格缺哪些输入参数？
- `app/src/components/ui/Pressable.tsx` — 数字筛选如何保持触控与读屏？

**Settled**

- 上游 D-7 课表周末：隐藏周六、周日，保留周五。
- 只用 brand/accent 语义浅底，不把状态色当课程装饰。
- 不复制 P11；通过 `renderGrid` 注入已有渲染器。

**Edges and seam**

- 接缝：既有周课表缓存、周次和课程身份规则。
- 导出乙域屏幕与网格输入；公共组件和路由留给甲。

**Run**

- `cd app; npm.cmd run test:ci -- --runInBand p3y2-timetable p1-16 p2y-a02`
- `npm.cmd run typecheck`

**Unknowns**

- P11 仍需消费可见星期与颜色；未接线不宣称当前路由视觉已变。
- 有重名课程时优先课程代码，不使用列表位置定色。

## 3. The workflow

1. 读第二部分，重述数字周次与工作日契约。
2. 写跨周颜色、周五保留和数字选周失败测试。
3. 提交失败测试。
4. 实现业务周次筛选与稳定配色规则。
5. 导出复用缓存的屏幕与网格输入。
6. 跑四态回归与增量质量检查，提交修复。
