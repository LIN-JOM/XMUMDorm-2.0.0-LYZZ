## 1. Where this task sits

- **Phase Y2 课表闭环**：完成导入、今日课程收缩和提醒接线。
- **This task moves R-Y3 课表与课前提醒**：已结束课程退出今日摘要。
- **Starts after**：既有学校时钟与今日摘要。**Waits on it**：本批工具回归。

## 2. What the developer needs to know

**Read first**

- `app/src/features/tools/todaySummary.ts` — 当前与下一节如何选择？
- `app/src/features/tools/ToolsDashboard.tsx` — 时钟如何刷新？
- `shared/config/semesters.js` — 学校日期与教学周如何判断？

**Settled**

- 时间按吉隆坡，不能按设备时区过滤。
- 到结束时间就移除；缺失或异常结束时间保留，不猜结束。
- 课程摘要保持最多三项与既有四态。

**Edges and seam**

- 接缝：既有今日课程选择与首页时钟刷新。
- 修改乙域纯规则与首页，不修改个人域摘要。

**Run**

- `cd app; npm.cmd run test:ci -- --runInBand p3y2-today-courses p2y-b02 p3y1`
- `npm.cmd run typecheck`

**Unknowns**

- 不能为异常时间构造课程结束；它仍显示供用户核对。
- 前后台系统行为仍需设备记录。

## 3. The workflow

1. 读第二部分，重述结束边界和学校时区。
2. 写结束时刻与午夜边界的失败测试。
3. 提交失败测试。
4. 今日列表使用剩余课程规则。
5. 让时间与回前台事件刷新摘要。
6. 跑回归与增量质量检查，提交修复。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 1 | 恰到课程结束时间 | 课程离开列表 | 今日课程筛选 |
| 2 | 上课中与未来课程 | 两者保留 | 今日课程筛选 |
| 3 | 缺失或异常结束时间 | 保留供核对 | 今日课程筛选 |
| 4 | UTC 日期与学校日期不同 | 使用学校当天课程 | 工具首页 |
| 5 | 时钟越过结束或回前台 | 列表自然更新 | 工具首页 |
