# 乙课表与提醒接线契约

日期：2026-10-11。业务实现只修改乙域，以下公共接线尚未实施。

## AC 读取前指引

宿主 `app/src/app/system/[id].tsx` 的 AC 读取按钮可替换为导出 `AcScheduleReadGuide`。
传入 `onRead={() => webRef.current?.readSchedule()}`，不改变读取句柄或消息解析。
`labels` 从公共词条取得；确认才读，取消不读。

| 属性 | 建议词条键 | 中文 | 英文 | 参数 |
|---|---|---|---|---|
| title | tools.acGuide.title | 读取前准备 | Before reading | 无 |
| instruction | tools.acGuide.steps | 在 AC 打开 Basic Info，再打开 Course List，然后读取课表。 | Open Basic Info in AC, then Course List, before reading your timetable. | 无 |
| confirm | tools.acGuide.confirm | 开始读取 | Read timetable | 无 |
| cancel | tools.acGuide.cancel | 稍后读取 | Later | 无 |

组件本身仍复用 `tools.readSchedule`，没有本地双语字典。

## 数字周次与 P11 网格

业务屏幕导出 `features/tools/TimetableScreen.tsx` 的 `TimetableScreen({ renderGrid })`。
现有课表路由可由甲替换为该屏幕，原 P11 仍是唯一网格渲染器。
`renderGrid` 接收 `week`、`visibleWeekdays`、`getCourseAccent`、`highlightWeekday`、`onPressMeeting` 和 `testID`。
传入的 `week.days` 只保留周一至五；原缓存七天数据保持原样。

P11 的最小扩展是接收 `visibleWeekdays` 与 `getCourseAccent`。
表头和格子改为迭代 `visibleWeekdays`，避免过滤数据后仍画出周末空列。
课程背景读取 `theme.color[getCourseAccent(meeting)].value`，正文保持 `text-primary`。
只消费现有 `bg-brand-soft` / `bg-accent-soft`；相同课程稳定，同色碰撞不代表同一门课。
数字周次使用业务时间筛选，不承担子栏目导航；读屏复用 `timetable.weekLabel`。

原型声明：AC 指引复用 P3 对话，课表复用 P11 与既有四态，不复制网格。
组件清单：Screen、Button、Pressable、Text、AlertDialog、LoadingState、EmptyState、ErrorState、OfflineBanner、InlineNotice。

```text
AC 读取按钮 → P3 确认 → 原 readSchedule
P11 屏幕 → 数字周次筛选 → 按周缓存 → P11 renderGrid
                               ↓
                         四态与导入入口
```
