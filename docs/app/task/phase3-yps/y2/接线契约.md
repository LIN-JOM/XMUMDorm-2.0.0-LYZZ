## AC 读取前指引

宿主 `app/src/app/system/[id].tsx` 的 AC 读取按钮可替换为导出 `AcScheduleReadGuide`。
传入 `onRead={() => webRef.current?.readSchedule()}`，不改变读取句柄或消息解析。
`labels` 从公共词条取得；确认才读，取消不读。

| 属性 | 建议词条键 | 中文 | 英文 | 参数 |
|---|---|---|---|---|
| title | tools.acGuide.title | 读取前准备 | Before reading | 无 |
| instruction | tools.acGuide.steps | 在 AC 打开 Basic Info，再打开 Course List，然后读取课表。 | Open Basic Info in AC, then Course List, before reading your timetable. | 无 |
| confirm | tools.acGuide.confirm | 开始读取 | Read timetable | 无 |
| cancel | tools.acGuide.cancel | 稍后读取 | Later | 无 |

组件本身仍复用 `tools.readSchedule`，没有本地双语字典。
