## 1. Where this task sits

- **Phase Y2 课表闭环**：完成导入、今日课程收缩和提醒接线。
- **This task moves R-Y3 课表与课前提醒**：读取前确认 Basic Info → Course List。
- **Starts after**：既有校方读取句柄。**Waits on it**：甲替换原读取按钮。

## 2. What the developer needs to know

**Read first**

- `app/src/app/system/[id].tsx` — AC 读取入口在哪里？
- `app/src/features/tools/SchoolSystemWebView.tsx` — 命令句柄如何保留？
- `app/src/components/ui/AlertDialog.tsx` — 确认与取消如何复用？

**Settled**

- 上游 R-6 重做课表、导入引导与上课提醒要求读取前指明操作页。
- 新中英文文案以 typed labels 传入，由甲接公共词条。
- 不修改宿主路由、WebView、共享 UI 或公共词条。

**Edges and seam**

- 接缝：既有 `readSchedule` 命令的调用前确认。
- 导出业务引导按钮组件；确认调用传入命令，取消不读。

**Run**

- `cd app; npm.cmd run test:ci -- --runInBand p3y2-ac-guide`
- `npm.cmd run typecheck`

**Unknowns**

- 组件不推测当前校方页面；用户进入指定页面后确认。
- 未挂到宿主前不宣称设备读表已完成。

## 3. The workflow

1. 读第二部分，重述确认后才读取的行为。
2. 写确认、取消与再次打开的失败测试。
3. 提交失败测试。
4. 用公共按钮与对话框实现业务引导。
5. 输出甲接线和双语词条清单。
6. 跑测试与增量质量检查，提交修复。
