**词表（全文只用这几组）：**
交付状态 = 交付 / 部分 / 未交付；交付 = 验收项全过，部分 = 过一部分，未交付 = 一项未过。

**边界一览（当前真实能力）**

- 能：内嵌 WebView 登录 Moodle，登录态留在平台 cookie，App 不读不存不外传。
- 能：手动同步已勾选课程 → 逐课章节模块 → 截止事件；只读，零写请求，无后端路由。
- 能：原生浏览课程 / 章节 / 模块与五类只读详情（公告、讨论、作业状态、文件夹、资源）。
- 能：截止分四桶；只对机器类型且可操作的截止，生成课前 30 分钟的本机提醒计划。
- 能：以校方 userId 分区的本机快照，同身份确认后才恢复；广场今日页读缓存显示最近 3 条待交。
- 不能：提交作业、看成绩册、日历视图、后台同步、冷启动读盘、多账户并行。
- 不能：脱离合成夹具的实站与真机验证；也不能证明通知在真机送达。

### D-1 提醒权限被拒或延后时仍显示「提醒已安排」

- **症状**：排程器返回「未授权」或「有 N 条未安排」，调用方把结果丢掉，界面照旧显示已安排。
- **证据**：`reminders/native.ts:49-53` 丢弃返回值；`WorkspaceHost.tsx:68-76` 只要回调 resolve 就写 `planned`。
- **影响**：学生以为截止提醒已生效，实际不会响；错过作业的风险由界面承诺造成。
- **判据**：`y3/交接与校园待验.md` 要求「显式处理 permission-denied、stale、deferred 与 native failure；失败不能仅 resolve 后显示交付成功」。

### D-2 校园实站与真机证据为零

- **症状**：所有渠道、解析、详情行为都在官方 4.5 合成页与 mock WebView 上验证，没有一次真实站点或真机记录。
- **证据**：`fixtures/moodle/README.md:5` 自述「不是 XMUM 实站抓取数据」。
  `p3y0-moodle-bridge-host.test.tsx:17-24` 整体 mock WebView；通知测试全 mock（`notification-native-client.test.ts:14-23`）。
- **影响**：校园主题、插件版本、会话跨重启、通知权限与送达都仍是未知；不解除 Y0 发布门。
- **判据**：`y3/交接与校园待验.md` §校园与设备待验 列出的八项全部记为未通过。

### D-3 登出、过期、换账号不即时清 Moodle 缓存与磁盘快照

- **症状**：登出只清 `xmumdorm:` 前缀的落盘；Moodle 快照用 `@dorm:moodle:v1:` 前缀直写 AsyncStorage，登出后仍在盘上。
- **证据**：`session.tsx:139-145` 只调 `clearNamespace()`；`shared/storage.ts:14,77-81` 只清本命名空间；`cache.ts:21` 用独立前缀。
  认证生命周期（`features/auth`、`app/_layout.tsx`）没有 `clearMoodleCache` 调用；清理只发生在页面挂载/关闭与清除按钮（`SchoolSystemWebView.tsx:92,97`、`WorkspaceHost.tsx:152`）。
- **影响**：与设计文档「logout、expiry、user switch 立即调用 clearMoodleCache」不符；旧账号快照要等下一次缓存访问才被代次清掉。
- **判据**：`y3/交接与校园待验.md` §认证、快照与清理 的明文承诺。

### D-4 T-04 的 Moodle 会话三态恒为「未登录」，清除会话不可达

- **症状**：Moodle 分支不接 `onSessionProbe`，会话探测永不触发；卡片恒显示未登录，清除会话按钮因状态条件不出现。
- **证据**：`system/[id].tsx:179-186` 没有传 `onSessionProbe`；`components/ui/SchoolSystemCard.tsx:102` 只在非 `signedOut` 时显示清除。
- **影响**：T-04 对 Moodle 一格失效：用户看不到登录/过期，也无法从列表清会话。
- **判据**：页面清单 T-04 要求三态徽标与清除会话动作。

### D-5 用户可见状态值是内部机器码，且夹带内联英文

- **症状**：九类状态回调共用 `tools.moodle.status`，词条值是 `'{value}'`。
  界面直接显示 `loading-courses`、`future-anomaly`、`not actionable` 等内部码。
- **证据**：`system/[id].tsx:76-84`；`i18n/zh.ts:135`、`i18n/en.ts:131` 均为 `{value}`；`system/[id].tsx:82` 另有内联英文。
- **影响**：中文界面出现英文机值，用户无法理解状态；也违反词条层单一来源。
- **判据**：宪法 6.1（面向用户的字符串走集中词条层）、10.4（错误可理解）、10.5-4（只留标识/动作/状态）。

### D-6 提取对象契约 52 个字段缺 19 个

- **症状**：课程缺收藏与进度；章节缺链接、可见性、当前状态；模块缺限制与完成状态。
  公告缺正文、结构化作者、发布时间、附件；作业缺开放与截止、要求、尝试次数、附件、成绩、评论数；资源缺重定向状态；文件夹 MIME 恒空。
- **证据**：`contract.ts:4-31`；`detail.ts:5-17,142-153`；`fixtures/moodle/README.md:22`（官方 cm state 含限制态，实现未取）。
- **影响**：原生工作台只能展示名称、结构与状态摘要，达不到 `P3R7` 契约表的字段边界。
- **判据**：`P3R7` §Moodle 提取对象契约 的 52 个字段。

### D-7 每日 03:00–04:30 维护窗口没有实现

- **症状**：维护时段内站点返回失败时，界面按普通失败处理，没有维护态文案与分支。
- **证据**：`app/src` 全仓无 maintenance / 03:00 / 04:30 判定（复现见附录命令 4）。
- **影响**：每日维护窗口里的失败会被显示成「加载失败」，与设计「显示维护状态，不把失败写成空数据」相反。
- **判据**：`P3R7` §数据质量规则「每日 03:00–04:30 显示维护状态」那一条。

### D-8 今日页在同步后最长 60 秒才更新

- **症状**：失效广播只在清缓存时发；同步写缓存不广播，今日页订阅收不到，只能等每分钟走表重算。
- **证据**：`cache.ts:33-49` 仅 `clearMoodleCache` 调 `notifyInvalidated`；`useMoodleAgenda.ts:38-44` 只订阅该广播。
  `TodayPane.tsx:59-62` 每 60 秒才更新 `now`。
- **影响**：从 Moodle 页同步完回到今日页，最多一分钟内仍显示旧待交或「未同步」。
- **判据**：广场今日页批次 R2 要求「订阅缓存失效事件」，T1 注释写明返回时必须自己变新。

### D-9 「无截止」桶把非作业模块全部列为无截止

- **症状**：任何无匹配截止事件的可见模块都进 `unset`，公告、资源、标签、页面全部被列为「无截止」。
- **证据**：`deadlines.ts:28-35`；界面按 `unset` 桶逐条渲染（`WorkspaceHost.tsx:180-181`）。
- **影响**：「无截止」清单等于模块清单，用户读不出哪一项真的是没写截止的作业。
- **判据**：`y3/04-截止分区与提醒.md` 用例 2 只要求「作业无截止」是一种合法状态。

### D-10 空态无动作、屏级四态缺无网态、列表与详情未复用既有组件

- **症状**：空态只有「没有可显示的内容」一行字；无网态缺失；课程列表与详情页自建 ScrollView，未用 `ListScreen` 或 `proto/P3`。
- **证据**：`WorkspaceScreen.tsx:79`、`DetailScreen.tsx:34,57`；`WorkspaceScreen.tsx:50`、`DetailScreen.tsx:29`。
  组件定义 §4 落点表见 `App组件类型定义.md:356-358`。
- **影响**：同类页面两套实现，改列表/详情规范要改两处；空态没有下一步动作。
- **判据**：宪法 10.1（四态是屏级交付物）、10.2 与 10.5-5（空态必须给动作）、9.5（组件库必须被消费）。

### D-11 通知与展示层四处小越线

- **症状**：通知默认文案是硬编码英文；Android 渠道名为「Class reminders」，Moodle 截止提醒也落进这个渠道。
  `maxHeight` 用 `space_6 * 8` 自造尺寸；按钮「进入本机工作台」7 个汉字。
- **证据**：`reminders/native.ts:46-47`；`features/notifications/permissions.ts:17`。
  `WorkspaceHost.tsx:173`；`i18n/zh.ts:127` 与 `WorkspaceHost.tsx:149`。
- **影响**：英文兜底可能漏到用户面前；系统设置里 Moodle 提醒被标成上课提醒；尺寸与文案越出规范。
- **判据**：宪法 6.1（词条层）、1.4.1（视觉只来自令牌）、10.5-3（按钮 ≤6 汉字）。

### D-12 代码坏味道与 P18 注册表状态（判断性）

- **症状**：同源 URL 白名单两份实现；域名字面量散在六个文件；查询函数带清理副作用；触发时刻有 number 与 ISO 两种形状；P18 仍标「建议·待评审」。
- **证据**：`contract.ts:81-101` 与 `detail.ts:25-57`；域名散在 `bridge.ts:16`、`contract.ts:84`、`detail.ts:29`、`identity.ts:10`。
  `cache.ts:56` 查询函数带副作用；`deadlines.ts:10` 与 `scheduler.ts:2` 经 `native.ts:52` 转换；`App组件类型定义.md:347,361` 仍标待评审。
- **影响**：改域名或改 URL 规则要散改；文档与实际实现不一致，评审者读到的仍是「待评审」。
- **判据**：坏味道基线 Duplicated Code、Shotgun Surgery、Mysterious Name、Data Clumps（判断性，非硬违规）。

### D-13 访客或登录页被判成「已过期」而非「未知」

- **症状**：探针遇到密码框或访客菜单一律返回 `expired`；任务书写的是 `unknown`。
- **证据**：`identity.ts:11`；`y3/05-学校身份与本机恢复.md` 用例 2 期望 `unknown`。
- **影响**：不恢复的行为正确，但语义把「没登录过」报成「登录过期」，后续若显示状态会误导用户。
